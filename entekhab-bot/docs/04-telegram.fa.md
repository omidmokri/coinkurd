# کنترل ربات از تلگرام

Freqtrade می‌تواند وضعیت و معامله‌ها را در تلگرام گزارش بدهد و دستور بگیرد. این **جدا**
از ربات تلگرام کوین کورد (`@Kurd_kurdistan_bot`) است؛ آن ربات هیچ معامله‌ای انجام نمی‌دهد
و این یکی فقط برای خودتان است.

## ۱. ساخت ربات

۱. در تلگرام به [@BotFather](https://t.me/BotFather) پیام بدهید.
۲. `/newbot` → نام و یوزرنیم بدهید → توکن را بگیرید.
۳. به [@userinfobot](https://t.me/userinfobot) پیام بدهید تا `chat_id` خودتان را بگیرید.

## ۲. گذاشتن در کانفیگ

در `config/config.entekhab.json`:

```json
"telegram": {
    "enabled": true,
    "token": "123456:ABC-...",
    "chat_id": "123456789"
}
```

توکن مثل رمز عبور است. فایل کانفیگ را کامیت نکنید.

## ۳. دستورهای مفید

| دستور | کار |
|---|---|
| `/status` | معامله‌های باز |
| `/profit` | خلاصهٔ سود و زیان |
| `/daily 7` | گزارش هفت روز اخیر |
| `/balance` | موجودی |
| `/stop` | توقف باز کردن معاملهٔ تازه |
| `/stopentry` | فقط ورودها را متوقف می‌کند، خروج‌ها ادامه دارند |
| `/forceexit <id>` | بستن دستی یک معامله |
| `/reload_config` | خواندن دوبارهٔ کانفیگ |

`/forceenter` پیش‌فرض خاموش است (`force_entry_enable: false`) و عمداً خاموش مانده.

## ۴. امنیت

- فقط `chat_id` خودتان را بگذارید. هر کس به آن چت دسترسی داشته باشد می‌تواند
  معاملهٔ شما را ببندد.
- اگر توکن لو رفت، در BotFather با `/revoke` باطلش کنید.
