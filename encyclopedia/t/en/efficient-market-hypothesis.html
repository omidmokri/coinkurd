Efficient Market Hypothesis

Simple definition

The idea that prices already reflect what is known, so finding a reliably mispriced asset is hard. It is a hypothesis about information, not a promise that prices are right.

Professional definition

The proposition that asset prices fully reflect a specified information set, so no rule using only that information earns a return above the equilibrium expected return. Stated in three forms by the information set assumed: weak, semi-strong and strong.

Technical definition

A statement that expected returns conditional on an information set equal equilibrium expected returns. Weak form takes the set to be past prices, returns and volume; semi-strong form all public information, so prices adjust at announcement rather than after it; strong form all information including private, which implies even insiders earn nothing abnormal. Because abnormal means abnormal relative to an asset-pricing model, every test is a joint test of efficiency and that model.

Academic definition

The hypothesis that prices are set so that expected returns conditional on a given information set coincide with equilibrium expected returns, rendering the information useless for earning risk-adjusted excess returns.

Mechanism

The engine is competition for information rents. If a knowable pattern paid, capital would crowd into it until the payment vanished, so efficiency is a prediction about the fate of discovered edges rather than a claim that markets are calm or correct. The same logic sets the limit: without some payoff to research nobody would gather information, so prices cannot be perfectly efficient and still get informative.

In practice

Who uses it
Asset pricing researchers, index fund managers, anyone evaluating a strategy's claimed edge, and regulators reasoning about disclosure.
Why it matters
It supplies the null hypothesis against which any claimed edge is measured, which is why a backtest without a benchmark is not evidence of anything.
Limitations
It cannot be tested on its own. Any rejection may instead reject the asset-pricing model used to define normal return, so efficiency is never falsified in isolation.

Common mistakes

  • Reading it as a claim that prices are fair or correct.
  • Treating a single anomaly as a refutation without checking the pricing model.
  • Confusing the weak form with the strong form when arguing about technical analysis.

Examples

market

A scheduled data release surprises the market. Under semi-strong efficiency the price moves at the release, not in the minutes after it, so a rule that buys one minute later earns nothing abnormal. Measuring that drift is how the form is actually tested.

research

A study finds small-capitalisation stocks beat the market on a risk-adjusted basis. That can mean the market is inefficient, or that the risk adjustment was wrong and size carries a risk the model omits. The data alone cannot separate the two.

numeric

Price is 100 and the model's equilibrium expected return is 2% per period. Efficiency then says the conditional expected price next period is 102, whatever the information set contains. A rule that expects 105 is claiming either an inefficiency or a missing risk.

Given
  • p_t = 100
  • equilibrium expected return from the chosen pricing model = 2% per period
  • information set available at t
Steps
  1. E[p_(t+1) | information] = (1 + 0.02) x 100
  2. = 102
E[p_(t+1) | information] = 102

The 2% is an output of a pricing model, not a market observation. Change the model and the efficient benchmark changes with it, which is the joint hypothesis problem in one line.

Mathematical foundation

\mathbb{E}\!\left[p_{j,t+1} \mid \Phi_t\right] = \left(1 + \mathbb{E}\!\left[r_{j,t+1} \mid \Phi_t\right]\right) p_{j,t}

Variables

p_{j,t}Price of asset j at time tprice units
\Phi_tThe information set assumed to be reflected in prices at t; its content is what distinguishes the three formsinformation set
\mathbb{E}[r_{j,t+1} \mid \Phi_t]Equilibrium expected return, supplied by an asset-pricing model and not by the hypothesis itselfreturn per period

Procedure

Choose the information set, which fixes which form is being tested. Choose an asset-pricing model to supply equilibrium expected returns. Form the excess of realised over model-implied expected return and test whether anything in the information set predicts it. A significant result rejects the pair, not the hypothesis alone.

Worked example

Given
  • p_t = 100
  • model-implied expected return = 2% per period
  • any information set Phi_t
Steps
  1. 1 + 0.02 = 1.02
  2. E[p_(t+1) | Phi_t] = 1.02 x 100
E[p_(t+1) | Phi_t] = 102

Interpretation

Efficiency does not say the price will be 102; it says no part of the information set shifts the conditional expectation away from 102. Predictability of returns is therefore not by itself evidence against efficiency unless the expected return model is granted.

Assumptions

  • The expected-return formulation above presumes a model that delivers equilibrium expected returns. The hypothesis supplies none, which is the joint hypothesis problem.
  • Transaction costs and the cost of acquiring information are set aside. With them, small predictable components can persist without being exploitable.
  • Weaker variants replace the equality with a submartingale or a pure martingale condition on prices; these are different statements and are tested differently.
Limits of the formula
  • Not independently falsifiable: a rejection is always shared between efficiency and the pricing model, so the hypothesis survives any single anomaly by construction.
  • Efficiency is relative to a stated information set and a market. A result for large listed equities says little about a thin token market with different costs and participants.

Commonly confused with

Random Walk

A random walk is a statistical model of a price path. Efficiency is an economic claim about information and expected returns. Efficiency does not require a random walk, and a random walk is not proof of efficiency.
