Simple definition

A small dedicated device that holds your key and signs inside itself. The key never leaves it, so a compromised computer cannot read it.

Professional definition

A purpose-built signing device whose private keys are generated on the device and never exported. The host computer builds the transaction, the device displays and signs it, and only the signature travels back. The protection comes from that boundary, not from the brand.

Technical definition

The threat model assumes the connected computer is hostile. Keys are generated on-device from its own entropy, the recovery phrase is shown once on the device screen, and signing requires a physical confirmation. The device screen is the trust anchor: address and amount must be read there, because malware controls what the host displays. A device bought second-hand or from an unofficial reseller, or initialised with a phrase someone else supplied, provides none of this.

Academic definition

A dedicated signing appliance that isolates key material and transaction confirmation from a potentially compromised host, narrowing the attack surface to physical access and user approval.

Mechanism

Every spend needs the key, so the only way to keep the key safe while still spending is to move the signing operation onto a device that does nothing else. Isolation works because the device exports a signature and never a secret, and because the user verifies on hardware that the host cannot repaint.

In practice

Who uses it
Long-term holders, treasury and operations teams, validators handling withdrawal keys, and anyone signing contract interactions regularly.
Why it matters
It keeps the key out of reach of malware on the everyday machine while still allowing routine signing.
Limitations
It does not protect against approving a malicious transaction, a copied or lost recovery phrase, coercion, or a tampered device from an untrusted seller.

Common mistakes

  • Buying a signing device second-hand or from an unofficial reseller.
  • Accepting a pre-printed recovery phrase instead of generating it on the device.
  • Confirming a signature without reading the address on the device screen.

Examples

security

Malware on the laptop swaps the destination address after the user pastes it. The host shows the intended address; the device screen shows the attacker's. Reading the device is the only way the substitution is caught.

numeric

A BIP-39 word list holds 2,048 words, so each word carries 11 bits. A 24-word phrase is 264 bits: 256 bits of entropy plus an 8-bit checksum, generated on the device and shown only there.

Given
  • Word list size = 2048 = 2^11
  • Phrase length = 24 words
  • BIP-39 checksum = entropy length / 32 bits
Steps
  1. 24 x 11 = 264 bits total
  2. 264 - 8 = 256 bits of entropy
  3. Checksum = 256 / 32 = 8 bits
256 bits of entropy in a 24-word phrase

The strength holds only if the device generated the words itself. A phrase supplied by anyone else is already known to them, whatever its length.
