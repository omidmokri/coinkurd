Efficient Frontier

Simple definition

The set of portfolios offering the most expected return available at each level of risk. Anything below it is dominated: the same risk could have bought more expected return.

Professional definition

In mean-variance space, the upper boundary of the feasible set: for every target expected return, the weight combination with the smallest variance. It is concave, starts at the global minimum-variance portfolio, and when a risk-free asset is added the relevant efficient set becomes a straight line through the tangency portfolio.

Technical definition

The solution set of a constrained quadratic programme: minimise the quadratic form of the weights with the covariance matrix, subject to the weighted expected return equalling a target and the weights summing to one, traced over all attainable targets. Without a risk-free asset the frontier is a hyperbola in mean-standard-deviation space. With unlimited lending and borrowing at one rate it is replaced by the capital allocation line from that rate through the maximum-Sharpe tangency portfolio. The frontier is only as reliable as the estimated inputs behind it.

Academic definition

The locus of minimum-variance portfolios across attainable levels of expected return, obtained as the solution set of a quadratic programme in the weight vector subject to budget and return constraints.

Mechanism

Because variance is quadratic and expected return linear in the weights, the feasible set in mean-standard-deviation space is bounded by a curve rather than a straight line. The curvature comes entirely from the covariance cross terms: the lower the correlations, the further left the frontier bows, and the more expected return is reachable at a given volatility.

In practice

Who uses it
Allocation committees, multi-asset researchers, and risk teams comparing candidate portfolios on a common risk axis.
Why it matters
It makes the trade-off explicit, so any proposed portfolio can be located against the best combination available at the same volatility.
Limitations
Frontiers computed from sample estimates move substantially from one estimation window to the next, so a point on the curve is much less precise than the curve's smoothness suggests.

Common mistakes

  • Presenting an estimated frontier as though the inputs were known quantities.
  • Optimising on past returns and treating the extreme corner weights as insight.
  • Forgetting that every added constraint pushes the whole frontier down.

Examples

numeric

Two assets with volatilities 20% and 10% and correlation 0.2. The minimum-variance mix holds 14.3% of the first and 85.7% of the second, and its volatility is 9.56% — below the 10% of the quieter asset held alone.

Given
  • sigma1 = 0.20, sigma2 = 0.10
  • rho = 0.2, so covariance = 0.2 x 0.20 x 0.10 = 0.004
Steps
  1. numerator = sigma2^2 - cov = 0.0100 - 0.0040 = 0.0060
  2. denominator = sigma1^2 + sigma2^2 - 2 cov = 0.0400 + 0.0100 - 0.0080 = 0.0420
  3. w1 = 0.0060 / 0.0420 = 0.1429, w2 = 0.8571
  4. variance = 0.1429^2 (0.0400) + 0.8571^2 (0.0100) + 2 (0.1429)(0.8571)(0.0040) = 0.009143
  5. volatility = sqrt(0.009143) = 0.0956
minimum-variance volatility 9.56%, lower than either asset on its own

The closed form applies to two assets only and can return a weight outside the zero-to-one range; with more assets, or with a short-selling constraint, the frontier is solved numerically.

market

Adding a class with a lower standalone expected return can still move the frontier up and to the left if its correlation with the existing holdings is low enough. The frontier judges combinations, never single holdings.

Mathematical foundation

\min_{\mathbf{w}} \; \mathbf{w}^{\top} \Sigma \mathbf{w} \quad \text{subject to} \quad \mathbf{w}^{\top} \boldsymbol{\mu} = \mu^{*}, \;\; \mathbf{w}^{\top} \mathbf{1} = 1, \qquad w_1^{\mathrm{MV}} = \frac{\sigma_2^2 - \rho_{12} \sigma_1 \sigma_2}{\sigma_1^2 + \sigma_2^2 - 2 \rho_{12} \sigma_1 \sigma_2}

Variables

\mathbf{w}Vector of portfolio weights being solved forfractions
\SigmaCovariance matrix of asset returnssquared return units
\boldsymbol{\mu}Vector of expected returns% per period
\mu^{*}Target expected return for the portfolio% per period
w_1^{\mathrm{MV}}Weight of asset 1 in the two-asset global minimum-variance portfoliofraction of portfolio
\rho_{12}Correlation between the two assets' returnsdimensionless

Procedure

Fix a target expected return, then find the weights that minimise portfolio variance subject to reaching that target and being fully invested. Repeat over a grid of targets; the resulting points trace the frontier. For two assets the global minimum-variance weight has the closed form above; beyond two, use a quadratic solver, and add non-negativity if short selling is not permitted.

Worked example

Given
  • two assets: sigma1 = 0.20, sigma2 = 0.10
  • rho_12 = 0.2
Steps
  1. covariance = 0.2 x 0.20 x 0.10 = 0.0040
  2. numerator = 0.0100 - 0.0040 = 0.0060
  3. denominator = 0.0400 + 0.0100 - 2(0.0040) = 0.0420
  4. w1 = 0.0060 / 0.0420 = 0.142857, w2 = 0.857143
  5. variance = 0.020408(0.0400) + 0.734694(0.0100) + 2(0.122449)(0.0040) = 0.0091429
  6. volatility = sqrt(0.0091429) = 0.095619
the global minimum-variance portfolio sits at 9.56% volatility, to the left of both single assets

Interpretation

A point on the frontier is the smallest variance obtainable at a stated expected return under the stated inputs. It is not a prediction, and portfolios on the frontier are not ranked against each other: the choice among them is a risk preference, not a calculation.

Assumptions

  • Single period; returns summarised by the mean vector and covariance matrix only.
  • Short sales are permitted unless a non-negativity constraint is added; the two-asset closed form can return a weight outside zero to one, which then has no unconstrained meaning.
  • Parameters are treated as known. Because they are estimates, the frontier is itself a random object and shifts with the estimation window.
Limits of the formula
  • The curve's apparent precision is an artefact of plotting point estimates; sampling error in the mean vector dominates, which is why minimum-variance and risk-parity constructions avoid using means at all.
  • With a risk-free asset the efficient set is a straight line, not this hyperbola, so the two must not be drawn as interchangeable.

Commonly confused with

Risk Parity

The frontier requires expected returns as inputs and ranks combinations by variance at a given mean. Risk parity uses no return estimates at all, so its portfolio need not lie on any estimated frontier.
