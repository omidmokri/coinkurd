Real versus nominal return

Simple definition

Nominal return is the percentage your balance grew. Real return is what is left after inflation. Only the second one tells you whether you can buy more than before.

Professional definition

Two ways of stating the same gain. The nominal figure is the change in currency units; the real figure deflates it by the price level over the same window. The exact link is multiplicative, not additive, and the gap widens as inflation rises.

Technical definition

Under the Fisher relation, one plus the nominal return equals the product of one plus the real return and one plus inflation. Subtracting inflation from the nominal return is a first-order approximation whose error is the cross-term r x i; at low inflation the error is small, at high inflation it is not. Realised and expected versions of the relation must be kept distinct.

Academic definition

The decomposition of a nominal rate of return into a real component and a compensation for realised or expected inflation, related multiplicatively rather than additively.

Mechanism

A return is a ratio of money, and inflation changes the unit that money is measured in. Correcting for it therefore means dividing by the price-level factor, not subtracting a percentage — the same reason that compounding two percentages is not adding them.

In practice

Who uses it
Long-horizon savers, pension and endowment committees, anyone comparing returns across inflationary regimes or across currencies.
Why it matters
A nominal track record from a high-inflation decade is not comparable with one from a low-inflation decade until both are deflated.
Limitations
The real figure inherits the chosen price index, and taxes are usually levied on the nominal gain, so after-tax real returns are lower again.

Common mistakes

  • Using n minus i at double-digit inflation and calling it exact.
  • Deflating with an index that does not match your spending.
  • Comparing a real return with a nominal benchmark.

Examples

market

A deposit account advertised at 18% in a year of 25% inflation is a losing position in goods, even though every monthly statement shows a larger balance than the one before.

numeric

Nominal 18%, inflation 25%: the exact real return is minus 5.6%, while the shortcut 18 minus 25 says minus 7%. The approximation is wrong by 1.4 percentage points because it drops the cross-term.

Given
  • nominal return n = 18%
  • inflation i = 25%
  • same measurement window for both
Steps
  1. 1 + r = 1.18 / 1.25 = 0.944
  2. r = 0.944 - 1 = -0.056
  3. linear shortcut: 0.18 - 0.25 = -0.07
exact r = -5.6%; approximation = -7.0%

Illustrative figures. The error equals r x i and grows with the size of both terms.

Mathematical foundation

(1+n) = (1+r)(1+i) \;\Longrightarrow\; r = \frac{1+n}{1+i} - 1 \;\approx\; n - i

Variables

nNominal return over the perioddecimal or %
rReal return over the same perioddecimal or %
iInflation over the same period, from a stated indexdecimal or %

Procedure

Measure the nominal return and inflation over identical windows. Divide one plus the nominal by one plus inflation and subtract one. Use the subtraction shortcut only as a rough check, and never at high inflation.

Worked example

Given
  • n = 18%
  • i = 25%
Steps
  1. 1.18 / 1.25 = 0.944
  2. 0.944 - 1
r = -5.6%

Interpretation

A real return of minus 5.6% means the holding commands 5.6% fewer goods than at the start, despite a larger nominal balance. The sign of the real figure, not the nominal one, answers whether wealth grew.

Assumptions

  • The nominal return and the inflation measure cover exactly the same window and the same currency.
  • The relation shown is the realised (ex post) form. The ex ante form uses expected inflation and therefore carries an expectations error.
  • n - i is an approximation only; it is reported here as such and must never be presented as the identity.
Limits of the formula
  • Index choice changes the answer; a household's own basket can differ materially from the published series.
  • Taxes usually apply to nominal gains, so the after-tax real return is lower than this calculation.

Commonly confused with

Real interest rate

The real interest rate is the real return on a lending contract. Real return is the general case, applied to any asset, including ones with no stated rate at all.
