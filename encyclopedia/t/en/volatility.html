Simple definition

How much and how fast a price swings around its own average. High volatility means large moves in both directions, and says nothing about which way.

Professional definition

The dispersion of an asset's returns, normally measured as the standard deviation of periodic returns and quoted on an annual basis. It measures the size of movement, is symmetric by construction, and carries no directional information.

Technical definition

Realised volatility is a sample statistic: the standard deviation of log returns over a window, scaled to an annual figure by the square root of the number of periods in a year. Because it is estimated from a finite sample it is noisy, and because it is backward-looking it is not the same object as the implied volatility quoted in options. Volatility also clusters, so a single window estimate describes that window and lags a regime change.

Academic definition

The standard deviation of an asset's returns over a specified interval, conventionally annualised, used as the canonical scalar measure of dispersion in return distributions.

Mechanism

Volatility rises when information arrives faster than liquidity can absorb it. Thinner books mean each order moves price further, and the resulting moves widen spreads and push liquidity providers to withdraw. That feedback loop is why volatility arrives in clusters rather than being spread evenly through time.

In practice

Who uses it
Position sizers, options traders, risk managers setting limits, and anyone comparing instruments of different typical range.
Why it matters
It converts price swings into one number that can size a position, scale a stop, or compare a small token with a broad index.
Limitations
It is symmetric, so an asset that grinds up and crashes down scores the same as one that does the opposite. A single window estimate is noisy and lags a regime change.

Common mistakes

  • Comparing an annualised crypto figure with an equity figure computed on 252 days.
  • Treating a volatility estimate as a bound on the next move.
  • Using a long window across a regime change and calling it current.

Examples

market

An asset ranges quietly for weeks, so a 30-day volatility estimate is low and stops placed on it are tight. A repricing arrives, daily ranges triple, and every stop sized on the quiet window is now far too close to the price.

numeric

Daily log returns have a standard deviation of 3.0%. Annualised on a 365-day year that is about 57%, and on a 252-day year about 48%. The same data, two headline numbers, so the day count must always be stated.

Given
  • standard deviation of daily log returns = 3.0%
  • crypto convention: T = 365 periods per year
  • equity convention for comparison: T = 252 trading days
Steps
  1. sqrt(365) = 19.105
  2. annualised, crypto convention = 3.0% x 19.105 = 57.3%
  3. sqrt(252) = 15.875
  4. annualised, equity convention = 3.0% x 15.875 = 47.6%
about 57% annualised on a 365-day year, about 48% on a 252-day year

Neither day count is more correct than the other; they are conventions attached to how the instrument trades. A figure quoted without its day count cannot be compared with anything.

Procedure

Build the series of period returns, using log returns so that they add across periods. Take the sample standard deviation with the n-1 denominator. Multiply by the square root of the number of periods in a year to state the figure on an annual basis, and record which day count was used.

Worked example

Given
  • sigma_period = 3.0% per day
  • T = 365
Steps
  1. sqrt(365) = 19.105
  2. 3.0% x 19.105 = 57.3%
sigma_ann = 57.3% per year on the 365-day convention

Interpretation

An annualised volatility of 57% is a statement about the typical size of moves implied by the sample, under the assumption that the scaling holds. It is not a range the price is expected to stay inside, and it has no direction.

Assumptions

  • The sqrt(T) scaling requires the period returns to be independent and identically distributed. Returns are not: they show volatility clustering and some autocorrelation, so the scaled figure is an approximation whose error grows with the horizon.
  • The n-1 denominator is the sample estimator, which is unbiased for the variance when the mean is estimated from the same data. Some platforms divide by n, which lowers the figure noticeably on short windows.
  • Log returns are the convention because they add across periods. Simple returns do not, and mixing the two makes the annualisation inconsistent.
  • Crypto is conventionally annualised with 365 periods because it trades continuously, while equities use about 252 trading days. Neither is correct in an absolute sense; the convention must be stated with the number.
  • The mean return is usually left in the formula but is often small relative to the dispersion over short windows; some practitioners set it to zero, which changes the figure slightly.
Limits of the formula
  • It treats upside and downside dispersion identically and is blind to skew and fat tails, so it understates how often extreme moves occur in return distributions that are not normal.
  • An estimate over a window describes that window. It carries no forward guarantee, and volatility clustering means the estimate is most wrong exactly when the regime changes.

Commonly confused with

Implied Volatility

This entry is realised volatility, computed from past returns. Implied volatility is a price, extracted from option premiums under a model, and the two routinely differ.
