Simple definition

The return a portfolio earned beyond what its risk exposures should have produced. Positive alpha looks like skill — but only relative to the model used to define 'should'.

Professional definition

The intercept of the regression of a portfolio's excess return on its factor exposures. In the single-factor case it is Jensen's alpha: realised return minus the risk-free rate minus beta times the market premium. It is always relative to a chosen model.

Technical definition

Alpha is the constant term that makes the factor regression fit, so it is by construction the part of average excess return the chosen factors cannot explain. Adding a factor that the portfolio loads on reallocates return from the intercept to that factor, so an alpha that is significant in a one-factor model can vanish in a multi-factor one. An alpha estimate also inherits the regression's sampling error and is rarely significant on a short record.

Academic definition

The intercept of a factor-model regression of portfolio excess returns, interpreted as risk-adjusted abnormal performance conditional on the specified factor structure.

Mechanism

A factor regression splits average excess return into a part attributable to known exposures and a leftover constant. The split depends entirely on which exposures are in the model. Alpha is therefore not a property of the portfolio but a property of the pair portfolio and model: enlarge the model and the leftover shrinks, which is exactly what happened historically as size and value factors were added.

In practice

Who uses it
Allocators evaluating active managers, researchers testing whether a strategy survives risk adjustment, and performance-attribution teams.
Why it matters
It isolates the part of a record that known risk exposures do not account for, which is the only part a fee for skill can be defended on.
Limitations
It is model-relative and sample-noisy. A positive alpha against one factor set is not evidence against another, richer one.

Common mistakes

  • Quoting an alpha without naming the factor model behind it.
  • Reading raw outperformance as alpha without any risk adjustment.
  • Treating an insignificant positive estimate as established skill.

Examples

numeric

Fund returns 14%, risk-free 3%, market 10%, beta 1.2. The model expects 3 + 1.2 x 7 = 11.4%, so Jensen's alpha is 2.6%. Against the one-factor model the fund looks skilful.

Given
  • R_p = 14%
  • R_f = 3%
  • R_m = 10%
  • beta = 1.2
  • annual figures, one market proxy
Steps
  1. market premium = 10% - 3% = 7%
  2. expected return = 3% + 1.2 * 7% = 11.4%
  3. alpha = 14% - 11.4% = 2.6%
Jensen's alpha = 2.6% per year

Verified arithmetic. The figure is the intercept of a one-factor regression and is only defined relative to that one factor.

pitfall

The same fund also loads 0.5 on a size factor earning 3% and 0.3 on a value factor earning 2%. Those exposures explain 2.1% of the 2.6%, leaving alpha of 0.5%. The skill was mostly factor exposure in disguise.

Given
  • one-factor alpha = 2.6%
  • size loading 0.5 with a 3% premium
  • value loading 0.3 with a 2% premium
  • illustrative premiums, not measured figures
Steps
  1. size contribution = 0.5 * 3% = 1.5%
  2. value contribution = 0.3 * 2% = 0.6%
  3. total explained by the added factors = 2.1%
  4. three-factor alpha = 2.6% - 2.1% = 0.5%
alpha falls from 2.6% to 0.5% when two factors are added

The portfolio did not change; the model did. This is why an alpha figure is meaningless without the factor model that produced it.

Mathematical foundation

\alpha_i = \bar{R}_i - \left[R_f + \beta_i\left(\bar{R}_m - R_f\right)\right], \qquad R_{i,t} - R_{f,t} = \alpha_i + \sum_{k=1}^{K} \beta_{i,k} F_{k,t} + \varepsilon_{i,t}

Variables

Procedure

State the factor model first. Subtract the matching risk-free rate from the portfolio's returns. Regress that excess return series on the factor returns over the same periods; the intercept is alpha and its t-statistic decides whether the estimate is distinguishable from zero. Report the model, the window and the standard error alongside the figure.

Worked example

Given
  • R_p = 14%, R_f = 3%, R_m = 10%, beta = 1.2
  • then add size loading 0.5 with 3% premium and value loading 0.3 with 2% premium
Steps
  1. one-factor expected return = 3 + 1.2 * (10 - 3) = 11.4%
  2. one-factor alpha = 14 - 11.4 = 2.6%
  3. added factor contribution = 0.5 * 3 + 0.3 * 2 = 1.5 + 0.6 = 2.1%
  4. three-factor alpha = 2.6 - 2.1 = 0.5%
alpha = 2.6% under one factor, 0.5% under three

Interpretation

A positive alpha says the record beat what the stated model predicted from its exposures. It is a statement about the residual of one specification, so it must always be read together with the model and the standard error.

Assumptions

  • Alpha is defined only relative to a specified factor model; there is no model-free alpha.
  • The regression assumes stable loadings over the window and linear factor exposure.
  • Jensen's alpha uses a single market factor; multi-factor specifications such as the three-factor model typically reduce the intercept for the same portfolio.
Limits of the formula
  • The estimate carries the regression's standard error and is usually insignificant on records shorter than several years.
  • Selecting the best alpha among many managers or strategies inflates it, so a reported figure is biased upwards by the search that found it.
  • Fees, borrowing costs and non-linear exposures such as option-like payoffs can all masquerade as alpha in a linear model.

Commonly confused with

Fama-French Factors

Adding size and value factors moves return out of the intercept and into factor exposure, so the same portfolio can show large alpha in one model and almost none in the other.

Commonly confused with

Information Ratio

Alpha is a level of unexplained return. The information ratio scales active return by its own volatility, so it rewards consistency rather than magnitude.
