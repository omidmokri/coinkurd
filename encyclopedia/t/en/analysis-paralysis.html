Analysis Paralysis

Category
Market Psychology
Level
Foundation

Simple definition

Gathering more and more evidence instead of deciding. Each extra chart feels like progress, but the decision itself never gets made or gets made too late.

Professional definition

Practitioner vocabulary for a state in which the search for confirmation displaces the decision. It is not a research construct; what can be stated precisely is the structural reason it persists: most added indicators are largely redundant, so they raise apparent confidence without adding independent information.

Technical definition

Many popular indicators are transformations of the same close-price series, so their signals are highly correlated. Adding one therefore changes the effective sample size very little while multiplying the number of conditions that must align, which pushes the signal rate down toward zero. The visible symptom is indecision; the measurable part is a rule set whose joint condition almost never fires, and that can be counted directly in a backtest.

Academic definition

An informal label for decision deferral under an expanding and largely redundant evidence set; the redundancy of correlated indicators is measurable, the label itself is not a formal construct.

Mechanism

Each new input raises the number of conditions a trade must satisfy, so the set of acceptable moments shrinks. Because the inputs mostly measure the same price series, the extra conditions add little independent evidence and mainly add agreement requirements. Waiting also has no visible cost on the screen, while a wrong entry does, so deferral feels free even when the opportunity is the thing being spent.

In practice

Who uses it
Newer discretionary traders assembling a method, and anyone whose checklist has grown one condition at a time.
Why it matters
Counting how often the full condition set has fired historically converts a feeling of caution into a number that can be adjusted.
Limitations
Not deciding is sometimes correct: a genuinely unclear market is a reason to stand aside. The term describes indecision caused by redundant evidence, which is a different thing and not always easy to tell apart.

Common mistakes

  • Adding an indicator to resolve a disagreement between two indicators.
  • Treating correlated signals as independent confirmation.
  • Leaving the entry trigger unwritten so it can always be reconsidered.

Examples

market

A checklist requires nine conditions, six of which are moving-average and momentum readings on the same closes. The set fires twice a year, and both times the trader waits for the tenth condition that was added last week.

everyday

Choosing between two routes home, then checking three more maps. The extra maps mostly repeat the first two, and the time spent checking is longer than the difference between the routes.

Commonly confused with

Overfitting

Overfitting is a measurable property of a model: it fits noise and fails out of sample. Analysis paralysis is about a decision not being taken. A rule set can suffer from both at once, for the same reason.
