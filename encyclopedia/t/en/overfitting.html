Overfitting

Simple definition

Tuning a rule until it fits the past very closely, including the parts that were random. It then performs well on the data it was built from and poorly on anything else.

Professional definition

Fitting a strategy to features of a sample that will not repeat. It arises from too many free parameters relative to the data, and from testing many candidates and keeping the best, which selects for luck as reliably as for skill.

Technical definition

Overfitting is a selection problem, not a coding error. With N independent candidate rules each tested at significance level alpha, the probability that at least one passes by chance is 1 minus (1 minus alpha) to the power N, which approaches certainty quickly. Added parameters do the same through flexibility: the model absorbs noise as if it were signal. In-sample metrics therefore rise with search effort while out-of-sample performance falls, and a good-looking equity curve on the data used to build the rule carries almost no information.

Academic definition

The estimation of model structure or parameters that captures sample-specific noise rather than a stable data-generating relationship, inflating in-sample fit while degrading generalisation to unseen data.

Mechanism

Search is the engine. Each additional parameter, filter, threshold or tested variant is another draw from a distribution of random outcomes, and the researcher keeps the maximum. The maximum of many draws is far above the mean even when every rule is worthless, so the reported in-sample result measures search effort as much as edge. Nothing in the sample can reveal this, because the sample is what was searched.

In practice

Who uses it
Strategy developers, quantitative researchers, machine-learning practitioners, and reviewers assessing someone else's results.
Why it matters
It explains the single most common failure of systematic trading: a result that was real in the sample and absent afterwards, with no bug to find.
Limitations
There is no test that proves a rule is not overfitted. Holdout data, walk-forward protocols and parameter parsimony reduce the risk; they do not remove it, and each reuse of the holdout erodes it.

Common mistakes

  • Reporting the best parameter set without the number of sets tried.
  • Reusing the same holdout period after each revision.
  • Adding a filter to remove the worst historical trades.

Examples

market

A rule with two parameters is profitable. Six filters are added to remove its worst historical trades and the curve becomes smooth. Live, the filters block ordinary trades too, and the edge is gone.

numeric

Test 100 worthless variants at a 5 percent threshold and the chance that at least one looks significant is 99.4 percent. Reporting that winner without the count of trials reports noise as a finding.

Given
  • N = 100 candidate rules, each with no genuine edge
  • significance threshold alpha = 0.05 per test
  • tests treated as independent
Steps
  1. probability one test does not pass = 1 - 0.05 = 0.95
  2. probability none of 100 passes = 0.95^100 = 0.0059
  3. probability at least one passes = 1 - 0.0059 = 0.9941
about a 99.4 percent chance of at least one false positive

Independence is an idealisation: overlapping parameter grids are correlated, which lowers the effective number of tests but does not remove the problem.

Mathematical foundation

P(\text{at least one false pass}) = 1 - (1 - \alpha)^{N}

Variables

\alphaSignificance threshold applied to each individual testprobability
NNumber of candidate rules, parameter sets or variants actually testedcount

Procedure

Count every variant actually evaluated, including those discarded early and those tried informally. Apply the expression to that count, not to the number of results reported, and compare the outcome with the confidence being claimed for the surviving rule.

Worked example

Given
  • alpha = 0.05
  • N = 100
Steps
  1. 1 - 0.05 = 0.95
  2. 0.95^100 = 0.0059
  3. 1 - 0.0059 = 0.9941
0.9941, about 99.4 percent

Interpretation

The expression gives the probability of finding at least one apparently significant rule when none has an edge. It is the reason a single surviving backtest, reported without its search history, is not evidence.

Assumptions

  • Tests are treated as independent; correlated parameter grids reduce the effective N but never to one.
  • Alpha is the threshold genuinely applied per test, not the one reported afterwards for the winner.
  • The count N must include informal and abandoned trials, which are the ones most often left out.
Limits of the formula
  • The expression bounds false discovery under search; it does not measure how much of a given result is noise.
  • It says nothing about overfitting through model flexibility, where a single highly parameterised model absorbs noise without any explicit search over variants.

Related terminology

Commonly confused with

Lookahead Bias

Lookahead bias uses information that did not exist yet, so the result is void. Overfitting uses only legitimate information but selects the rule on the same data it is then judged by, so the result is unmeasurable rather than impossible.
