Confidence Interval

Simple definition

A range built around an estimate, wide enough that the method producing it lands on the true value a stated share of the time. It shows how little one sample pins down.

Professional definition

An interval computed from sample data by a procedure whose long-run coverage equals the stated level. A 95% interval means that across repeated samples, 95% of intervals built this way contain the true parameter — not that this particular interval contains it with 95% probability.

Technical definition

The set of parameter values a two-sided test at level alpha would not reject, so interval and test carry the same information presented differently. Confidence attaches to the procedure, not to the realised interval: once computed, the interval either contains the parameter or does not, and nothing in frequentist probability assigns that a number. The reading that gives a probability to the parameter describes a Bayesian credible interval, which requires a prior.

Academic definition

A random interval whose coverage probability for a parameter equals a specified level under repeated sampling from the assumed model.

Mechanism

The width comes almost entirely from the standard error, which shrinks with the square root of the sample size. That square root is why precision is expensive: four times the data for half the width. The interval therefore reports how much the sample could not settle, which is the part a point estimate silently hides.

In practice

Who uses it
Anyone reporting an estimated mean, Sharpe ratio, win rate or regression coefficient, and anyone deciding whether a measured edge is distinguishable from zero.
Why it matters
It converts a single number into an honest range, and an interval that straddles zero says plainly that the data cannot rule out no edge at all.
Limitations
The coverage guarantee holds only if the model is right. Dependent observations, non-constant variance or a selected sample all break it, usually making the interval too narrow.

Common mistakes

  • Saying there is a 95% probability the true value lies inside this interval.
  • Treating a wide interval as a weak result rather than a small sample.
  • Building the interval after selecting the best of many strategies.

Examples

numeric

Mean daily return 0.05% with 1.0% standard deviation over 250 days gives a standard error of 0.063%. The 95% interval runs from minus 0.075% to plus 0.175% — it straddles zero, so the sample cannot distinguish this strategy from no edge.

Given
  • sample mean = 0.05% per day
  • s = 1.0% per day
  • n = 250, df = 249
  • 95% two-sided level, t critical = 1.9695
  • observations assumed independent and identically distributed
Steps
  1. standard error = 1.0 / sqrt(250) = 0.063246%
  2. half width = 1.9695 x 0.063246 = 0.12456%
  3. lower = 0.05 - 0.12456 = -0.07456%
  4. upper = 0.05 + 0.12456 = 0.17456%
95% CI = (-0.0746%, 0.1746%) per day

Verified numerically. The interval contains zero, so a 5% two-sided test of a zero mean would not reject — the interval and the test are the same statement.

everyday

Imagine building a hundred such intervals from a hundred independent samples. About ninety-five of them would contain the true value and about five would miss entirely. You never learn which kind you are holding, and that is the honest content of the word confidence.

Mathematical foundation

Procedure

Compute the sample mean and the sample standard deviation with the n minus 1 divisor. Divide the standard deviation by the square root of the sample size to get the standard error. Look up the t critical value for your level and degrees of freedom. Multiply, then add and subtract from the mean. Report the level, the sample size and whether the interval contains the value of interest.

Worked example

Given
  • mean = 0.05% per day
  • s = 1.0% per day
  • n = 250
  • 95% level, t(0.975, 249) = 1.9695
Steps
  1. standard error = 1.0/sqrt(250) = 0.063246
  2. margin = 1.9695 x 0.063246 = 0.12456
  3. interval = 0.05 - 0.12456 to 0.05 + 0.12456
95% CI = (-0.0746%, 0.1746%) per day

Interpretation

The 95% refers to the long-run coverage of the procedure, not to a 95% probability that the parameter lies in this interval. Saying 'there is a 95% chance the true mean is between these numbers' is a misreading: the parameter is fixed and the interval is what varies across samples. The statement that does assign probability to the parameter is a Bayesian credible interval, and it needs a prior.

Assumptions

  • The t form assumes independent, identically distributed observations and an approximately normal sampling distribution of the mean; autocorrelated or heteroskedastic returns break both.
  • The stated coverage is a property of the procedure under repeated sampling from the assumed model, not a probability statement about the realised interval.
  • The interval must be specified before the data are mined. An interval computed around the best of many searched estimates has far worse coverage than its nominal level.
Limits of the formula
  • Width scales with one over the square root of n, so halving it costs four times the data and quartering it sixteen times.
  • Coverage is only as good as the model. In practice intervals on financial data are usually too narrow, because dependence in the series inflates the effective sample size assumed by the formula.

Commonly confused with

p-value

They are two views of one calculation. The interval lists every null value that would survive the test; the p value reports how one chosen null fared. The interval is usually the more informative report.
