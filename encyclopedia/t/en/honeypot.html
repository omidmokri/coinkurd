Simple definition

A token you can buy but cannot sell. The chart looks healthy because only buying works; the money that goes in cannot come back out.

Professional definition

A token whose contract permits inbound purchases while preventing resale for ordinary holders, whether by a transfer restriction, an address allow-list, or a sell charge set so high that the proceeds round to nothing. The rising price is an artefact of one-way flow.

Technical definition

A deliberate asymmetry in transfer logic. The defining property is that the sell path is conditional on something the buyer does not control: a controlling key that can change transfer rules or rates after listing, an allow-list the insiders are on, or a fee parameter that is mutable without limit. Static source review and a simulated sell both help, but a mutable parameter means a token that tests clean today can be closed tomorrow.

Academic definition

A crypto-asset whose transfer logic is asymmetric by design, admitting purchases while rendering resale infeasible for non-privileged holders, so that recorded prices do not represent realisable value.

Mechanism

Price on a pool is just the ratio of reserves, and a buy moves it up whether or not anyone could ever sell. Blocking the return path therefore produces a chart that only rises, which is the advertisement. The loss is realised not when the price falls but at the first attempt to exit, which is also when most holders discover the restriction.

In practice

Who uses it
Anyone buying a token outside an established listing, plus listing reviewers and on-chain analysts.
Why it matters
The restriction is in public code before any money is risked, so it is one of the few crypto risks that can be checked in advance.
Limitations
A clean check is not a guarantee: where fee or rule parameters are mutable, behaviour can change after the test, and a scanner verdict is an opinion on code it may not fully model.

Common mistakes

  • Judging a token by its price chart and holder count.
  • Buying before confirming that other holders have sold successfully.
  • Trusting a single automated scanner as proof the token is safe.

Examples

numeric

A holder buys 1,000 tokens quoted at 0.50, a position shown as worth 500. The contract applies a 99% charge on sales, so the sell returns about 5. The displayed value was never realisable.

Given
  • Holding = 1,000 tokens
  • Quoted price = 0.50
  • Displayed value = 500
  • Sell charge applied by the contract = 99%
Steps
  1. Gross proceeds at the quote = 1,000 x 0.50 = 500
  2. Retained by the contract = 500 x 0.99 = 495
  3. Received = 500 - 495 = 5
A position displayed as 500 realises about 5, before pool impact and gas

A quoted price only measures realisable value when the sell path is open to the holder. Here it measures the buy path only.

security

A token passes a buy test, then a controlling key raises the sell charge after the pool has filled. The code that was reviewed is the code that allowed the change, so the earlier check told the buyer nothing durable.

Rug Pull

In a honeypot the exit is closed from the beginning. In a rug pull it closes when the insiders choose to leave.
