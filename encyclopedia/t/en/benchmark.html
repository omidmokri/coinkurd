Simple definition

The reference portfolio or index a result is measured against. Without one, a return is just a number and there is nothing to say whether it was good.

Professional definition

A specified, investable reference against which a portfolio's return and risk are judged. A usable benchmark is unambiguous in constituents and weights, investable, measurable at the portfolio's own frequency, appropriate to the mandate's style, and chosen before the period it will be used to judge.

Technical definition

The selection criteria are substantive, not formal: constituents and weights must be unambiguous; the reference must be investable, so holding it is a genuine alternative; its return must be measurable over the evaluation period; it must be appropriate to the manager's stated universe and style; and it must be specified in advance. A benchmark chosen after the results are known is not a benchmark but a retrospective justification, because the selection itself encodes the outcome. A wrong reference corrupts every relative measure derived from it.

Academic definition

A specified reference portfolio, investable and determined ex ante, relative to which active return, tracking error and risk-adjusted performance measures are defined.

Mechanism

Every relative performance figure is a difference between two series, so it inherits the properties of both. Change the reference and the active return, the tracking error and the information ratio all change while the portfolio does not. Specifying the reference first is what keeps those measures computed rather than chosen.

In practice

Who uses it
Investment committees, fund selectors, performance analysts, and any manager whose mandate is relative rather than absolute.
Why it matters
It turns a return into an evaluation by naming, in advance, the alternative the investor could have held instead.
Limitations
No published index matches every mandate. Where the opportunity set is unusual a custom reference is required, and its construction then becomes a judgement that can itself be disputed.

Common mistakes

  • Choosing the benchmark after the period being evaluated.
  • Measuring a portfolio against an index it could not have bought.
  • Comparing a concentrated mandate with a broad index and calling the gap skill.

Examples

numeric

A portfolio returns 12.0% in a year while its stated benchmark returns 14.0%. The active return is minus 2.0 points despite a positive absolute return. Measured against a reference that returned 9.0%, the same portfolio would show plus 3.0.

Given
  • portfolio return for the year: 12.0%
  • stated benchmark return for the same year: 14.0%
  • an alternative index returned 9.0%
Steps
  1. active return against the stated benchmark = 12.0% - 14.0% = -2.0 points
  2. active return against the alternative = 12.0% - 9.0% = +3.0 points
the same portfolio is 2.0 points behind or 3.0 points ahead depending only on the reference

Only one of those references was specified in advance. That is the whole reason the criterion exists.

market

A manager whose mandate is limited to large domestic companies is measured against a global index. In a year when the domestic market lags, the shortfall reflects the mandate rather than the manager: the reference fails the appropriateness criterion.

Commonly confused with

Index Investing

An index is something you can hold; a benchmark is a role a reference is given in advance for evaluation. The same index can be either, neither, or both, depending on the mandate.
