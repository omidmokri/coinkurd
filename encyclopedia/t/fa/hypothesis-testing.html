تعریف ساده

رویه‌ای برای پرسیدن اینکه آیا یک نتیجه می‌توانست به‌طور معقول تنها از بخت آمده باشد. می‌تواند توضیحی خسته‌کننده را رد کند؛ نمی‌تواند توضیحی جالب را ثابت کند.

تعریف حرفه‌ای

قاعدهٔ تصمیمی که فرض صفری را می‌پذیرد، حساب می‌کند داده‌های مشاهده‌شده زیر آن چقدر حدی‌اند، و وقتی این حدی‌بودن از آستانه‌ای که پیش‌تر انتخاب شده بگذرد فرض صفر را رد می‌کند. آستانه نرخ بلندمدت ردهای نادرست را کنترل می‌کند، نه درستی هیچ نتیجهٔ تکی را.

تعریف فنی

یک آزمون، فرض صفر، آمارهٔ آزمونی با توزیع معلوم زیر آن فرض، و سطح معناداری آلفا را که احتمال خطای نوع اول را کراندار می‌کند تعیین می‌کند. رد فرض صفر شاهدی برای هیچ جانشین خاصی نیست، و رد نشدن شاهدی بر درستی فرض صفر نیست — ممکن است تنها به این معنا باشد که نمونه توان کافی نداشت. تضمین آلفا به‌ازای هر آزمون برقرار است، پس به‌محض اجرای آزمون‌های بسیار روی یک داده از بین می‌رود.

مکانیزم

منطق آن یک‌طرفه است: احتمال داده به‌شرط فرض صفر را حساب می‌کند، هرگز احتمال فرض صفر به‌شرط داده را. همین نامتقارنی است که روش را برای استفاده ایمن و برای بدنقل‌کردن آسان می‌کند. سطح پنج درصد یعنی یک از هر بیست فرض صفرِ درست به‌شانس رد می‌شود، پس بیست جست‌وجو بیشتر اوقات یک مثبت کاذب می‌سازد.

کاربرد عملی

چه کسانی به‌کار می‌برند
پژوهشگران استراتژی، تحلیلگران عاملی، تیم‌های ریسک که مدلی را اعتبارسنجی می‌کنند، و هر کسی که تصمیم می‌گیرد نتیجهٔ یک بک‌تست ارزش سرمایه دارد یا نه.
چرا مهم است
انضباطی تحمیل می‌کند: نخست توضیح خسته‌کننده را بگو، بعد نشان بده که داده با آن به‌سختی جور می‌شود. بدون این گام، یک بک‌تست سودآور و یک بک‌تست خوش‌شانس یکسان به‌نظر می‌رسند.
محدودیت‌ها
تضمین به‌ازای هر آزمون است. جست‌وجوی استراتژی‌ها تا یکی قبول شود همان مسئلهٔ مقایسه‌های چندگانه است، و آمارهٔ آزمون منتشرشده آن‌وقت هیچ تفسیر معتبری ندارد.

خطاهای رایج

  • رد فرض صفر را اثبات کارکرد استراتژی دانستن.
  • رد نشدن را شاهد نبودِ اثر خواندن.
  • اجرای ده‌ها مشخصه و گزارش تنها همان یکی که قبول شد.

مثال‌ها

numeric

یک استراتژی در ۲۵۰ روز میانگین ۰٫۰۵٪ در روز با انحراف معیار روزانهٔ ۱٫۰٪ دارد. خطای معیار ۰٫۰۶۳٪ است، پس آمارهٔ t برابر ۰٫۷۹ و مقدار p دوطرفه حدود ۰٫۴۳. فرض صفرِ میانگین بازدهی صفر رد نمی‌شود.

داده‌ها
  • sample mean daily return = 0.05%
  • sample standard deviation = 1.0%
  • n = 250, so df = 249
  • null hypothesis: true mean = 0
  • returns assumed independent and identically distributed
مراحل
  1. standard error = 1.0 / sqrt(250) = 0.063246%
  2. t = 0.05 / 0.063246 = 0.7906
  3. two-sided p from the t distribution with 249 df = 0.4299
t = 0.79, p = 0.43; the null is not rejected at any conventional level

Verified numerically. Not rejecting does not mean the edge is zero. A true daily edge of 0.05% against a 1.0% standard deviation reaches the 5% threshold only around n = 1,540 on average, and is detected with 80% probability only around n = 3,140.

market

پژوهشگری بیست قاعدهٔ بی‌ربط را در سطح ۵٪ آزمون می‌کند. حتی اگر همهٔ قاعده‌ها بی‌ارزش باشند، احتمال اینکه دست‌کم یکی قبول شود ۶۴٪ است. با صد قاعده ۹۹٫۴٪. برندهٔ آن‌وقت برساختهٔ انتخاب است، نه یک کشف.

مبنای ریاضی

t = \frac{\bar{x} - \mu_0}{s/\sqrt{n}}, \qquad \text{df} = n-1, \qquad \text{reject } H_0 \text{ if } p < \alpha

متغیرها

\bar{x}میانگین نمونهٔ سری مشاهده‌شدهsame unit as the data
\mu_0مقداری که فرض صفر ادعا می‌کند، غالباً صفرsame unit as the data
s/\sqrt{n}خطای معیار میانگین: نوفهٔ نمونه‌گیری در برآوردsame unit as the data
\alphaسطح معناداری: نرخ بلندمدتِ پذیرفته‌شدهٔ ردهای نادرستprobability

روش محاسبه

فرض صفر و جانشین را پیش از نگاه کردن به نتیجه بیان کنید. آلفا را پیش‌تر انتخاب کنید. آمارهٔ آزمون و مقدار p آن را زیر فرض صفر حساب کنید. مقایسه و تصمیم بگیرید. سپس هر آزمونی که اجرا شد را گزارش کنید، نه تنها همان یکی که قبول شد، و اگر آزمون‌های بسیاری اجرا شد آستانه را تعدیل کنید یا نتیجه را اکتشافی بدانید نه تأییدشده.

مثال حل‌شده

داده‌ها
  • sample mean = 0.05% per day
  • s = 1.0% per day
  • n = 250
  • H0: true mean = 0, two-sided, alpha = 0.05
مراحل
  1. standard error = 1.0/sqrt(250) = 0.063246
  2. t = 0.05/0.063246 = 0.7906
  3. p with 249 degrees of freedom = 0.4299
  4. 0.4299 > 0.05
Do not reject H0. The observed mean is well inside what a zero-edge strategy produces by chance over 250 days.

تفسیر نتیجه

یک رد می‌گوید داده غیرعادی می‌بود اگر فرض صفر درست بود. نمی‌گوید فرض صفر با احتمال مشخصی نادرست است، و هیچ نمی‌گوید کدام جانشین برقرار است. رد نشدن می‌گوید نمونه نتوانست فرض صفر را از جانشین‌ها تفکیک کند — نبودِ شاهد، نه شاهدِ نبود.

فرض‌ها

  • The test statistic's distribution under the null must be correct; the t form shown assumes independent, identically distributed observations, which autocorrelated and volatility-clustered return series violate.
  • Alpha must be fixed before the data are examined, and the null must be stated before the result is seen.
  • The stated error rate applies to a single pre-specified test. Under many tests on the same data the family-wise rate is far higher and must be controlled explicitly.
محدودیت‌های فرمول
  • It cannot assign a probability to a hypothesis. That requires a prior and a Bayesian framework, which is a different procedure answering a different question.
  • Statistical significance is not economic significance: a tiny edge can be significant on a long sample and still vanish under transaction costs.
