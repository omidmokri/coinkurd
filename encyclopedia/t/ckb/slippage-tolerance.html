پێناسەی ساکار

خراپترین نرخ کە ڕازی دەبیت پێی، پێش ئەوەی ئاڵوگۆڕ هەڵبوەشێت. نزم دابنێی لەوانەیە مامەڵە ئەنجام نەدرێت؛ بەرز دابنێی لەوانەیە زۆر خراپتر لە نرخی ڕاگەیەنراو پڕ بکرێتەوە.

پێناسەی پیشەیی

سنوورێک کە لە گواستنەوەی ئاڵوگۆڕدا وەک کەمترین دەرئەنجام دەنووسرێت و گرێبەست دەبێت بیگەیەنێت، ئەگەرنا گواستنەوەکە دەگەڕێتەوە. بەرامبەر گۆڕانی دۆخی حەوز لە نێوان نرخدان و جێبەجێکردن دەپارێزێت، جا لە ڕێڕەوی ئاسایی بێت یان لە ڕیزکردنی بەئەنقەستی بلۆک.

پێناسەی تەکنیکی

ئەم پارامەترە کەمترین دەرئەنجامی پەسەندکراو دیاری دەکات، زۆرتر دەرئەنجامی ڕاگەیەنراو لە یەک کەم سنوور. سنوورێکە نەک ئامانج: هەر بڕێک لە نێوان نرخی ڕاگەیەنراو و ئەو سنووردا بێ‌دەنگ جێبەجێ دەبێت، بۆیە ئەو سنوورە هەمان زۆرترین بەهایەیە کە هێرشبەر دەتوانێت بە مامەڵەکردن لە هەردوو لای داواکارییەکەوە بەریبات. بەرزکردنەوەی بۆ تێپەڕکردنی گواستنەوەیەکی سەرنەکەوتوو، هەر ئەو پەنجەرە پان دەکاتەوە کە هێرشی ساندویچ پێویستی پێیەتی؛ خودی سەرنەکەوتن کرێی گاز دەبات نەک سەرمایە.

میکانیزم

ئاڵوگۆڕی سەر تۆڕ بەرامبەر دۆخێک نرخ دەکرێت کە تا کاتی جێبەجێبوون چیتر بوونی نییە، چونکە گواستنەوەی تر لە نێواندا دادەنیشن و ڕیزکردن لەلایەن دروستکەری بلۆکەوە دیاری دەکرێت. سنوورەکە ئەو نادڵنیایی دەکات بە بنکەیەکی سەخت: یان گرێبەست لانیکەم ئەو بنکە دەگەیەنێت، یان هیچ ڕوو نادات. هەر شتێک سەروو ئەو بنکە بێت زیادەیەکە کە بەکارهێنەر پێشتر ڕازی بووە لەدەستی بدات.

بەکارهێنانی پراکتیکی

کێ بەکاری دەهێنێت
هەر کەسێک کە لەسەر تۆڕێکی گشتی ئاڵوگۆڕ دەنێرێت، ڕێنیشاندەرەکان کە ئەم پارامەترە بە خۆکاری ڕێک دەخەن، و تیمەکان کە سیاسەتی جێبەجێکردنی داواکاری لەسەر تۆڕ دەنووسن.
بۆچی گرنگە
تاکە ئامرازی لای بەکارهێنەرە بۆ دیاریکردنی خراپترین جێبەجێکردنی ئەگەری، و هێڵی بەرگری سەرەکییە بەرامبەر بردنی بەها لە دەوری داواکاری.
سنوورەکان
زیان سنووردار دەکات بەڵام ڕێی لێ ناگرێت، و ناتوانێت جوڵەی نرخی ئاسایی لە جوڵەی دیزاینکراو جیا بکاتەوە. سەبارەت بەو کرێ و کاریگەری نرخەی پێشتر لە نرخەکەدایە هیچ ناکات.

هەڵەکانی باو

  • بەرزکردنەوەی سنوور تا ئەو کاتەی گواستنەوە ئەنجام بدرێت.
  • بەکارهێنانی یەک ڕێژەی بنەڕەتی بۆ جووتی لەنگەرگیر و تۆکنی تەنک پێکەوە.
  • گەڕانەوەی ئاڵوگۆڕ وەک تێکچوونی پڕۆتۆکۆل خوێندنەوە نەک کارکردنی سنوورەکە.

نموونەکان

numeric

ئاڵوگۆڕێک بە دەرئەنجامی ڕاگەیەنراوی ٩٬٨٧١.٦ نرخ دەکرێت. بە سنووری ٠.٥ لەسەد، گرێبەست دەبێت لانیکەم ٩٬٨٢٢.٢ بگەیەنێت، بۆیە خراپترین جێبەجێکردنی پەسەندکراو نزیکەی ٤٩.٤ یەکە خوارتر لە نرخەکەیە. بە ٥ لەسەد، نزیکەی ٤٩٣.٦ یەکە خوارتر.

داتاکان
  • quoted output = 9,871.6
  • tolerance s = 0.5%
  • alternative tolerance s = 5%
هەنگاوەکان
  1. floor at 0.5% = 9,871.6 x (1 - 0.005) = 9,822.24
  2. give-up at 0.5% = 9,871.6 - 9,822.24 = 49.36
  3. floor at 5% = 9,871.6 x (1 - 0.05) = 9,378.02
  4. give-up at 5% = 493.58
The tolerance multiplies directly into the value the user has pre-agreed to forgo.

A fill anywhere above the floor is accepted without warning, so the floor is the figure to reason about, not the quote.

market

ئاڵوگۆڕێک لە حەوزێکی تەنکدا بە سنووری ٠.١ لەسەد دوو جار دەگەڕێتەوە چونکە مامەڵەی تر پێشتر دادەنیشن. بەرزکردنەوەی سنوور بۆ ٥ لەسەد سەرکەوتووی دەکات، و هەروەها جێبەجێکردنێکی خراپتر بۆ هەر کەسێک کە بتوانێت ڕیزی بلۆک دیاری بکات هەرزان دەکات.

بنەمای ماتماتیکی

\Delta y_{\min} = \widehat{\Delta y}\,(1 - s)

گۆڕاوەکان

\Delta y_{\min}کەمترین دەرئەنجام کە گرێبەست دەبێت بگەیەنێت ئەگەرنا دەگەڕێتەوەtoken units
\widehat{\Delta y}دەرئەنجامی ڕاگەیەنراو بەپێی دۆخی حەوز لە کاتی دروستکردنی گواستنەوەtoken units
sسنووری خلیسکان کە بەکارهێنەر دیاری دەکاتfraction

ڕێبازی ژمێریاری

دەرئەنجامی چاوەڕوانکراو لە دۆخی حەوز لە کاتی دروستکردندا بژمێرە، لە یەک کەم سنوور بدە، و ئەنجامەکە وەک کەمترین دەرئەنجام لە گواستنەوەدا بنووسە. لە کاتی جێبەجێکردندا گرێبەست دەرئەنجامی ڕاستەقینە لەگەڵ ئەو بنکە بەراورد دەکات و ئەگەر کەمتر بوو دەیگەڕێنێتەوە؛ ئەمە کرێی گاز دەبات بەڵام باڵانس دەست‌نەخراو دەهێڵێتەوە.

نموونەی کرابوو

داتاکان
  • quoted output = 9,871.6 units
  • s = 0.005
هەنگاوەکان
  1. 1 - s = 0.995
  2. 9,871.6 x 0.995 = 9,822.24
Minimum output 9,822.24; the transaction reverts below that.

لێکدانەوە

ئەم ژمارە خراپترین دۆخە کە بەکارهێنەر پێشتر مۆڵەتی داوە، نەک ئەنجامی چاوەڕوانکراو. ڕاستەکە ئەوەیە هەر ئەمە وەک نرخی پلانکراو بگیرێت، چونکە هەر جێبەجێکردنێک لە نێوان بنکە و نرخی ڕاگەیەنراودا بەبێ ئاگادارکردنەوە پەسەند دەکرێت.

گریمانەکان

  • The limit is enforced on the output amount by the swap contract itself. Some routers instead express it as a maximum input for an exact-output swap, which is the same bound written the other way round.
  • The quote is taken from the pool state at build time; a stale quote makes the floor stale too.
سنووری فۆرموڵ
  • The bound caps the loss per transaction but says nothing about how often the fill lands near the floor rather than near the quote.
  • It offers no protection against the fee and price impact already contained in the quote, nor against a malicious token contract.
  • Protocol front ends choose different defaults and some adjust them automatically, so a quoted default is not a standard.
