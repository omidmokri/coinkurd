پێناسەی ساکار

ڕێوشوێنێک بۆ پرسینی ئەوەی ئایا ئەنجامێک دەکرا بە شێوەیەکی لۆژیکی تەنها لە بەختەوە هاتبا. دەتوانێت ڕوونکردنەوەیەکی بێ‌تام ڕەت بکاتەوە؛ ناتوانێت ئەوی سەرنجڕاکێش بسەلمێنێت.

پێناسەی پیشەیی

یاسایەکی بڕیار کە گریمانەیەکی سفر دەپەسێنێت، دەژمێرێت داتای بینراو لە ژێر ئەودا چەند سنووریە، و کاتێک ئەو سنووری‌بوون لە سنوورێکی پێشوەخت هەڵبژێردراو تێپەڕ بوو گریمانەی سفر ڕەت دەکاتەوە. سنوورەکە ڕێژەی درێژخایەنی ڕەتکردنەوەی هەڵە کۆنترۆڵ دەکات، نەک ڕاستی هیچ ئەنجامێکی تاک.

پێناسەی تەکنیکی

تاقیکردنەوەیەک گریمانەی سفر، ئامارێکی تاقیکردنەوە بە دابەشبوونی زانراو لە ژێر ئەو گریمانە، و ئاستی گرنگی ئاڵفا کە ئەگەری هەڵەی جۆری یەکەم سنووردار دەکات دیاری دەکات. ڕەتکردنەوەی گریمانەی سفر بەڵگە نییە بۆ هیچ جێگرەوەیەکی دیاریکراو، و ڕەت‌نەکردنەوە بەڵگە نییە بۆ ڕاستی گریمانەی سفر — لەوانەیە تەنها مانای ئەوە بێت کە نمونە هێزی پێویستی نەبوو. گەرەنتی ئاڵفا بۆ هەر تاقیکردنەوەیەک بەردەوامە، بۆیە هەر کە چەندین تاقیکردنەوە لەسەر یەک داتا ئەنجام درا لەناو دەچێت.

میکانیزم

لۆژیکەکەی یەک‌ئاراستەیە: ئەگەری داتا دەژمێرێت بە مەرجی گریمانەی سفر، هەرگیز ئەگەری گریمانەی سفر بە مەرجی داتا نا. هەر ئەم ناهاوسەنگییە ئەوەیە کە ڕێبازەکە بۆ بەکارهێنان سەلامەت و بۆ هەڵە‌گێڕانەوە ئاسان دەکات. ئاستی پێنج لەسەدی یانی یەک لە هەر بیست گریمانەی سفری ڕاست بە بەخت ڕەت دەکرێتەوە، بۆیە بیست گەڕان زۆرتر لە نیوەی کاتەکان ئەرێنییەکی هەڵە دروست دەکەن.

بەکارهێنانی پراکتیکی

کێ بەکاری دەهێنێت
توێژەرانی ستراتیژی، شیکەرانی فاکتەری، تیمەکانی مەترسی کە مۆدێلێک پشتڕاست دەکەنەوە، و هەر کەسێک کە بڕیار دەدات ئەنجامی بەکتێستێک شایەنی سەرمایەیە یان نا.
بۆچی گرنگە
ڕێکخستنێک دەسەپێنێت: سەرەتا ڕوونکردنەوەی بێ‌تام بڵێ، پاشان نیشان بدە کە داتا بە ئاسانی لەگەڵی ناگونجێت. بەبێ ئەو هەنگاوە، بەکتێستێکی قازانجدار و بەکتێستێکی بەختەوەر وەک یەک دەردەکەون.
سنوورەکان
گەرەنتی بۆ هەر تاقیکردنەوەیەکە. گەڕان بەدوای ستراتیژیدا تا یەکێک دەرباز بێت هەمان کێشەی بەراوردی فرەیە، و ئەو ئاماری بڵاوکراوە ئەوکات هیچ لێکدانەوەیەکی دروستی نییە.

هەڵەکانی باو

  • ڕەتکردنەوەی گریمانەی سفر وەک سەلماندنی کارکردنی ستراتیژی دابنێی.
  • ڕەت‌نەکردنەوە وەک بەڵگەی نەبوونی کاریگەری بخوێنیتەوە.
  • جێبەجێکردنی دەیان تایبەتمەندی و ڕاگەیاندنی تەنها ئەوەی دەرباز بوو.

نموونەکان

numeric

ستراتیژێک لە ٢٥٠ ڕۆژدا تێکڕای ٠.٠٥٪ لە ڕۆژێک بە لادانی ستانداردی ڕۆژانەی ١.٠٪ هەیە. هەڵەی ستاندارد ٠.٠٦٣٪ـە، بۆیە ئاماری t دەکاتە ٠.٧٩ و بەهای p ـی دوولا نزیکەی ٠.٤٣. گریمانەی سفری تێکڕای ڕێژەی گەڕانەوەی سفر ڕەت ناکرێتەوە.

داتاکان
  • sample mean daily return = 0.05%
  • sample standard deviation = 1.0%
  • n = 250, so df = 249
  • null hypothesis: true mean = 0
  • returns assumed independent and identically distributed
هەنگاوەکان
  1. standard error = 1.0 / sqrt(250) = 0.063246%
  2. t = 0.05 / 0.063246 = 0.7906
  3. two-sided p from the t distribution with 249 df = 0.4299
t = 0.79, p = 0.43; the null is not rejected at any conventional level

Verified numerically. Not rejecting does not mean the edge is zero. A true daily edge of 0.05% against a 1.0% standard deviation reaches the 5% threshold only around n = 1,540 on average, and is detected with 80% probability only around n = 3,140.

market

توێژەرێک بیست یاسای بێ‌پەیوەندی لە ئاستی ٥٪دا تاقی دەکاتەوە. تەنانەت ئەگەر هەموو یاساکان بێ‌بەها بن، ئەگەری ئەوەی لانیکەم یەکێکیان دەرباز بێت ٦٤٪ـە. بە سەد یاسا ٩٩.٤٪ـە. ئەوکات براوەکە دەستکردی هەڵبژاردنە، نەک دۆزینەوە.

بنەمای ماتماتیکی

t = \frac{\bar{x} - \mu_0}{s/\sqrt{n}}, \qquad \text{df} = n-1, \qquad \text{reject } H_0 \text{ if } p < \alpha

گۆڕاوەکان

\mu_0ئەو بەهایەی گریمانەی سفر بانگەشەی دەکات، زۆرتر سفرsame unit as the data
s/\sqrt{n}هەڵەی ستانداردی تێکڕا: ژاوەژاوی نمونەگرتن لە خەمڵاندنداsame unit as the data
\alphaئاستی گرنگی: ڕێژەی درێژخایەنی پەسەندکراوی ڕەتکردنەوەی هەڵەprobability

ڕێبازی ژمێریاری

گریمانەی سفر و جێگرەوە پێش سەیرکردنی ئەنجام بڵێ. ئاڵفا پێشوەخت هەڵبژێرە. ئاماری تاقیکردنەوە و بەهای p ـی لە ژێر گریمانەی سفردا بژمێرە. بەراورد بکە و بڕیار بدە. پاشان هەموو ئەو تاقیکردنەوەی جێبەجێکرا ڕابگەیەنە، نەک تەنها ئەوەی دەرباز بوو، و ئەگەر زۆر جێبەجێکرابوو سنوورەکە ڕاست بکەوە یان ئەنجامەکە بە گەڕانی سەرەتایی دابنێ نەک پشتڕاستکراو.

نموونەی کرابوو

داتاکان
  • sample mean = 0.05% per day
  • s = 1.0% per day
  • n = 250
  • H0: true mean = 0, two-sided, alpha = 0.05
هەنگاوەکان
  1. standard error = 1.0/sqrt(250) = 0.063246
  2. t = 0.05/0.063246 = 0.7906
  3. p with 249 degrees of freedom = 0.4299
  4. 0.4299 > 0.05
Do not reject H0. The observed mean is well inside what a zero-edge strategy produces by chance over 250 days.

لێکدانەوە

ڕەتکردنەوەیەک دەڵێت داتا نا‌ئاسایی دەبوو ئەگەر گریمانەی سفر ڕاست بوایە. نەدەڵێت گریمانەی سفر بە ئەگەرێکی دیاریکراو هەڵەیە، و هیچ نەدەڵێت کام جێگرەوە ڕاستە. ڕەت‌نەکردنەوە دەڵێت نمونە نەتوانی گریمانەی سفر لە جێگرەوەکان جیا بکاتەوە — نەبوونی بەڵگە، نەک بەڵگەی نەبوون.

گریمانەکان

  • The test statistic's distribution under the null must be correct; the t form shown assumes independent, identically distributed observations, which autocorrelated and volatility-clustered return series violate.
  • Alpha must be fixed before the data are examined, and the null must be stated before the result is seen.
  • The stated error rate applies to a single pre-specified test. Under many tests on the same data the family-wise rate is far higher and must be controlled explicitly.
سنووری فۆرموڵ
  • It cannot assign a probability to a hypothesis. That requires a prior and a Bayesian framework, which is a different procedure answering a different question.
  • Statistical significance is not economic significance: a tiny edge can be significant on a long sample and still vanish under transaction costs.
