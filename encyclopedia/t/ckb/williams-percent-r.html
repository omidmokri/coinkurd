پێناسەی ساکار

ژمارەیەک لە کەمی ١٠٠ بۆ سفر کە نیشان دەدات نرخی داخستن لەکوێی نێوان بەرزترین لووتکە و نزمترین بنکەی n خولی ڕابردوو دادەنیشێت.

پێناسەی پیشەیی

پێوەرێکی لەرزۆکی شوێنی ناو بوار. دووری لە بەرزترین لووتکەی پەنجەرە بۆ نرخی داخستنی ئێستا وەک بەشێک لە تەواوی بواری لووتکە بۆ بنکە دەپێوێت و وەک ڕێژەیەکی نەرێنی ڕادەگەیەنێت: سفر لە سەرەوەی بوار و کەمی ١٠٠ لە بنکە. چوارچێوەی مرجەعی باو ١٤ـە.

پێناسەی تەکنیکی

ویلیامز %R و %Kی خاوی پێوەری ستۆکاستیک یەک بڕگەن لەسەر دوو پێوەر: %R دەکاتە %K کەم ١٠٠. یەکێکیان داخستن لە سەرەوەی بوار کەم دەکات و ئەوی تر بنکەی بوار لە داخستن، و هەردووکیان بەسەر هەمان بوار دابەش دەکەن. لە کردەوەدا تاکە جیاوازییان ئەوەیە کە %R بە نەریت خاو دەکێشرێت و %K زۆرتر هێواشکراو، و ئەوەی سنوورەکانی نەریتییان جیاوازە.

میکانیزم

ئەم پێوەرە شوێنێکە نەک ڕێژەیەک: دەڵێت نرخی داخستن بەرامبەر هەموو ئەوەی بازاڕ لەو پەنجەرەدا پێی گەیشتووە لەکوێ تەواو بووە. ژمارەی نزیک سفر مانای ئەوەیە داخستن لە سەرەوەی هەمان پەنجەرەیە، و ئەمە بە حوکمی پێناسە هەر کاتێک لووتکەیەکی نوێ دروست بکرێت ڕوودەدات — بۆیە لە ئاراستەدا، پێوەرەکە بە سنووری خۆی دەلکێت و لەوێ دەمێنێتەوە، وەک هەر پێوەرێکی شوێنی ناو بوار کە ناچارە.

بۆچی گرنگە

سنوورەکان

هەڵەکانی باو

  • %R و ستۆکاستیک وەک دوو پشتڕاستکردنەوەی سەربەخۆ دابنێی.
  • کڕینی هەر ژمارەیەکی خواروو کەمی ٨٠ لە ئاراستەی داشکاودا.
  • بەراوردکردنی %Rی خاوی ١٤ خولی لەگەڵ ستۆکاستیکی هێواشی هێواشکراو.

نموونەکان

market

لە سەرکەوتنێکی بەردەوامدا، %R هەفتەکان لە نێوان سفر و کەمی ٢٠ دادەنیشێت، چونکە هەر داخستنێک نزیک سەرەوەی پەنجەرەی جوڵاوە. فرۆشتنی هەر ژمارەیەکی سەروو کەمی ٢٠ مانای فرۆشتنی هەر لووتکەیەکی نوێیە لە ئاراستەدا.

numeric

لەو پەنجەرەدا بەرزترین لووتکە ١٢٠، نزمترین بنکە ١٠٠ و نرخی داخستن ١٠٤ـە. ‏%R دەکاتە کەمی ٨٠. ‏%Kی خاوی ستۆکاستیک لەسەر هەمان سێ ژمارە ٢٠ـە، کە تەواو %R زیاد ١٠٠ـە.

داتاکان
  • highest high over n periods = 120
  • lowest low over n periods = 100
  • current close = 104
هەنگاوەکان
  1. range = 120 - 100 = 20
  2. %R = (120 - 104) / 20 x (-100) = (16 / 20) x (-100) = -80
  3. %K = (104 - 100) / 20 x 100 = 20
  4. check: %R = %K - 100 = 20 - 100 = -80
%R = -80, and the identity with raw %K holds exactly.

The identity holds for the unsmoothed %K only. A slow stochastic smooths %K, so its plotted line no longer matches %R plus 100.

بنەمای ماتماتیکی

\%R_n = \frac{HH_n - C_t}{HH_n - LL_n} \times (-100) = \%K_n - 100, \qquad \%K_n = \frac{C_t - LL_n}{HH_n - LL_n} \times 100

ڕێبازی ژمێریاری

بەرزترین لووتکە و نزمترین بنکەی n خولی ڕابردوو بدۆزە. نرخی داخستنی ئێستا لە بەرزترین لووتکە کەم بکە، بەسەر جیاوازی بەرزترین لووتکە و نزمترین بنکە دابەش بکە، و لە کەمی ١٠٠ بدە. ئەنجام لە نێوان کەمی ١٠٠ و سفردایە. زیادکردنی ١٠٠ بۆی، %Kی خاوی ستۆکاستیکی هەمان پەنجەرە دەدات.

نموونەی کرابوو

داتاکان
  • HH over n periods = 120
  • LL over n periods = 100
  • close = 104
هەنگاوەکان
  1. range = 120 - 100 = 20
  2. (120 - 104) / 20 = 0.8
  3. %R = 0.8 x (-100) = -80
  4. %K = (104 - 100) / 20 x 100 = 20, so %K - 100 = -80
%R = -80, identical to raw %K minus 100.

لێکدانەوە

ئەم ژمارەیە شوێنێکە لە ناو بواری سەرەوەترینی جوڵاو. سفر مانای ئەوەیە داخستن لەسەر لووتکەی پەنجەرەیە و کەمی ١٠٠ مانای ئەوەیە لەسەر بنکەیەتی. هیچ لەسەر قەبارەی بوار نادەڵێت، تەنها لەسەر ئەوەی داخستن لەکوێی ناویدا تەواو بووە.

گریمانەکان

  • A lookback of 14 is the common default; any other length changes every value and the thresholds with it.
  • Williams %R is conventionally plotted raw, with no smoothing. The identity %R = %K - 100 holds against the unsmoothed fast %K only, not against a smoothed slow stochastic.
  • If the highest high equals the lowest low, the ratio is undefined. Implementations differ: some return 0, some minus 100, some carry the previous value forward.
  • The window extremes are single observations, not averages, so one spike bar sets the denominator for n periods afterwards.
سنووری فۆرموڵ
  • Bounded, so it pins at its extremes in a trend; a reading of minus 2 means a new high is being made, not that a reversal is near.
  • It contains the same information as the stochastic raw %K, so treating the two as independent signals double-counts one measurement.
  • Because the denominator is built from two extreme bars, a single outlier compresses the oscillator for the whole remaining window.
