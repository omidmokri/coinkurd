پێناسەی ساکار

ئەو پۆرتفۆلیۆ یان ئیندێکسەی ئەنجام بەرامبەری دەپێورێت. بەبێ ئەو، ڕێژەی گەڕانەوە تەنها ژمارەیەکە و هیچ نەدەڵێت کە باش بووە یان نا.

پێناسەی پیشەیی

مرجعێکی دیاریکراو و وەبەرهێنانی‌کراو کە ڕێژەی گەڕانەوە و مەترسی پۆرتفۆلیۆ بەرامبەری هەڵسەنگێنرێت. پێوەرێکی بەکارهاتوو لە بەش و کێشەکاندا بێ‌ناڕوونی، وەبەرهێنانی‌کراو، پێوراو بە هەمان دووبارەیی پۆرتفۆلیۆ، گونجاو لەگەڵ شێوازی ئەرکەکە، و پێش ئەو ماوەی بۆ هەڵسەنگاندنی بەکاردێت هەڵبژێردراوە.

پێناسەی تەکنیکی

پێوەرەکانی هەڵبژاردن ناوەڕۆکین نەک فۆرمی: بەش و کێشەکان دەبێت بێ‌ناڕوونی بن؛ مرجع دەبێت وەبەرهێنانی‌کراو بێت تا هەڵگرتنی بەدیلێکی ڕاستەقینە بێت؛ ڕێژەی گەڕانەوەی دەبێت لە ماوەی هەڵسەنگاندندا بپێورێت؛ دەبێت گونجاو بێت لەگەڵ جیهانی سامان و شێوازی ڕاگەیەنراوی بەڕێوەبەر؛ و دەبێت پێشوەخت دیاری کرابێت. پێوەرێک کە دوای زانینی ئەنجامەکان هەڵبژێردرێت پێوەر نییە بەڵکو پاساوی پاشەکیشە، چونکە خودی هەڵبژاردن ئەنجامەکە لە خۆی دەگرێت. مرجعی هەڵە هەر پێوەرێکی بەراوردی لێی دەرچوو تێک دەدات.

میکانیزم

هەر ژمارەیەکی کارایی بەراوردی جیاوازی نێوان دوو زنجیرەیە، بۆیە خاسیەتی هەردووکیان بە میرات دەبات. مرجع بگۆڕە و ڕێژەی گەڕانەوەی چالاک، هەڵەی بەدواداچوون و ڕێژەی زانیاری هەموو دەگۆڕێن لە کاتێکدا پۆرتفۆلیۆ نەگۆڕاوە. دیاریکردنی مرجع پێشوەخت ئەو شتەیە کە ئەم پێوەرەکان دەپارێزێت وەک ژمێردراو نەک هەڵبژێردراو.

بەکارهێنانی پراکتیکی

کێ بەکاری دەهێنێت
لیژنەی وەبەرهێنان، هەڵبژێرانی سندوق، شیکەرانی کارایی، و هەر بەڕێوەبەرێک کە ئەرکەکەی بەراوردییە نەک ڕەها.
بۆچی گرنگە
ڕێژەی گەڕانەوە دەکات بە هەڵسەنگاندن، بە ناوبردنی پێشوەختی ئەو بەدیلەی وەبەرهێنەر دەتوانی لە جیاتی هەڵبگرێت.
سنوورەکان
هیچ ئیندێکسێکی بڵاوکراوە لەگەڵ هەموو ئەرکێکدا ناگونجێت. لەو جێگەی کۆمەڵەی هەلەکان نامۆیە مرجعێکی داشتەکراو پێویستە، و دروستکردنی ئەو خۆی دەبێتە بڕیارێکی دەمەقاڵەکراو.

هەڵەکانی باو

  • هەڵبژاردنی پێوەر دوای ئەو ماوەی هەڵسەنگێنرێت.
  • پێوانی پۆرتفۆلیۆ بەرامبەر ئیندێکسێک کە نەیدەتوانی بیکڕێت.
  • بەراوردی ئەرکێکی چەقبەستوو لەگەڵ ئیندێکسی فراوان و شارەزایی ناونانی بۆشاییەکە.

نموونەکان

numeric

پۆرتفۆلیۆیەک لە ساڵێکدا ١٢.٠٪ ڕێژەی گەڕانەوە دەدات لە کاتێکدا پێوەری ڕاگەیەنراوی ١٤.٠٪. ڕێژەی گەڕانەوەی چالاک نەرێنی ٢.٠ خاڵە، سەرەڕای ڕێژەی ڕەهای ئەرێنی. بەرامبەر مرجعێک بە ڕێژەی ٩.٠٪، هەمان پۆرتفۆلیۆ ئەرێنی ٣.٠ نیشان دەدا.

داتاکان
  • portfolio return for the year: 12.0%
  • stated benchmark return for the same year: 14.0%
  • an alternative index returned 9.0%
هەنگاوەکان
  1. active return against the stated benchmark = 12.0% - 14.0% = -2.0 points
  2. active return against the alternative = 12.0% - 9.0% = +3.0 points
the same portfolio is 2.0 points behind or 3.0 points ahead depending only on the reference

Only one of those references was specified in advance. That is the whole reason the criterion exists.

market

بەڕێوەبەرێک کە ئەرکەکەی بە کۆمپانیای گەورەی ناوخۆ سنووردارە، بەرامبەر ئیندێکسێکی جیهانی دەپێورێت. لە ساڵێکدا کە بازاڕی ناوخۆ دوا دەکەوێت، کەمییەکە ئەرکەکە دەنوێنێت نەک بەڕێوەبەر: مرجع لە پێوەری گونجاویدا سەرناکەوێت.

زاراوەی پەیوەندیدار

related
هەڵەی شوێنکەوتن ئەلفا بێتا وەبەرهێنانی ئیندێکسی بەڕێوەبردنی چالاک بەرامبەر ناچالاک ڕێژەی زانیاری بەڵگەنامەی سیاسەتی وەبەرهێنان ڕێژەی گەڕانەوەی پارە-کێشدار پۆرتفۆلیۆی ناوەند و پەیک دابەشکردنی ستراتیژی سامان دابەشکردنی تاکتیکی سامان
زۆر جار تێکەڵ دەکرێت لەگەڵ

وەبەرهێنانی ئیندێکسی

ئیندێکس شتێکە کە دەکرێت هەڵبگیرێت؛ پێوەری بنچینەیی ڕۆڵێکە کە پێشوەخت بۆ هەڵسەنگاندن بە مرجعێک دەدرێت. هەمان ئیندێکس بەپێی ئەرکەکە دەکرێت هەر یەکێکیان، هیچیان، یان هەردووکیان بێت.
