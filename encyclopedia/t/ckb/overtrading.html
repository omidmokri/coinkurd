پێناسەی ساکار

مامەڵەکردن زۆر زیاتر لەوەی پلانت دەیەوێت. هەر مامەڵەیەک تێچوویەکی هەیە، بۆیە ژمارەی زۆر بە بێ‌دەنگی هەژمارەکە دەخوات، تەنانەت کاتێک هەر بڕیارێک بە تەنها لۆژیکی دیارە.

پێناسەی پیشەیی

شێوەیەک کە تێیدا ژمارەی مامەڵە زۆر بەرزتر دەبێت لەوەی بەرتەری ستراتیژی ڕەوای دەکات، زۆرتر دوای زیانێک کە دەبێت قەرەبوو بکرێت یان جوڵەیەک کە لەدەست چووە. زیانەکە ژمێریارییە: کرێ، سپرێد و خلیسکانی نرخ لە هەر چوون‌و‌هاتنێکدا دەدرێن و بە شێوەی لێکدان کۆدەبنەوە.

پێناسەی تەکنیکی

زیادەڕۆیی لە مامەڵەکردن باشترە بە تێچوو پێناسە بکرێت نەک بە هەست. لە هەر چوون‌و‌هاتنێکدا مامەڵەکار کرێ دەدات، بەناو سپرێددا دەپەڕێت، و خلیسکانی نرخ بەرامبەر قووڵی بەردەست هەڵدەگرێت؛ لە پۆزیشنی هەمیشەیی لیڤەرجدار، فاندینگیش لەگەڵ کاتی ڕاگرتن کۆ دەبێتەوە. لەبەر ئەوەی ئەم تێچووانە لەسەر هەر مامەڵەیەک دەبردرێن، ئەو بەشی ماوەی سەرمایە بە ژمارەی چوون‌و‌هاتنەکان بە شێوەی هەندەسی دادەبەزێت، بۆیە تێچووێکی بچووکی هەر مامەڵە لە خێرایی بەرزدا دەبێتە داشکانێکی ساڵانەی گەورە.

میکانیزم

تێچوو لەسەر هەر مامەڵەیەک دەبردرێت و بەرتەری لەسەر هەر هەلێک دروست دەبێت، بۆیە بەرزکردنی خێرایی بەبێ بەرزکردنی بەرتەری تەنها بەشی تێچوو دەگۆڕێت. هەر چوون‌و‌هاتنێک یەک جار سپرێد، دوو جار کرێ و هەر خلیسکانێک کە دەفتەری داواکاری بسەپێنێت دەدات؛ ئەم کەمکردنەکان لێکدانن نەک کۆکردن، و هەر ئەمەیە کە هێڵی سەرمایە بەبێ هیچ زیانێکی گەورە بەرەو خوارەوە دەچەمێنێت.

بەکارهێنانی پراکتیکی

کێ بەکاری دەهێنێت
مامەڵەکارانی چالاک، سکاڵپەرەکان، و هەر کەسێک کە تێچووی هەر مامەڵەی بەشێکی بەرچاوی تێکڕای قەبارەی مامەڵەکەی بێت.
بۆچی گرنگە
ژماردنی چوون‌و‌هاتنەکان و تێچووەکان نیگەرانییەکی ناڕوون دەکات بە ژمارەیەکی پێوانەکراو کە بە یاسا بەڕێوە دەبرێت نەک بە ویست.
سنوورەکان
خێرایی بەخۆی هەڵە نییە. بەرتەرییەکی ڕاستەقینەی خێرا، مامەڵەی زۆر ڕەوا دەکات؛ پێناسەکە بەستراوە بە تێچووی هەر مامەڵە بەرامبەر قازانجی چاوەڕوانکراوی هەر مامەڵە.

هەڵەکانی باو

  • پێوانی ئەنجام پێش کەمکردنی تێچوو و فاندینگ.
  • بەرزکردنی خێرایی بۆ قەرەبووکردنی خێراتری زیان.
  • بەراوردکردنی تێچووی هەژمارێکی بچووک لەگەڵ تیمێکی پیشەیی.

نموونەکان

everyday

دوو مامەڵەکار هەمان ئاماژەکان وەردەگرن. یەکێکیان مانگی چوار جار کار دەکات و ئەوی تر چل جار. پێش هەر جیاوازییەکی لێهاتوویی، دووەم دە قات باجی دەرگا داوە.

numeric

بیست چوون‌و‌هاتن لە مانگێکدا بە تێچووی گشتی ٠.١٢ لەسەد بۆ هەر یەکێک، دوای ساڵێک لێکدەری سەرمایەی ٠.٧٥٠ بەجێ دەهێڵێت: داشکانێکی نزیکەی ٢٥ لەسەد، بەبێ تەنانەت یەک مامەڵەی زیانبار.

داتاکان
  • N = 20 round trips per month, 240 per year
  • all-in cost per round trip c = 0.12 percent of position value
  • positions sized at full equity, cost charged on each round trip
  • gross directional result assumed exactly zero
هەنگاوەکان
  1. (1 - 0.0012)^240
  2. = 0.9988^240
  3. = 0.7496
equity multiplier of about 0.750, a cost drag near 25 percent for the year

Illustrative cost assumption, not a quoted fee schedule. Perpetual-contract funding would be charged on top, in proportion to holding time rather than trade count.

ڕێبازی ژمێریاری

سپرێدی بڕدراو لە چوون‌و‌هاتن، هەردوو کرێ و خلیسکانی ڕاستەقینە کۆ بکە بۆ تێچووی هەر چوون‌و‌هاتنێک. پاشان بە شێوەی لێکدان یەک جار بۆ هەر چوون‌و‌هاتنێک جێبەجێی بکە بۆ ئەوەی ڕێڕەوی سەرمایە تەنها بەهۆی تێچوو ببینرێت، پێش زیادکردنی هەر دەرئەنجامی ناخاوێنی مامەڵە.

نموونەی کرابوو

داتاکان
  • c = 0.0012
  • N = 240
هەنگاوەکان
  1. 1 - c = 0.9988
  2. 0.9988^240 = 0.7496
  3. 1 - 0.7496 = 0.2504
equity multiplier 0.750; cost drag about 25 percent

لێکدانەوە

دەربڕینی دووەم ڕێڕەوی سەرمایەیە تەنها بەهۆی تێچوو: ئەوەی خێرایی بە تەنها دەکات کاتێک دەرئەنجامی ناخاوێن سفرە. ئەنجامی ڕاستەقینە ئەمە لە دەرئەنجامی ناخاوێن دەدات، بۆیە ستراتیژی دەبێت لە هەر مامەڵەیەکدا زیاتر لە c بەدەست بهێنێت تا لە سوڕانەوەی خۆی ڕزگار بێت.

گریمانەکان

  • Position size is constant as a fraction of equity, so costs apply to the whole account on each round trip; variable sizing changes the exponent's effect.
  • The spread is crossed on both legs; passive limit fills reduce or remove that component and can earn a rebate on some venues.
  • Perpetual-contract funding is not in c, because it accrues with holding time rather than per transaction.
سنووری فۆرموڵ
  • c is a realised quantity, not a quoted one: slippage is only known after the fill, so pre-trade estimates understate it in thin books.
  • The relation shows cost arithmetic only. It is not a claim about how much any particular trader's returns fall with frequency.
