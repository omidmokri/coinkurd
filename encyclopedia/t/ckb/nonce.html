پێناسەی ساکار

ژمارەیەک کە کانکەر جار لە دوای جار دەگۆڕێت تا یەکێک بدۆزێت کە هاشی بلۆک ئەوەندە بچووک بکات کە لە تاقیکردنەوەی تۆڕ تێپەڕێت.

پێناسەی پیشەیی

لە کانکردنی بەڵگەی کاردا، ئەو خانەی سەردێرە کە بۆ دۆزینەوەی هاشێکی بچووکتر یان یەکسان بە ئامانجی ئێستا دەگۆڕێت. لە زنجیرەکانی هەژمار-بنەمادا هەمان وشە مانایەکی دووەمی بێ‌پەیوەندی هەیە: ژمێرەرێک بۆ هەر هەژمارێک کە ڕیزبەندی گواستنەوەکانی نێرەر دادەنێت و ڕێگە لە دووبارە ناردن دەگرێت.

پێناسەی تەکنیکی

گۆڕاوی گەڕانە، نەک نهێنی. لەبەر ئەوەی هاشی سەردێر وەک پێشبینی‌نەکراو ڕەفتار دەکات، هیچ ستراتیژێک لە گەڕانی خاو باشتر نییە؛ بۆیە ژمارەی هەوڵی چاوەڕوانکراو بە قورسی بەرز دەبێتەوە و نانسی بردراو هیچ زانیارییەکی تێدا نییە. نانسی سەردێری بیتکۆین ٣٢ بیتە، نزیکەی ٤.٣ ملیار هەڵبژاردە، کە ئامێری ئەمڕۆ لە بەشێکی چرکەدا تەواوی دەکات؛ بۆیە کانکەران ئێکسترانانسی کۆینبەیس، مۆری کات و کۆمەڵەی گواستنەوەکانیش دەگۆڕن تا بوارى گەڕان گەورەتر بکەن.

میکانیزم

گەڕان تەنها بۆیە کار دەکات کە هاش پێشبینی‌نەکراوە: گۆڕینی یەک بیتی نانس هەموو دەرئەنجام دەنووسێتەوە، بۆیە هەڵبژاردەکان ڕیز یان پاڵاوتن ناکرێن. هەر ئەمەش کارەکە پێوانەپێکراو و ساختەنەکراو دەکات؛ هەر هەوڵێک تیروپشکێکی سەربەخۆیە و تاکە ڕێگەی نیشاندانی هەوڵی زۆر، پێشکەشکردنی براوەیەکە.

بەکارهێنانی پراکتیکی

کێ بەکاری دەهێنێت
ئەندازیارانی فیرموێر و حەوزی کانکردن، جێبەجێکەرانی پڕۆتۆکۆڵ، و دروستکەرانی جانتای دیجیتاڵ کە دەبێت نانسی هەژمار بە دروستی بەڕێوە ببەن.
بۆچی گرنگە
نانسی کانکردن ئەو شوێنەیە کە تێچووی بەڵگەی کار بەڕاستی لێ دەدرێت؛ نانسی هەژمار ئەوەیە ڕێگە لە دووبارە ناردنی گواستنەوەی واژۆکراو دەگرێت.
سنوورەکان
نانس بە تەنها هیچ دەرناخات. تەنها ئەو هاشەی لێی دەردەچێت بەرامبەر ئامانج مانا هەیە، و نانسی هەژمار پەیوەستە بە پڕۆتۆکۆڵ.

هەڵەکانی باو

  • تێکەڵکردنی نانسی کانکردن لەگەڵ نانسی هەژمار لە ئیتریۆم.
  • وا بزانی نانسی بەختەوەر پێشبینی یان پێش‌ژمێری دەکرێت.
  • دووبارەکردن یان بازدان بەسەر نانسی هەژمار و گیرخواردنی ڕیزی جانتا.

نموونەکان

crypto

حەوزەکە بۆ هەر ئامێرێک بوارى ئێکسترانانسی جیاواز دەدات تا دوو کرێکار هەمان سەردێر دووجار تاقی نەکەنەوە. خانەی نانس بە تەنها زۆر بچووکە بۆ سەرقاڵکردنی فارمێکی پیشەسازی.

numeric

ئەگەر هاش وەک یەکڕەنگ لەسەر ٢٥٦ بیت مۆدێل بکرێت و ئامانج ٢ بە هێزی ٢٢٤ بێت، نزیکەی یەک هەوڵ لە هەر ٤.٣ ملیار سەرکەوتوو دەبێت؛ بۆیە ژمارەی چاوەڕوانکراوی نانسی تاقیکراو هەتا بلۆکێکی دروست نزیکەی ٢ بە هێزی ٣٢ـە.

داتاکان
  • hash output = 256 bits, modelled as uniform
  • target T = 2^224
  • trials are independent
هەنگاوەکان
  1. P(success per attempt) = (T + 1) / 2^256 ~ 2^224 / 2^256 = 2^-32
  2. E[attempts] = 1 / 2^-32 = 2^32
about 4.29 x 10^9 attempts per valid block

An idealisation. Real targets are not powers of two and real hash functions are only assumed to behave uniformly.

بنەمای ماتماتیکی

H(\text{header} \, \| \, \text{nonce}) \le T, \qquad \mathbb{E}[\text{attempts}] = \frac{2^{256}}{T + 1}

گۆڕاوەکان

Hفەنکشنی هاشی زنجیرە، لێرە پوختەی ٢٥٦ بیتیbit string
Tئامانجی ئێستا: گەورەترین بەهای هاش کە وەک دروست پەسەند دەکرێتinteger
\text{nonce}خانەی گەڕانی سەردێرinteger

ڕێبازی ژمێریاری

سەردێر پێک بهێنە، هاشی بکە، و پوختەکە وەک ژمارە لەگەڵ ئامانج بەراورد بکە. ئەگەر گەورەتر بوو، نانس بگۆڕە و دووبارە هاشی بکە. کاتێک بوارى نانس تەواو بوو، ئێکسترانانس، مۆری کات یان کۆمەڵەی گواستنەوەکان بگۆڕە و بەردەوام بە.

نموونەی کرابوو

داتاکان
  • T = 2^224
  • H outputs 256 bits, modelled as uniform
هەنگاوەکان
  1. P = 2^224 / 2^256 = 2^-32
  2. E[attempts] = 2^32
about 4.29 x 10^9 hash attempts expected per valid block

لێکدانەوە

ژمارەی هەوڵی چاوەڕوانکراو لیستی نرخی پڕۆتۆکۆڵە: دەڵێت بلۆکێکی دروست لە ئامانجی ئێستادا دەبێت چەند ژمێرکاری تێبچێت. هەر بلۆکێکی دیاریکراو دەکرێت لە یەکەم هەوڵ بدۆزرێتەوە یان لە هەوڵی تریلیۆنەم.

گریمانەکان

  • The hash function is modelled as a uniform random function; this is an assumption about SHA-256, not a proven property.
  • Attempts are independent, so the search is memoryless and past failures do not raise the next attempt's chance.
  • Written for a 256-bit digest; the exponent changes with the digest length.
سنووری فۆرموڵ
  • The formula gives an expectation, not a schedule: realised times per block are exponentially distributed.
  • It describes the mining nonce only. The account nonce of an account-based chain has no probabilistic content at all.

The expected-attempts formula holds under the random-oracle idealisation of the hash function; this is flagged in math.assumptions because it is a modelling assumption, not a theorem about SHA-256. The word carries two unrelated protocol meanings and the entry keeps them separate, which is the commonest source of confusion in translated glossaries.
