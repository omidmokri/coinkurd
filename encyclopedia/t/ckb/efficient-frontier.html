پێناسەی ساکار

ئەو کۆمەڵە پۆرتفۆلیۆیەی لە هەر ئاستێکی مەترسیدا زۆرترین ڕێژەی گەڕانەوەی چاوەڕوانکراوی بەردەست دەدەن. هەر شتێکی خواری زاڵ‌لێکراوە: بە هەمان مەترسی دەکرا ڕێژەی گەڕانەوەی زیاتر بکڕدرێت.

پێناسەی پیشەیی

لە بۆشایی تێکڕا-ڤاریانسدا، سنووری سەرەوەی کۆمەڵەی کرداری: بۆ هەر ئامانجێکی ڕێژەی گەڕانەوە، ئەو تێکەڵەی کێشانە کە کەمترین ڤاریانسی هەیە. چەماوەیە، لە پۆرتفۆلیۆی کەمترین ڤاریانسی گشتی دەست پێدەکات، و بە زیادکردنی سامانی بێ‌مەترسی کۆمەڵەی کارامەی پەیوەندیدار دەبێتە هێڵێکی ڕاست بە پۆرتفۆلیۆی بەرکەوتەدا.

پێناسەی تەکنیکی

کۆمەڵەی وەڵامی پڕۆگرامێکی پلەدووی سنووردار: کەمکردنی فۆرمی پلەدووی کێشەکان لەگەڵ ماتریکسی کۆڤاریانس، بە مەرجی ئەوەی ڕێژەی گەڕانەوەی کێشدار یەکسان بە ئامانج بێت و کۆی کێشەکان یەک بێت، و کێشانی بەسەر هەموو ئامانجەکانی بەدەستهێنراو. بەبێ سامانی بێ‌مەترسی، ئەم سنوورە لە بۆشایی تێکڕا-لادانی ستاندارددا هایپربۆلایەکە. بە قەرزدان و قەرزگرتنی بێ‌سنوور لە یەک ڕێژە، جێگەی دەگرێتەوە هێڵی دابەشکردنی سەرمایە لەو ڕێژەوە بۆ پۆرتفۆلیۆی بەرکەوتەی بەرزترین ڕێژەی شارپ. متمانەی سنوورەکە زیاتر نییە لە متمانەی داتاکانی هەڵسەنگێندراوی پشتەوەی.

میکانیزم

لەبەر ئەوەی ڤاریانس پلەدوو و ڕێژەی گەڕانەوە هێڵییە لە کێشەکاندا، کۆمەڵەی کرداری لە بۆشایی تێکڕا-لادانی ستاندارددا بە چەماوەیەک سنووردار دەکرێت نەک بە هێڵێکی ڕاست. ئەو چەمانە تەواو لە زاراوەکانی بەرامبەری کۆڤاریانسەوە دێت: هەرچی پەیوەندیەکان کەمتر، سنوورەکە زیاتر بۆ چەپ دەچەمێت و لە لەرزۆکییەکی دیاریکراودا ڕێژەی گەڕانەوەی زیاتر بەردەست دەبێت.

بەکارهێنانی پراکتیکی

کێ بەکاری دەهێنێت
لیژنەی دابەشکردن، توێژەرانی فرە-سامان، و تیمی مەترسی کە پۆرتفۆلیۆی پێشنیارکراو لەسەر یەک تەوەری مەترسی بەراورد دەکەن.
بۆچی گرنگە
ئاڵوگۆڕەکە ئاشکرا دەکات، بۆیە هەر پۆرتفۆلیۆیەکی پێشنیارکراو دەکرێت بەرامبەر باشترین تێکەڵەی هەمان لەرزۆکی دانرێت.
سنوورەکان
سنوورەکانی لە هەڵسەنگاندنی نمونەوە ژمێردراو لە پەنجەرەیەکەوە بۆ ئەوی تر زۆر دەجوڵێن، بۆیە خاڵێک لەسەر چەماوەکە زۆر کەم‌وردترە لەوەی ساوێتی چەماوەکە پیشان دەدات.

هەڵەکانی باو

  • نیشاندانی سنووری هەڵسەنگێندراو وەک ئەوەی داتاکان زانراو بوون.
  • باشکردن لەسەر ڕێژەی گەڕانەوەی ڕابردوو و کێشەکانی گۆشەی توند وەک تێگەیشتن.
  • لەبیرکردنی ئەوەی هەر سنوورێکی زیادکراو تەواوی سنوورەکە بەرەو خوار ڕادەکێشێت.

نموونەکان

numeric

دوو سامان بە لەرزۆکی ٢٠٪ و ١٠٪ و پەیوەندی ئاماری ٠.٢. تێکەڵەی کەمترین ڤاریانس ١٤.٣٪ لە یەکەم و ٨٥.٧٪ لە دووەم هەڵدەگرێت و لەرزۆکییەکەی ٩.٥٦٪ـە — خوار ١٠٪ی سامانی هێمنتر بە تەنها.

داتاکان
  • sigma1 = 0.20, sigma2 = 0.10
  • rho = 0.2, so covariance = 0.2 x 0.20 x 0.10 = 0.004
هەنگاوەکان
  1. numerator = sigma2^2 - cov = 0.0100 - 0.0040 = 0.0060
  2. denominator = sigma1^2 + sigma2^2 - 2 cov = 0.0400 + 0.0100 - 0.0080 = 0.0420
  3. w1 = 0.0060 / 0.0420 = 0.1429, w2 = 0.8571
  4. variance = 0.1429^2 (0.0400) + 0.8571^2 (0.0100) + 2 (0.1429)(0.8571)(0.0040) = 0.009143
  5. volatility = sqrt(0.009143) = 0.0956
minimum-variance volatility 9.56%, lower than either asset on its own

The closed form applies to two assets only and can return a weight outside the zero-to-one range; with more assets, or with a short-selling constraint, the frontier is solved numerically.

market

زیادکردنی پۆلێک کە ڕێژەی گەڕانەوەی چاوەڕوانکراوی بە تەنهای نزمترە، هێشتا دەتوانێت سنوورەکە بەرەو سەرەوە و چەپ ببات، ئەگەر پەیوەندیەکەی لەگەڵ بەرهەمەکانی ئێستا بەقەدەر بەس نزم بێت. سنوورەکە تێکەڵەکان هەڵدەسەنگێنێت، هەرگیز بەرهەمی تاک نا.

بنەمای ماتماتیکی

\min_{\mathbf{w}} \; \mathbf{w}^{\top} \Sigma \mathbf{w} \quad \text{subject to} \quad \mathbf{w}^{\top} \boldsymbol{\mu} = \mu^{*}, \;\; \mathbf{w}^{\top} \mathbf{1} = 1, \qquad w_1^{\mathrm{MV}} = \frac{\sigma_2^2 - \rho_{12} \sigma_1 \sigma_2}{\sigma_1^2 + \sigma_2^2 - 2 \rho_{12} \sigma_1 \sigma_2}

گۆڕاوەکان

\mathbf{w}ڤێکتۆری کێشەکانی پۆرتفۆلیۆ کە بۆی دەکەینەوەfractions
\Sigmaماتریکسی کۆڤاریانسی ڕێژەی گەڕانەوەی سامانەکانsquared return units
\boldsymbol{\mu}ڤێکتۆری ڕێژەی گەڕانەوەکانی چاوەڕوانکراو% per period
\mu^{*}ئامانجی ڕێژەی گەڕانەوەی چاوەڕوانکراو بۆ پۆرتفۆلیۆ% per period
w_1^{\mathrm{MV}}کێشی سامانی ١ لە پۆرتفۆلیۆی کەمترین ڤاریانسی گشتی دوو-سامانfraction of portfolio
\rho_{12}پەیوەندی ئاماری نێوان ڕێژەی گەڕانەوەی دوو سامانdimensionless

ڕێبازی ژمێریاری

ئامانجێکی ڕێژەی گەڕانەوە جێگیر بکە، پاشان ئەو کێشانە بدۆزەوە کە ڤاریانسی پۆرتفۆلیۆ کەم دەکەنەوە بە مەرجی گەیشتن بەو ئامانج و وەبەرهێنانی تەواو. ئەمە بەسەر تۆڕێکی ئامانجەکان دووبارە بکە؛ خاڵەکانی دەرئەنجام سنوورەکە دەکێشن. بۆ دوو سامان، کێشی کەمترین ڤاریانسی گشتی فۆرمی داخراوی سەرەوەی هەیە؛ بۆ زیاتر لە دوو، چارەسەرکەری پلەدوو بەکاربهێنە، و ئەگەر فرۆشتنی قەرزی ڕێپێنەدراوە مەرجی نا-نەرێنی زیاد بکە.

نموونەی کرابوو

داتاکان
  • two assets: sigma1 = 0.20, sigma2 = 0.10
  • rho_12 = 0.2
هەنگاوەکان
  1. covariance = 0.2 x 0.20 x 0.10 = 0.0040
  2. numerator = 0.0100 - 0.0040 = 0.0060
  3. denominator = 0.0400 + 0.0100 - 2(0.0040) = 0.0420
  4. w1 = 0.0060 / 0.0420 = 0.142857, w2 = 0.857143
  5. variance = 0.020408(0.0400) + 0.734694(0.0100) + 2(0.122449)(0.0040) = 0.0091429
  6. volatility = sqrt(0.0091429) = 0.095619
the global minimum-variance portfolio sits at 9.56% volatility, to the left of both single assets

لێکدانەوە

خاڵێک لەسەر سنوورەکە کەمترین ڤاریانسی بەدەستهێنراوە لە ڕێژەیەکی دیاریکراوی گەڕانەوەدا بەپێی داتاکانی دیاریکراو. پێشبینی نییە، و پۆرتفۆلیۆکانی سەر سنوور بەرامبەر یەک پلەبەندی نەکراون: هەڵبژاردن لە نێوانیان دەستپێکی مەترسییە نەک ژمێریاری.

گریمانەکان

  • Single period; returns summarised by the mean vector and covariance matrix only.
  • Short sales are permitted unless a non-negativity constraint is added; the two-asset closed form can return a weight outside zero to one, which then has no unconstrained meaning.
  • Parameters are treated as known. Because they are estimates, the frontier is itself a random object and shifts with the estimation window.
سنووری فۆرموڵ
  • The curve's apparent precision is an artefact of plotting point estimates; sampling error in the mean vector dominates, which is why minimum-variance and risk-parity constructions avoid using means at all.
  • With a risk-free asset the efficient set is a straight line, not this hyperbola, so the two must not be drawn as interchangeable.
