پێناسەی ساکار

ئەوەی قەرزدار بۆ قەرزێک لە حەوزی قەرزدان دەدات. بازاڕ ناکرێت: هەرچەند زیاتر لە حەوزەکە پێشتر قەرز درابێت، ڕێژە بەرزتر دەچێت.

پێناسەی پیشەیی

ئەو سووەی لەسەر قەرزی ماوە وەردەگیرێت و هەر بلۆکێک لە فەنکشنێکی بڵاوکراوەی ڕێژەی بەکارهێنان دووبارە دەژمێردرێت. زۆربەی پڕۆتۆکۆلەکان چەمانەی شکاو بەکاردەهێنن: لێژییەکی هێمن تا بەکارهێنانێکی ئامانج و پاشان لێژییەکی زۆر توندتر لە سەرووی، بۆیە خودی ڕێژە هەمان ئەو میکانیزمەیە کە بەشێک لە حەوز دەرهێنراو دەهێڵێتەوە.

پێناسەی تەکنیکی

ئەم ڕێژە گۆڕاوێکی کۆنتڕۆڵە نەک نرخێک کە لە بازاڕکردنەوە بدۆزرێتەوە. خوار خاڵی شکان، لێژی تێچووی ئاسایی متمانە دەنوێنێت؛ سەروو ئەوە، بەشی توند سزایەکە کە بۆ ناچارکردن بە دانەوە و ڕاکێشانی پێشکەشکردن دیزاین کراوە. لەبەر ئەوەی تێچوو ڕێژەی بەکارهێنانە نەک کوالیتی متمانە، ڕێژە هیچ زانیارییەک لەسەر مەترسی قەرزدار ناگەیەنێت و لە فشاری دەرهێناندا هەر وەک گەشەی قەرزکردن بەرز دەبێتەوە. هەر پڕۆتۆکۆلێک بنەڕەت، خاڵی شکان و هەردوو لێژی بۆ هەر سامانێک بە جیا دیاری دەکات، بۆیە ڕێژەی ڕاگەیەنراو لە نێوان مەڵبەندەکاندا بەراوردکراو نین.

میکانیزم

ئەم چەمانەیە بە یەک ژمارە دوو کار دەکات. لە بەشی هێمندا متمانە بە شتێک نزیک لە تێچووی بازاڕ دابەش دەکات. سەروو خاڵی شکان چیتر نرخ نییە و دەبێت بە ئامراز: ڕێژەیەک کە بە چەند لەسەدێک گۆڕان لە بەکارهێناندا دووقات دەبێت، هەڵگرتنی قەرز بە ئازار و دابینکردن زۆر ڕاکێشەر دەکات؛ بەم شێوەیە حەوزەکە خۆی لە بەکارهێنانی تەواو دەکێنێتەوە.

بەکارهێنانی پراکتیکی

کێ بەکاری دەهێنێت
قەرزدارەکان کە تێچووی پۆزیشنێکی لیڤەرجدار دەژمێرن، دابینکەران کە لای تری هەمان چەمانە دەخوێننەوە، و تیمی مەترسی کە خاڵی شکان و لێژیەکان هەڵدەبژێرن.
بۆچی گرنگە
هەموو تێچووی هەڵگرتنی قەرزێکی سەر تۆڕە، و شێوەی چەمانە بە قەرزدار دەڵێت ئەو تێچوو بە چ خێراییەک دەتوانێت بگۆڕێت.
سنوورەکان
ڕێژە جوڵاوە، سەربانی نییە و ئاگادارکردنەوەی پێشوەختەش نییە. یەک ژمارەی ڕاگەیەنراو لە نێوان پڕۆتۆکۆلەکاندا مانای جیاواز هەیە چونکە پارامەتری چەمانە بۆ هەر سامانێک جیاوازە.

هەڵەکانی باو

  • پێوانەی پۆزیشن لەسەر ڕێژەی ئەمڕۆ، وەک ئەوەی بە درێژایی ماوەی هەڵگرتن جێگیر بێت.
  • بەراوردکردنی ڕێژەی ڕاگەیەنراوی پڕۆتۆکۆلێک لەگەڵ ئەوی تر بەبێ بینینی چەمانەکان.
  • پشتگوێخستنی ئەوەی بازدانی ڕێژە دەکرێت لە دەرچوونی دابینکەرانەوە بێت نەک لە هاتنی قەرزدارەکان.

نموونەکان

numeric

بە بنەڕەتی سفر، لێژییەک کە لە خاڵی شکانی ٨٠ لەسەددا دەگاتە ٧ لەسەد و لێژییەکی توندی ١٠٠ لەسەد لە سەرووی، ڕێژەی قەرز لە خاڵی شکاندا ٧ لەسەد و لە بەکارهێنانی ٩٠ لەسەددا نزیکەی ٥٧ لەسەدە.

داتاکان
  • base rate = 0
  • slope 1 = 7% reached at the kink
  • kink U* = 80%
  • slope 2 = 100% applied over the remaining 20% of utilisation
  • all four parameters are illustrative, not any particular protocol's
هەنگاوەکان
  1. at U = 0.80: r = 0 + (0.80 / 0.80) x 0.07 = 7.0%
  2. at U = 0.90: excess = (0.90 - 0.80) / (1 - 0.80) = 0.50
  3. r = 0.07 + 0.50 x 1.00 = 0.57, i.e. 57%
A ten-point rise in utilisation past the kink takes the rate from 7% to 57%.

Real protocols use steeper or gentler second slopes; the point is the discontinuity in sensitivity, not these numbers.

market

قەرزدارێک پۆزیشنێک بە ڕێژەیەکی ئاسوودە دەکاتەوە. پاشان دابینکەرانی گەورە دەردەهێنن، بەکارهێنان لە خاڵی شکان تێپەڕ دەبێت، و تێچووی هەمان قەرزی نەگۆڕاو لە یەک ڕۆژدا چەند قات دەبێت — بەبێ هیچ گۆڕانێک لە مەترسی خودی قەرزدار.

بنەمای ماتماتیکی

U = \frac{B}{C + B}, \qquad r_b = \begin{cases} r_0 + \dfrac{U}{U^{*}}\,s_1, & U \le U^{*} \\[6pt] r_0 + s_1 + \dfrac{U - U^{*}}{1 - U^{*}}\,s_2, & U > U^{*} \end{cases}

ڕێبازی ژمێریاری

ڕێژەی بەکارهێنان لە باڵانسی قەرزدراو و بەردەست بژمێرە. ئەگەر لەسەر خاڵی شکان یان خوارتر بوو، لێژی یەکەم بەپێی پێشکەوتن لە هەمان بەشدا زیاد بکە. ئەگەر سەرووتر بوو، هەموو لێژی یەکەم کۆی لێژی دووەم بەپێی پێشکەوتن لە بوارى ماوەدا زیاد بکە. ئەنجام ڕێژەیەکی ساڵانەکراوە کە گرێبەست هەر بلۆکێک کۆی دەکاتەوە.

نموونەی کرابوو

داتاکان
  • C = 800,000
  • B = 7,200,000
  • r_0 = 0
  • U* = 0.80
  • s_1 = 0.07
  • s_2 = 1.00
هەنگاوەکان
  1. U = 7,200,000 / 8,000,000 = 0.90
  2. U > U*, so use the upper branch
  3. (U - U*) / (1 - U*) = 0.10 / 0.20 = 0.50
  4. r_b = 0 + 0.07 + 0.50 x 1.00 = 0.57
Borrow rate 57% annualised at 90% utilisation.

لێکدانەوە

ئەم ژمارە تێچووی ئێستای قەرزە نەک پێشبینی: هەر بلۆکێک لە باڵانسی حەوزەوە دووبارە دەژمێردرێت و دەتوانێت بەبێ هیچ کردارێک لە لایەن قەرزدارەوە زۆر بجوڵێت. خوێندنەوەی لێژی سەروو خاڵی شکان گرنگترە لە خوێندنەوەی ئاستی ئەمڕۆ، چونکە هەمان لێژی مەترسییەکەیە.

گریمانەکان

  • A two-segment kinked model, which is the common shape but not universal: some protocols use three segments, a smooth curve, or rates set by governance or an external market.
  • All four parameters are per-asset protocol settings. The values used in the worked example are illustrative and not drawn from any live market.
  • Rates are quoted annualised; the contract accrues per block, so the realised cost compounds within the year.
سنووری فۆرموڵ
  • Utilisation conflates credit demand with supply withdrawal, so the rate is a poor signal of borrower quality or of market stress direction.
  • The model is a design choice, not an equilibrium result; there is no guarantee the chosen slopes keep the pool liquid in a severe run.
  • Quoted figures are not comparable across protocols or across assets within one protocol.
