پێناسەی ساکار

ژمارەی ئەو بلۆکانەی پێش بلۆکێکی دیاریکراو هاتوون، لە بلۆکی یەکەمەوە. ژمارەی لاپەڕەی زنجیرەیە، نەک کاتژمێری.

پێناسەی پیشەیی

شوێنی بلۆکێک لە زنجیرەی ڕەسمیدا، کە لە بلۆکی جێنێسیسەوە بە سفر دەژمێردرێت. بەرزی تەنها لە ناو یەک زنجیرەی ڕەسمیدا بلۆک بەبێ دوودڵی دیاری دەکات؛ دوای ڕێکخستنەوە، هەمان بەرزی دەکرێت بلۆکێکی تر هەڵبگرێت.

پێناسەی تەکنیکی

ئیندێکسە، نەک مۆری کات. بەرزی لەگەڵ هەر بلۆکێکی پەسەندکراو یەک یەکە بەرز دەبێتەوە، بۆیە بلۆکی تێپەڕیو دەپێوێت نەک کاتی تێپەڕیو. دوو لقی ڕکابەر دەتوانن یەک بەرزی هەبێت و لەسەر ناوەڕۆکی جیاواز بن؛ بۆیە پڕۆتۆکۆڵ و گەڕۆکەکان بلۆک بە هاشی دەناسێننەوە و بەرزی بۆ ئاسانی بەکاردەهێنن. قووڵی پشتڕاستکردنەوە لە بەرزییەوە دێت: بەرزی سەر، کەم بەرزی خستنەژوورەوە، زیاد یەک.

میکانیزم

بەرزی تەنها بۆیە ناسنامەیە کە لە هەر ساتێکدا یەک لق ڕەسمییە. لە کاتی ڕێکخستنەوەدا، بەرزی سەر دەکرێت هەر بمێنێتەوە یان تەنانەت دابەزێت لە کاتێکدا بلۆکەکانی ژێری دەگۆڕێن؛ بۆیە گواستنەوەیەک کە چەند پشتڕاستکردنەوەی هەبوو دەکرێت بگەڕێتەوە بۆ مێمپووڵ. ئەوەی مەترسی کۆتاییکردن دەپێوێت قووڵی بە بلۆکە، نەک خودی بەرزی.

بەکارهێنانی پراکتیکی

کێ بەکاری دەهێنێت
سیستەمەکانی دانانی پارە لە مەڵبەندەکان، کارەکانی پاراستن، شیکەرانی ئۆنچەین، و هەر کەسێک کە یاسای پەسەندکردنی پارە لەسەر بنەمای پشتڕاستکردنەوە دەنووسێت.
بۆچی گرنگە
ئیندێکسێکی دڵنیا و خۆیی زنجیرە دەدات بۆ ڕیزکردنی ڕووداوەکان و بۆ دیاریکردنی ئەوەی گواستنەوە چەند قووڵ بێت پێش ئەوەی کۆتاییکراو دابنرێت.
سنوورەکان
بەرزی هیچ ناڵێت چەند کات تێپەڕیوە، و ناڵێت بلۆکی ئەو بەرزییە هەمان ئەو بلۆکەیە کە لایەنی بەرامبەر دەیبینێت.

هەڵەکانی باو

  • گۆڕینی جیاوازی بەرزی بۆ کات بە ماوەی ئامانج، وەک ئەوەی ورد بێت.
  • ناسینەوەی بلۆک تەنها بە بەرزی لە کاتی ڕێکخستنەوە.
  • پەسەندکردنی پارە بە یەک پشتڕاستکردنەوە لە زنجیرەیەکی کەم-هاش.

نموونەکان

crypto

بەرزکردنەوەی پڕۆتۆکۆڵ لەسەر بەرزییەکی دیاریکراو کاتبەندی دەکرێت نەک لەسەر ڕێککەوتێک؛ بۆیە هەموو نۆدەکان لە هەمان بلۆکدا یاساکان دەگۆڕن، بێ‌ئەوەی خێرایی هاتنی بلۆکەکان کاریگەر بێت.

numeric

گواستنەوەیەک لە بەرزی ١٠٠٠٠٠١ خراوەتە ناو بلۆک و سەری زنجیرە ئێستا ١٠٠٠٠٠٦ـە. قووڵی شەش پشتڕاستکردنەوەیە، چونکە خودی ئەو بلۆکە یەکەم پشتڕاستکردنەوە دەژمێردرێت.

داتاکان
  • inclusion height = 1,000,001
  • tip height = 1,000,006
  • convention: the including block counts as confirmation 1
هەنگاوەکان
  1. C = 1,000,006 - 1,000,001 + 1
  2. C = 6
6 confirmations

Some tools report depth as tip minus inclusion height, giving 5 for the same chain state. Check the convention before wiring a crediting rule.

بنەمای ماتماتیکی

C = h_{tip} - h_{tx} + 1

گۆڕاوەکان

Cقووڵی پشتڕاستکردنەوەی گواستنەوەblocks
h_{tip}بەرزی سەری ئێستای زنجیرەی ڕەسمیblock index
h_{tx}بەرزی ئەو بلۆکەی گواستنەوەکەی گرتۆتە خۆblock index

ڕێبازی ژمێریاری

بەرزی ئەو بلۆکە بخوێنە کە گواستنەوەکە تێدایە، بەرزی ئەو سەرە بخوێنە کە نۆدی خۆت بە ڕەسمی دادەنێت، کەمی بکە، و ئەگەر بەپێی نەریتی خۆت بلۆکی گرتن یەکەم پشتڕاستکردنەوەیە، یەک زیاد بکە.

نموونەی کرابوو

داتاکان
  • h_tx = 1,000,001
  • h_tip = 1,000,006
هەنگاوەکان
  1. 1,000,006 - 1,000,001 = 5
  2. 5 + 1 = 6
C = 6 confirmations

لێکدانەوە

C ژمارەی ئەو بلۆکانەی کار یان پشتڕاستکردنەوە دەژمێرێت کە لەسەر گواستنەوە کەڵەکە بوون. پێوەرێکە لەوەی گەڕاندنەوە ئێستا چەند گرانە، نەک گەرەنتی ئەوەی گەڕاندنەوە مەحاڵە.

گریمانەکان

  • Heights are read from one node's canonical chain; two nodes in disagreement will report different depths.
  • The convention that the including block counts as the first confirmation is common but not universal.
سنووری فۆرموڵ
  • A reorganisation can lower C or remove the transaction entirely.
  • Equal confirmation counts on different chains do not represent equal security, because the cost per block differs.
