پێناسەی ساکار

ڕێگەیەک بۆ هاشکردنی جووت‌جووتی ژمارەیەکی زۆر داتا، جار لە دوای جار، تا یەک هاش جێگەی هەموویان بگرێت. پاشان بەڵگەیەکی کورت دەریدەخات کە دانەیەک لە ناویدایە.

پێناسەی پیشەیی

دارەی هاشی دووانەیی: هەر گەڵایەک هاشی دانەیەکە، هەر خاڵێکی ناوەوە هاشی دوو منداڵەکەیەتی، و ڕەگ یەک پابەندبوونی تاکە بۆ هەموو کۆمەڵەی ڕیزکراو. ئەندامەتی بە دانی یەک هاشی هاوپۆل لە هەر ئاستێکدا دەردەخرێت؛ هەمان ڕێڕەوی گەڵا بۆ ڕەگ.

پێناسەی تەکنیکی

دروستکردن: هەر دانەیەک هاش بکە، پوختەکانی تەنیشت جووت بکە، جووتەکان هاش بکە، و دووبارەی بکەوە تا یەک ڕەگ بمێنێتەوە؛ لە جۆری بیتکۆیندا، ئاستی بە ژمارەی تەک دوایین خاڵەکەی دووبارە دەکاتەوە. پشکنین، ڕەگ لە گەڵاکە و سەروی لۆگاریتمی دووانەیی n هاشی هاوپۆل دووبارە دەژمێرێت؛ بۆیە قەبارەی بەڵگە بە لۆگاریتم گەشە دەکات نەک بە هێڵ. ڕەگ ئەندامەتی و ڕیزبەندی دەردەخات، هەرگیز تەواوی نا: ناتوانێت دەربخات کە شتێک نەشاردراوەتەوە.

میکانیزم

جووتکردن لە هەر ئاستێکدا ژمارەی پوختەکان نیو دەکات، بۆیە قووڵی لۆگاریتمی قەبارەی کۆمەڵەیە. هەر ئەم یەک ڕاستییە ئابووری کلاینتی سووکە: ئامێرێک کە تەنها سەردێری بلۆکی هەیە دەکرێت قەناعەت پێ بهێنرێت کە گواستنەوەیەک لە ناو بلۆکێکی هەزاران گواستنەوەدایە، چونکە بەڵگەکە چەند هاشێکە نەک خودی بلۆکەکە.

بەکارهێنانی پراکتیکی

کێ بەکاری دەهێنێت
جێبەجێکەرانی نۆد و کلاینتی سووک، ئەندازیارانی ڕۆڵئاپ و پردە، پشکنەرانی پشتڕاستکردنەوەی جۆری بەڵگەی ذەخیرە، و هەر کەسێک بەڵگەی ئەندامەتی داڕێژێت.
بۆچی گرنگە
ڕێگە بە پشکنەر دەدات ئەندامەتی لە کۆمەڵەیەکی گەورەدا بە یەک پابەندبوونی بچووک بپشکنێت؛ بناغەی کلاینتی سووک، بەڵگەی دۆخ و پشکنینی هەرزان لەسەر زنجیرە.
سنوورەکان
ئەندامەتی بەرامبەر ڕەگێک دەردەخات کە پێشتر متمانەت پێیەتی. ڕێڕەوی دروست بەرامبەر ڕەگی زنجیرەیەکی نادروست هیچ دەرناخات، و داتای شاردراوە نادیار دەمێنێتەوە.

هەڵەکانی باو

  • بەڵگەی مێرکل وەک شایەتی دروستی خودی زنجیرە دابنێی.
  • وا بزانی ڕەگ تەواوی کۆمەڵەکە دەردەخات نەک پابەندبوون بەو.
  • پشتگوێخستنی دووبارەکردنی دوایین خاڵ لە ئاستەکانی تەکدا لە کاتی دروستکردنی بەڵگە.

نموونەکان

crypto

جانتایەک کە تەنها سەردێری بلۆکەکان دەپارێزێت ڕێڕەوی مێرکلی یەک گواستنەوە لە هاوەڵێک داوا دەکات. ئەگەر ڕەگی دووبارە ژمێردراو لەگەڵ ئەو سەردێرەی هەیەتی یەکسان بوو، گواستنەوەکە لەو بلۆکەدایە؛ بەبێ دابەزاندنی بلۆک.

numeric

بلۆکێک بە ٢٠٤٨ گواستنەوە بۆ بەڵگەی ئەندامەتی پێویستی بە ١١ هاشی هاوپۆلە. بە ٣٢ بایت بۆ هەریەکە، دەکاتە ٣٥٢ بایت بەرامبەر ٦٥٥٣٦ بایت بۆ هەموو پوختەکانی گەڵا؛ هەمان پاشەکەوتی لۆگاریتمی کە پشکنینی سووک کردەیی دەکات.

داتاکان
  • n = 2,048 leaves
  • digest size = 32 bytes (SHA-256)
هەنگاوەکان
  1. path length = ceil(log2 2048) = 11
  2. proof size = 11 x 32 = 352 bytes
  3. all leaf digests = 2048 x 32 = 65,536 bytes
352-byte proof instead of 65,536 bytes of leaf digests

The proof also needs the leaf's own digest and its index; the comparison is of orders of magnitude, not an exact wire format.

بنەمای ماتماتیکی

|\pi| = \lceil \log_2 n \rceil

ڕێبازی ژمێریاری

گەڵاکان بژمێرە و لۆگاریتمی بنەمای دوو بە خڕکردنەوەی بۆ سەرەوە بگرە: ئەوە قووڵی دارە و ژمارەی ئەو هاشانەی هاوپۆلە کە پشکنەر پێویستی پێیانە. پشکنین، گەڵاکە لەگەڵ هەر هاوپۆلێک بە ڕیز هاش دەکات و بەهای کۆتایی لەگەڵ ڕەگی بڵاوکراوە بەراورد دەکات.

نموونەی کرابوو

داتاکان
  • n = 2,048
هەنگاوەکان
  1. log2 2048 = 11
  2. ceil(11) = 11
11 sibling hashes, independent of which leaf is being proved

لێکدانەوە

تێچووی بەڵگە بە هەر دووهێندەبوونی کۆمەڵەکە یەک هاش زیاد دەبێت. دووهێندەکردنی ژمارەی گواستنەوەکانی بلۆکێک ٣٢ بایت لە بەڵگەکە زیاد دەکات؛ بۆیە پشکنینی ئەندامەتی لەگەڵ گەشەی زنجیرە هەرزان دەمێنێتەوە.

گریمانەکان

  • A balanced binary tree with a fixed digest size; other arities and sparse variants give different path lengths.
  • The verifier already holds an authentic root, obtained from a header it trusts.
سنووری فۆرموڵ
  • Logarithmic cost covers inclusion only. Proving absence needs a sorted or sparse tree design, and proving data availability needs something else entirely.
  • Implementation details, such as duplicating the last node on odd levels, affect how proofs must be encoded and have caused real bugs.
