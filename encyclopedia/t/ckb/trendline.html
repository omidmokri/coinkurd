پێناسەی ساکار

هێڵێکی ڕاست کە بەسەر زنجیرەیەک بنکەی بەرزتر یان لووتکەی نزمتردا دەکێشرێت تا ئاراستە و لاری جوڵە بە یەک نیگا ببینرێت.

پێناسەی پیشەیی

هێڵێکی ڕاست کە بە دوو خاڵی سوینگ یان زیاتری هاوئاراستە دەبەسترێت و بەرەو پێشەوە درێژ دەکرێتەوە وەک ئاستێکی جوڵاو. هێڵی ئاراستەی سەرکەوتوو بنکەی بەرزتر لە خواری نرخ دەبەستێتەوە، و ئەوی داشکاو لووتکەی نزمتر لە سەرووی. ئەوەی دەخوێنرێتەوە لارییە، نەک هێڵەکە.

پێناسەی تەکنیکی

نزیکەیەکی هێڵی لە ڕێڕەوێکی ناهێڵی. لەبەر ئەوەی خاڵەکانی بەستن، هەڵبژاردنی سێبەری مۆم یان لاشەی مۆم، پێوەری نرخ و چۆنیەتی مامەڵەکردن لەگەڵ خولی نەبوو هەموویان لاری دەگۆڕن، هێڵی ئاراستە شتێکی پارامێتردارە نەک بینینێک. دوو شیکەر بە هەمان چارت دوو هێڵی جیاواز دەکێشن؛ بۆیە تەنها شێوەی دووبارەکراوەی هێڵی ئاراستە ئەوەیە کە لە کۆددا بە ڕێسایەکی ڕوونی پیڤۆت پێناسە کرابێت.

میکانیزم

هێڵی ئاراستە تەنها بەو ڕادەیە ئاستە کە بەشداران داواکاریەکانیان لەسەری دابنێن؛ ئەمە میکانیزمێکی دوواندنەوەیە نەک فیزیکی. بەڵام ئاگادارکردنەوەی لاری ساناترە: هێڵێکی توندتر بۆ ساغ مانەوە کڕینی خێراتری دەوێت، بۆیە زووتر دەشکێت، و شکاندن دەڵێت ڕێژەی داواکاری دابەزیوە، نەک بەزەروری ئەوەی ئاراستە کۆتایی هاتووە.

بەکارهێنانی پراکتیکی

کێ بەکاری دەهێنێت
مامەڵەکاری چارت بۆ دیاریکردنی دۆخی ئاراستە، مامەڵەکاری کەناڵ، و دروستکەری ستراتیژی کە پێش بەکتێست ڕێسایەکی ئۆتۆماتیکی پیڤۆتی دەوێت.
بۆچی گرنگە
زنجیرەیەک سوینگ دەکات بە یەک ژمارە، یانی لاری، و خاڵێکی پووچەڵکردنەوەی جوڵاو دەدات کە لەگەڵ تەمەنی ئاراستە تەسکتر دەبێت.
سنوورەکان
بە تەواوی بە هەڵبژاردنی خاڵەکانی بەستن بەندە. هەر هێڵێکی ئاراستە کە دوای ڕووداو دووبارە بکێشرێت باش دەردەکەوێت؛ بۆیە هێڵی دەستکێش نابێت هەرگیز وەک داتای چوونەژوورەوە بخرێتە بەکتێست.

هەڵەکانی باو

  • دووبارە کێشانی هێڵ دوای هەر شکاندنێک تا جێگیر بێت.
  • تێکەڵکردنی سێبەر و لاشەی مۆم وەک خاڵی بەستن لەسەر یەک هێڵ.
  • خوێندنەوەی شکاندنی هێڵی توند وەک گەڕانەوەی ئاراستە.

نموونەکان

chart

سێ بنکەی سەرکەوتوو لەسەر ١٠٠، ١١٢ و ١٢٦ هێڵی ئاراستەیەکی سەرکەوتوو دروست دەکەن. بنکەی چوارەم لەسەر ١٣٠ لە سەرووی هێڵەکەیە، بۆیە ئاراستە ساغە بەڵام هێواش بووە؛ هێڵ دەست لێ نەدراوە و زانیاری نوێ نادات.

numeric

هێڵی ئاراستەی سەرکەوتوو کە لە مۆمی ١٠ لەسەر ١٠٠ و مۆمی ٤٠ لەسەر ١٣٠ بەستراوە، هەر مۆمێک یەک یەکە بەرز دەبێتەوە. لە مۆمی ٦٠دا هێڵ لەسەر ١٥٠ـە، بۆیە داخستنی ١٤٦ لە خواری هێڵەکەیە، هەرچەندە نرخ زۆر لە سەرووی خاڵی یەکەمی بەستنە.

داتاکان
  • anchor 1: bar index 10, price 100
  • anchor 2: bar index 40, price 130
  • evaluation bar index = 60
  • close at bar 60 = 146
هەنگاوەکان
  1. slope m = (130 - 100) / (40 - 10) = 1.0 per bar
  2. line value at bar 60 = 100 + 1.0 x (60 - 10) = 150
  3. 146 < 150
the close is 4 points below the trendline at that bar

Slope is per bar index, not per calendar day. Weekends and halted sessions change the answer if calendar time is used instead.

بنەمای ماتماتیکی

m = \frac{P_2 - P_1}{t_2 - t_1}, \qquad L(t) = P_1 + m\,(t - t_1)

گۆڕاوەکان

P_1, P_2نرخ لە دوو پیڤۆتی بەستنprice units
t_1, t_2ژمارەی مۆمی دوو پیڤۆتی بەستنbars
mلاری: گۆڕانی نرخ لە هەر مۆمێکprice units per bar
L(t)ئاستی هێڵی درێژکراوە لە مۆمی tprice units

ڕێبازی ژمێریاری

ڕێسایەکی پیڤۆت جێگیر بکە، بۆ نموونە بنکەیەک کە لە هەردوو لایەوە k بنکەی بەرزتری هەیە. دوو پیڤۆتی پشتڕاستکراوەی هاوهێمای ئەم دواییە بگرە، لاری لە نرخ و ژمارەی مۆمەکانیان دەربهێنە، پاشان هێڵ لە هەر مۆمێکی دواتر هەڵبسەنگێنە. بۆ دووبارەکرانەوە، نرخی داخستن بەراورد بکە نەک سێبەری مۆم.

نموونەی کرابوو

داتاکان
  • anchor 1: (t = 10, P = 100)
  • anchor 2: (t = 40, P = 130)
  • target bar t = 60
هەنگاوەکان
  1. m = (130 - 100) / (40 - 10) = 1.0
  2. L(60) = 100 + 1.0 x (60 - 10)
L(60) = 150

لێکدانەوە

لاری ڕێژەیەکە: ئەو یەکەی نرخ کە لە هەر مۆمێکدا بەدەستهاتووە بەو مەرجەی ئاراستە ماوە. بەراوردی داخستنی ئێستا لەگەڵ L(t) تەنها دەڵێت ئایا نرخ هێشتا لە سەرووی ئەو ڕێژەی پێشچوونەیە یان نا؛ هیچی تر.

گریمانەکان

  • Linear price axis. On a logarithmic axis the same two anchors imply a different path, because the line is then straight in log price.
  • Time measured in bar index. Using calendar time changes the slope whenever sessions are missing.
  • The anchors are confirmed pivots known at the time, not extremes identified later. Choosing anchors with hindsight is lookahead bias.
سنووری فۆرموڵ
  • Two anchors never define a unique line in practice: wick or body, and which pivot counts, both move it.
  • The formula is exact; the object it describes is a choice. Precision in the arithmetic does not make the line objective.
