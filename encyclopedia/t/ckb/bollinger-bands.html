پێناسەی ساکار

تێکڕای جوڵاوێک لەگەڵ دوو هێڵ لە سەرەوە و خوارەوەی، کە دووریان بە لەرزۆکی نرخی ئەم دواییە دیاری دەکرێت. کاتێک جوڵەکانی نرخ گەورە دەبن هێڵەکان فراوان دەبن و کاتێک بازاڕ ئارام دەبێت تەنک دەبنەوە.

پێناسەی پیشەیی

پۆشەرێک لەسەر بنەمای لەرزۆکی نرخ: تێکڕای جوڵاوی سادەی ٢٠ خول وەک باندی ناوەڕاست، و دوو باندی دەرەوە بە دووری دوو لادانی ستاندارد لە هەمان ٢٠ نرخی داخستن، لە سەرەوە و خوارەوەی. پانی باندەکان خوێندنەوەی لەرزۆکی نرخە و شوێنی نرخ لە نێوان باندەکان خوێندنەوەیەکی بەراوردە.

پێناسەی تەکنیکی

باندی ناوەڕاست تێکڕای جوڵاوی سادەی n خولە لە نرخی داخستن، و باندەکانی دەرەوە بە ئەندازەی k لادانی ستاندارد لە هەمان n داتا لە سەرەوە و خوارەوەی دادەنیشن؛ بنەڕەتی بۆڵینجەر n=٢٠ و k=٢ـە. لەبەر ئەوەی پەرشوبڵاوی لەسەر هەر مۆمێک دووبارە دەژمێردرێتەوە، پۆشەرەکە گونجاوە نەک جێگیر. نزیکەی ٨٩ لەسەدی داتاکان لە نێوان باندەکانی دوو سیگمادا دەکەون؛ ئەمە یاسایەکی ئەزموونی زنجیرەکانی داراییە، نەک ئەو ٩٥ لەسەدەی دابەشبوونی نۆرماڵ دەیدات، چونکە ڕێژەی گەڕانەوەکان نۆرماڵ نین.

میکانیزم

لەبەر ئەوەی دووری باندەکان لادانی ستانداردی هەمان ئەو پەنجەرەیەیە کە تێکڕاکە دروست دەکات، پۆشەرەکە لەگەڵ بازاڕ هەناسە دەدات. ماوەیەکی ئارام خەمڵاندنی پەرشوبڵاوی بچووک دەکاتەوە و باندەکان تەنک دەکات؛ بۆیە دوای فشارخواردن زۆرجار جوڵەیەکی فراوان دێت. فشارخواردن ئارامی ڕابردوو دەپێوێت، ئاراستەی کۆتاییهێنانی ناپێشبینێت.

بەکارهێنانی پراکتیکی

کێ بەکاری دەهێنێت
شیکەرانی تەکنیکی، دروستکەرانی ستراتیژی سیستەماتیک کە گوێ بە لەرزۆکی نرخ دەدەن، و مامەڵەکارانێک کە سنووری زیان و سنووری قازانج بەپێی پەرشوبڵاوی ئەم دواییە دادەنێن.
بۆچی گرنگە
نرخ دەخاتە سەر پێوەرێکی بەراورد بە لەرزۆکی، بۆیە یەک چارت دەکرێت لە ماوەی ئارام و توندوتیژدا بەبێ گۆڕینی پارامەتر بخوێندرێتەوە.
سنوورەکان
باندەکان پەرشوبڵاوی ڕوون دەکەنەوە، نە ئاراستە و نە بەهای ڕاست. بەرکەوتن ئاماژە نییە، و لە ئاراستەدا نرخ دەتوانێت هەفتەکان بەسەر باندێکدا بسوڕێت.

هەڵەکانی باو

  • فرۆشتن لە هەر بەرکەوتنێکی باندی سەرەوە، وەک بڕگەی سەقف.
  • خوێندنەوەی باندی دوو سیگما وەک بوارێکی ٩٥ لەسەدی.
  • بەراوردکردنی پانی باند لە نێوان ئامرازەکان بەبێ دابەشکردن بەسەر نرخ.

نموونەکان

market

لە ئاراستەیەکی بەهێزدا نرخ دەتوانێت چەند مۆمێک بە دوای یەکدا لە دەرەوەی باندی سەرەوە دابخرێت. ئەمە سوارییە بەسەر باندەوە و نیشانەی جوڵەیەکی بەردەوامە؛ ئەوانەی هەر داخستنێکی دەرەوە وەک ئاماژەی گەڕانەوە گرت، بە پێچەوانەی ئاراستە مامەڵەیان کرد.

numeric

تێکڕای ٢٠ نرخی داخستن ١٠٠.٠ و لادانی ستاندارد ٢.٥ـە. باندی سەرەوە ١٠٥.٠، باندی خوارەوە ٩٥.٠، و پانی پۆشەر ١٠ لەسەدی باندی ناوەڕاستە؛ ژمارەیەکی لەرزۆکی نرخ، نەک پێشبینی.

داتاکان
  • n = 20 closes
  • SMA(20) = 100.0
  • standard deviation of the same 20 closes = 2.5
  • k = 2
هەنگاوەکان
  1. upper = 100.0 + 2 x 2.5 = 105.0
  2. lower = 100.0 - 2 x 2.5 = 95.0
  3. width = 105.0 - 95.0 = 10.0
  4. relative width = 10.0 / 100.0 = 10%
Upper 105.0, lower 95.0, band width 10 percent of the middle band.

Width is a dispersion statistic. It says nothing about which band price will reach next.

بنەمای ماتماتیکی

MB_t = \frac{1}{n}\sum_{i=0}^{n-1} C_{t-i}, \qquad UB_t = MB_t + k\sigma_t, \qquad LB_t = MB_t - k\sigma_t

گۆڕاوەکان

MB_tباندی ناوەڕاست: تێکڕای جوڵاوی سادەی n نرخی داخستنی کۆتاییprice units
UB_t, LB_tباندی سەرەوە و باندی خوارەوەprice units
C_{t-i}نرخی داخستنی i خول پێشترprice units
\sigma_tلادانی ستانداردی هەمان n نرخی داخستنprice units
n, kدرێژی چوارچێوەی مرجەع و ڕێژەی باند؛ بنەڕەتی بۆڵینجەر ٢٠ و ٢ـەperiods, multiple

ڕێبازی ژمێریاری

تێکڕای n نرخی داخستنی کۆتایی بگرە بۆ باندی ناوەڕاست. لادانی ستانداردی هەمان n داتا بژمێرە. k ئەوەندەی ئەو ژمارەیە جارێک زیاد و جارێک کەم بکە بۆ دانانی باندەکانی دەرەوە. ئەمە لەسەر هەر مۆمێکی نوێ دووبارە بکەرەوە، بۆیە ناوەند و پانی پێکەوە نوێ دەبنەوە.

نموونەی کرابوو

داتاکان
  • n = 20
  • SMA(20) = 100.0
  • standard deviation of the window = 2.5
  • k = 2
هەنگاوەکان
  1. k x sigma = 2 x 2.5 = 5.0
  2. UB = 100.0 + 5.0
  3. LB = 100.0 - 5.0
UB = 105.0, LB = 95.0, width = 10.0

لێکدانەوە

پانی دەڵێت نرخەکانی داخستنی ئەم دواییە چەند پەرشوبڵاو بوون؛ شوێنی نرخ لە نێوان باندەکان دەڵێت نرخ چەند لادانی ستاندارد لە تێکڕای ئەم دواییەی خۆی دوورە. هیچیان ئاراستە نادەن.

گریمانەکان

  • Bollinger's defaults are n = 20 and k = 2; both are configuration choices, not constants.
  • Sigma is computed on the same n closes that form the average. Platforms differ on whether they divide by n or by n-1, which shifts the bands slightly on short lookbacks.
  • Closes are the default input. Using typical price or another series produces a different envelope with the same name.
سنووری فۆرموڵ
  • The roughly 89 percent containment reported for financial series is an empirical regularity, not a property guaranteed by the formula, and it varies by market and period.
  • Sigma is backward-looking, so the bands widen after a volatility shock rather than before it.
  • Band width is in price units, so it is comparable across instruments only after dividing by price.

باندەکانی بۆڵینجەر پەرشبوونی نرخەکانی داخستن بە دەوری تێکڕادا دەپێون. ATR ئەو مەودا دەپێوێت کە نرخ لە ناو هەر مۆمێکدا، لەگەڵ بۆشاییەکان، بەری دەکات. هەردووکیان لەرزۆکی نرخن، لە دوو کەرەستەی جیاوازەوە.

The roughly 89 percent containment figure is reported as an empirical regularity for financial series and is not a distributional guarantee; it varies by instrument and window. The Kurdish headword keeps the English proper name transliterated, as practitioners do, so it is marked english-retained rather than proposed. Platforms differ on population versus sample standard deviation, which changes the bands on short lookbacks.
