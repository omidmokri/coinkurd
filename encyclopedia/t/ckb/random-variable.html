پێناسەی ساکار

ژمارەیەک کە بەهای پێشوەخت نەزانراوە، چونکە بەستراوە بە ئەنجامی بارودۆخێکی نادڵنیا. ڕێژەی گەڕانەوەی سبەینێی سامانێک یەکێکە لەوانە.

پێناسەی پیشەیی

یاسایەک کە بۆ هەر ئەنجامێکی گونجاوی تاقیکردنەوەیەکی نادڵنیا ژمارەیەک دیاری دەکات و ئەگەری ئەو ئەنجامەکانیش لەگەڵ خۆی دەهێنێت. جۆری دابڕاو بەهای ژمێرکراو دەگرێت؛ جۆری بەردەوام لە نێو بوارێکدا بەها دەگرێت و بە چەقینە ڕوون دەکرێتەوە، نەک بە ئەگەری خاڵی.

پێناسەی تەکنیکی

نەخشەیەکی پێوانەپێکراو لە بۆشایی ئەگەرەوە بۆ هێڵی ژمارەی ڕاستەقینە. یاساکەی بە تەواوی بە نەخشەی دابەشبوونی کۆکراوی F(x) = Pr(X ≤ x) دیاری دەکرێت، کە کەم نابێتەوە و لەلای ڕاست بەردەوامە. داتای ڕوویداو تەنها چەند هەڵگرتنێکی ئەو یاسایەن، نەک خودی یاساکە — ئەمە هۆکاری سەرەکی ئەوەیە کە یەک مێژووی نرخ ناتوانێت ئەو پڕۆسەیە ئاشکرا بکات کە دروستی کردووە.

میکانیزم

جیاکردنەوەی ئەنجام لەو ژمارەیەی پێی دەدرێت ئەوەیە کە نادڵنیایی دەکاتە شتێکی ژماردنی. کاتێک هەر ئەنجامێک بەهایەک و ئەگەرێکی هەبوو، تێکڕا، بڵاوبوونەوە و مەترسی کلک هەمووی لە یەک شتەوە دەردەچن. تێچووی ئەوەیە کە خودی ئەو شتە هەرگیز نابینرێت، تەنها هەڵگرتنەکانی.

بەکارهێنانی پراکتیکی

کێ بەکاری دەهێنێت
هەر کەسێک کە بڕێکی نادڵنیا مۆدێل دەکات: بەڕێوەبەرانی مەترسی بۆ دیاریکردنی قەبارەی بەرکەوتە، کوانتەکان بۆ پێناسەی پڕۆسەی ڕێژەی گەڕانەوەی ستراتیژێک، و مێزەکانی بژاردەی مامەڵە بۆ نرخاندن.
بۆچی گرنگە
ئەو شتەیە کە هەموو ئامارێکی دواتر لێی دەژمێردرێت. بەهای چاوەڕوانکراو، واریانس، بەهای لەبەردەم مەترسی و قەبارەی پۆزیشن هەموویان لەسەر هەمان گۆڕاو دەخوێندرێنەوە.
سنوورەکان
ئەم دانانە هەڵبژاردنێکی مۆدێلکردنە نەک بینینێک. دوو شیکەر دەتوانن دوو گۆڕاوی جیاواز بۆ هەمان بازاڕ دابنێن و بگەن بە ژمارەی مەترسیی بەرگریکراو بەڵام ناکۆک.

هەڵەکانی باو

  • ڕێڕەوی نرخی ڕوویداو وەک خودی گۆڕاوەکە دابنێی.
  • گریمانەی یاسایەکی جێگیر لە کاتێکدا پڕۆسەی دروستکەر دەگۆڕێت.
  • بردنی تێگەیشتنی مۆدێلی دابڕاو بۆ سەر بڕی بەردەوام.

نموونەکان

everyday

پێش هەڵدانی تاس، ئەنجام گۆڕاوێکی ئەگەرییە بە شەش بەهای هاوئەگەر. دوای کەوتنی، ئەو ٤ـەی دەیبینیت ڕوودانێکە نەک خودی گۆڕاوەکە. بازاڕیش بە هەمان شێوە دەخوێندرێتەوە: چارت هەمان ڕوودانە.

numeric

ژمارەی داخستنەکانی سەرەوە لە پێنج دانیشتنی سەربەخۆدا بژمێرە، کە هەریەکە بە هاوئەگەری سەرەوە یان خوارەوە دادەخرێت. ئەم ژماردنە گۆڕاوێکی ئەگەرییە لەسەر ٠ بۆ ٥، و ئەگەری زۆرترین سێ داخستنی سەرەوە ٢٦ لە ٣٢ـە، یانی ٨١.٢٥٪.

داتاکان
  • 5 sessions
  • Pr(up close) = 0.5 for each session
  • sessions assumed independent
  • X = number of up-closes
هەنگاوەکان
  1. X is binomial with n = 5 and p = 0.5, so all 32 up/down paths are equally likely
  2. Paths with 0, 1, 2 or 3 up-closes: 1 + 5 + 10 + 10 = 26
  3. Pr(X <= 3) = 26 / 32
Pr(X <= 3) = 0.8125

The fair-coin model illustrates the mechanics only. It is not a claim that daily closes are independent or equally likely.

ڕێبازی ژمێریاری

ئەنجامەکانی گونجاو بنووسە یان ڕوونی بکەوە. بۆ هەریەکە ژمارەیەک دابنێ. بۆ هەریەکە ئەگەرێک دابنێ، بەشێوەیەک کۆی ئەگەرەکان ببێتە یەک. پاشان نەخشەی دابەشبوون بە کۆکردنەوەی ئەگەر لەلای چەپەوە دروست دەبێت: بۆ هەر xێک، ئەگەری هەر ئەنجامێک کە ژمارەی x یان کەمتر بێت کۆ بکە.

نموونەی کرابوو

داتاکان
  • X = number of up-closes in 5 independent sessions
  • Pr(up close) = 0.5 each
هەنگاوەکان
  1. Each of the 32 up/down paths has probability 1/32
  2. Number of paths with at most 3 up-closes = 1 + 5 + 10 + 10 = 26
  3. F(3) = Pr(X <= 3) = 26/32
F(3) = 0.8125

لێکدانەوە

نەخشەی دابەشبوون لە هەر سنوورێکدا وەڵامی یەک پرسیار دەداتەوە: چەند ئەگەر لەسەر ئەم بەها یان خوارتری دانیشتووە. هیچ نەدەڵێت کام ئەنجام ڕوودەدات، تەنها دەڵێت کۆی ئەگەر چۆن بەسەر ئەنجامەکاندا بڵاوکراوەتەوە.

گریمانەکان

  • A probability space with a consistent probability measure is taken to exist; the definition does not supply it.
  • Discrete variables are described by a mass function and continuous ones by a density, while the distribution function covers both cases.
  • Independence between successive draws is an extra assumption, not part of the definition of a random variable.
سنووری فۆرموڵ
  • The definition fixes no particular distribution, so it cannot by itself tell you how any market behaves.
  • Some heavy-tailed laws have a perfectly well-defined distribution function while their mean or variance does not exist.
