پێناسەی ساکار

ئەوەی یەک گرێبەست نوێنەری چەند بڕێک لە سامانی بناغەییە. کڕینی یەک گرێبەست هەرگیز کڕینی یەک یەکە نییە؛ کڕینی هەمان بڕەیە کە تایبەتمەندی گرێبەست دەڵێت.

پێناسەی پیشەیی

ئەو بڕی دیاریکراوی سامانی بناغەیی کە یەک گرێبەست دەگرێتەوە، یان ئەو هاوکارەی بەسەر ئاستی ئیندێکسێکدا جێبەجێ دەکرێت. نرخی ڕاگەیەنراو دەکاتە پارە: بەهای ناوی یەکسانە لەگەڵ قەبارەی گرێبەست لە ژمارەی گرێبەست لە نرخ، و بەهای هەر تیکێکیش دیاری دەکات.

پێناسەی تەکنیکی

خانەیەکی تایبەتمەندییە، نەک گۆڕاوی بازاڕ. بەهای ناویی بەرکەوتن، بەهای کاشی بچووکترین هەنگاوی نرخ و بەوەش ورد‌بوونی دیاریکردنی قەبارە دیاری دەکات: مامەڵەکار ناتوانێت کەمتر لە یەک گرێبەست قەبارە بگرێت، بۆیە قەبارەی گرێبەست بچووکترین مەترسی دەربڕاو دیاری دەکات. بۆرسەکان هەمان سامانی بناغەیی بە قەبارەی ستاندارد، مینی و مایکرۆ تۆمار دەکەن بۆ ئەوەی هەمان بنکە نزم بکەنەوە، و قەبارەکان بۆ یەک سامان لە نێوان بۆرسەکاندا جیاوازن.

میکانیزم

ستانداردکردنی بڕ ئەوەیە کە گرێبەستەکان دەکات بە جێگرەوەپێکراو: ئەگەر هەر گرێبەستێک هەمان بڕ بگرێتەوە، هەر فرۆشیارێک دەتوانێت پۆزیشنی هەر کڕیارێک دابخات. کاریگەری لاوەکی بنکەیەکی دیاریکردنی قەبارەیە. لەو شوێنەی ئەم بنکە بەرامبەر هەژمار گەورە بێت، تەنها ئامرازی کۆنترۆڵی مەترسی دووری سنووری زیانە، چونکە بڕ کەم نەکرێت — و هەر ئەمە هۆکاری ڕاستەقینەی بوونی گرێبەستی مینی و مایکرۆیە.

بەکارهێنانی پراکتیکی

کێ بەکاری دەهێنێت
هەر کەسێک کە گرێبەستی داهاتوو یان بژاردەی بۆرسەیی مامەڵە دەکات، و تیمەکانی مەترسی کە ژمارەی گرێبەست بۆ ڕاپۆرت و سنوورەکان دەکەنە بەرکەوتن.
بۆچی گرنگە
پردە لە نێوان چارت بە زمانی نرخ و هەژمار بە زمانی پارە؛ بەبێ ئەو ناتوانرێت دووری سنووری زیان ببێتە ژمارەی زیان.
سنوورەکان
تایبەتمەندییەکان بە بۆرسەوە بەستراون و پێداچوونەوەیان دەکرێت، و یەک هێما لە دوو بۆرسدا دەکرێت لە قەبارە، تیک و شێوازی یەکلاییکردنەوە جیاواز بێت؛ بۆیە قەبارە دەبێت لە تایبەتمەندی ئێستای گرێبەست بخوێنرێتەوە.

هەڵەکانی باو

  • نرخی ڕاگەیەنراو وەک ئەوە بخوێنیتەوە کە یەک گرێبەست یەک یەکەی سامانە.
  • کۆپیکردنی قەبارەی پۆزیشن لە نێوان بۆرسەکانی هاوکاری جیاواز.
  • لەبیرکردنی ئەوەی بەهای تیک، نەک ژمارەی تیک، زیان دیاری دەکات.

نموونەکان

market

دوو بۆرسە گرێبەستێک لەسەر هەمان ئیندێکس تۆمار دەکەن، یەکێکیان بە هاوکاری ٥٠ و ئەوی تر بە ٥. چارت یەکە و تیکیش یەکە، بەلام جوڵەیەکی دە تیکی لە یەکەمیاندا دە ئەوەندە تێچووی هەیە. تایبەتمەندی گرێبەست مەترسی دیاری دەکات، نەک چارت.

numeric

وابزانە گرێبەستێک ٥ یەکە لە ئیندێکسێکی بە نرخی ٣٬٠٠٠ بگرێتەوە و بچووکترین هەنگاوی نرخ ٠.٢٥ بێت. بەهای ناویی هەر گرێبەست ١٥٬٠٠٠ و بەهای هەر تیک ١.٢٥ـە، بۆیە سێ گرێبەست بە هەشت تیک جوڵەی پێچەوانە، ٣٠ تێچووی هەیە.

داتاکان
  • Contract size Q_c = 5 units per contract
  • Price P = 3,000 index points
  • Minimum price increment = 0.25 points
  • n = 3 contracts
  • Adverse move = 8 ticks
هەنگاوەکان
  1. Notional per contract = 5 x 3,000 = 15,000
  2. Tick value = 5 x 0.25 = 1.25
  3. Loss = 1.25 x 8 x 3 = 30
Notional 45,000 across three contracts; the eight-tick adverse move costs 30

Figures are illustrative. Contract size, tick size and tick value are published per product by each venue and must be read there.

بنەمای ماتماتیکی

N = Q_c \times n \times P, \qquad V_{\text{tick}} = Q_c \times \Delta_{\text{tick}}

گۆڕاوەکان

Nبەهای ناویی بەرکەوتنی پۆزیشنcurrency
Q_cقەبارەی گرێبەست: یەکەی سامانی بناغەیی لە هەر گرێبەست، یان هاوکاری ئیندێکسunits per contract
nژمارەی گرێبەستی هەڵگیراوcontracts
Pنرخی ڕاگەیەنراو یان ئاستی ئیندێکسprice units
V_{\text{tick}}بەهای کاشی یەک هەنگاوی کەمینەی نرخ لە هەر گرێبەستcurrency
\Delta_{\text{tick}}بچووکترین هەنگاوی نرخی دیاریکراوی بۆرسەprice units

ڕێبازی ژمێریاری

قەبارەی گرێبەست و بچووکترین هەنگاوی نرخ لە تایبەتمەندی بەرهەم بخوێنەوە. قەبارە لە ژمارەی گرێبەست و نرخی ئێستا بدە بۆ بەهای ناوی. قەبارە لە هەنگاوی نرخ بدە بۆ بەهای یەک تیک، پاشان لە ژمارەی تیک و ژمارەی گرێبەست بدە تا هەر دوورییەکی نرخ ببێتە پارە.

نموونەی کرابوو

داتاکان
  • Q_c = 5
  • n = 3
  • P = 3,000
  • tick = 0.25
هەنگاوەکان
  1. N = 5 x 3 x 3,000 = 45,000
  2. V_tick = 5 x 0.25 = 1.25
  3. 8 ticks x 1.25 x 3 contracts = 30
N = 45,000 and an eight-tick adverse move costs 30

لێکدانەوە

ئەمانە گۆڕینی یەکەن نەک مۆدێل: دەڵێن پۆزیشنێک چەند بەهای هەیە و دوورییەکی نرخ چەند تێچووی هەیە. بەهاکەیان ئەوەیە ئەو دوو ژمارەی مامەڵەکار بەڕاستی کۆنترۆڵی دەکات، ژمارەی گرێبەست و دووری سنووری زیان، لەگەڵ سەرمایەی هەژمار بەراوردکراو دەکەن.

گریمانەکان

  • A linear, quote-currency-settled contract. An inverse or coin-margined contract converts price into money differently, so this notional identity does not hold there.
  • Contract size and tick size are taken from the current published specification of that product on that venue.
سنووری فۆرموڵ
  • Notional is a gross exposure figure. It says nothing about margin required, which is set separately by the venue.
  • Tick value is fixed only where the multiplier is fixed; products quoted in yield or in percentage terms can have a tick value that depends on price.

قەبارەی لۆت

قەبارەی لۆت هەنگاوی مامەڵەپێکراوی بڕە، یانی هەر پلەیەک چەند دەکرێت زیاد بکرێت. قەبارەی گرێبەست دەڵێت هەر یەکێک لەو یەکەکان نوێنەری چەند بڕێکی سامانی بناغەییە. یەکێکیان ورد‌بوون دیاری دەکات و ئەوی تر بەرکەوتن.
