پێناسەی ساکار

ئەو ڕێژەیەی پۆرتفۆلیۆیەک بەدەستی هێناوە زیاتر لەوەی بەرکەوتنەکانی مەترسی دەبووایە دروستی بکەن. ئەلفای ئەرێنی وەک شارەزایی دەردەکەوێت — بەڵام تەنها بەرامبەر ئەو مۆدێلەی «دەبووایە» پێناسە کردووە.

پێناسەی پیشەیی

پێگەی سەرەتایی ڕێگرێشنی ڕێژەی زیادەی پۆرتفۆلیۆ بەسەر بەرکەوتنەکانی فاکتەری. لە حالەتی تاک‌فاکتەری هەمان ئەلفای یێنسنە: ڕێژەی ڕاستەقینە کەم ڕێژەی بێ‌مەترسی کەم بێتا لێکدراو لە زیادەی بازاڕ. هەمیشە بەرامبەر مۆدێلێکی هەڵبژێردراوە.

پێناسەی تەکنیکی

ئەلفا ئەو ڕستەی جێگیرەیە کە ڕێگرێشنی فاکتەری دەگونجێنێت، بۆیە بە پێکهاتەی خۆی هەمان ئەو بەشی تێکڕای ڕێژەی زیادەیە کە فاکتەرەکانی هەڵبژێردراو ناتوانن ڕوونی بکەنەوە. زیادکردنی فاکتەرێک کە پۆرتفۆلیۆ لەسەری بار هەیە، ڕێژە لە پێگەی سەرەتاییەوە دەگوازێتەوە بۆ ئەو فاکتەرە، بۆیە ئەلفایەک کە لە مۆدێلی تاک‌فاکتەری گرنگە دەتوانێت لە مۆدێلی فرە‌فاکتەریدا نەمێنێت. هەڵسەنگاندنی ئەلفا هەڵەی نمونەگرتنی ڕێگرێشنیش بە میرات دەگرێت و لەسەر تۆمارێکی کورت بە دەگمەن گرنگە.

میکانیزم

ڕێگرێشنی فاکتەری تێکڕای ڕێژەی زیادە دابەش دەکات بە بەشێک کە بۆ بەرکەوتنەکانی زانراو دەگەڕێتەوە و جێگیرێکی پاشماوە. ئەم دابەشکردنە بە تەواوی بەوەوە بەستراوە کە چ بەرکەوتنێک لە مۆدێلەکەدایە. بۆیە ئەلفا تایبەتمەندیی پۆرتفۆلیۆ نییە، تایبەتمەندیی جووتی پۆرتفۆلیۆ و مۆدێلە: مۆدێل گەورە بکە و پاشماوە بچووک دەبێتەوە؛ هەمان ئەوەی بە مێژوویی ڕوویدا کە فاکتەرەکانی قەبارە و بەها زیاد کران.

بەکارهێنانی پراکتیکی

کێ بەکاری دەهێنێت
دابەشکەرانی سەرمایە کە بەڕێوەبەرانی چالاک هەڵدەسەنگێنن، توێژەران کە تاقی دەکەنەوە ئایا ستراتیژییەک لە ڕێکخستنی مەترسی دەرباز دەبێت، و تیمەکانی پاڵپێوەنانی کارایی.
بۆچی گرنگە
ئەو بەشی تۆمار جیا دەکاتەوە کە بەرکەوتنەکانی مەترسیی زانراو ڕوونی ناکەنەوە؛ تەنها ئەو بەشەی دەکرێت کرێی شارەزایی لەسەری بپارێزرێت.
سنوورەکان
بەرامبەر مۆدێلە و ژاوەژاوی نمونە هەیە. ئەلفای ئەرێنی بەرامبەر کۆمەڵەیەک فاکتەر، بەڵگە نییە بەرامبەر کۆمەڵەیەکی تری دەوڵەمەندتر.

هەڵەکانی باو

  • گوتنی ئەلفا بەبێ ناوهێنانی مۆدێلی فاکتەریی پشتی.
  • خوێندنەوەی پێشکەوتنی خاو وەک ئەلفا بەبێ هیچ ڕێکخستنی مەترسی.
  • هەڵسەنگاندنی ئەرێنیی بێ‌گرنگی وەک شارەزاییی چەسپاو دانان.

نموونەکان

numeric

سندوق ١٤٪ ڕێژە دەدات، بێ‌مەترسی ٣٪، بازاڕ ١٠٪، بێتا ١.٢. مۆدێل چاوەڕوانی ٣ + ١.٢ × ٧ = ١١.٤٪ دەکات، بۆیە ئەلفای یێنسن ٢.٦٪ـە. بەرامبەر مۆدێلی تاک‌فاکتەری، سندوقەکە شارەزا دەردەکەوێت.

داتاکان
  • R_p = 14%
  • R_f = 3%
  • R_m = 10%
  • beta = 1.2
  • annual figures, one market proxy
هەنگاوەکان
  1. market premium = 10% - 3% = 7%
  2. expected return = 3% + 1.2 * 7% = 11.4%
  3. alpha = 14% - 11.4% = 2.6%
Jensen's alpha = 2.6% per year

Verified arithmetic. The figure is the intercept of a one-factor regression and is only defined relative to that one factor.

pitfall

هەمان سندوق ٠.٥ لەسەر فاکتەری قەبارە بە زیادەی ٣٪ و ٠.٣ لەسەر فاکتەری بەها بە زیادەی ٢٪ـیش بار هەیە. ئەو بەرکەوتنەکان ٢.١٪ لە ٢.٦٪ ڕوون دەکەنەوە و ئەلفا ٠.٥٪ دەمێنێتەوە. ئەو شارەزاییە زۆرتر بەرکەوتنی فاکتەری بوو بە جلێکی تر.

داتاکان
  • one-factor alpha = 2.6%
  • size loading 0.5 with a 3% premium
  • value loading 0.3 with a 2% premium
  • illustrative premiums, not measured figures
هەنگاوەکان
  1. size contribution = 0.5 * 3% = 1.5%
  2. value contribution = 0.3 * 2% = 0.6%
  3. total explained by the added factors = 2.1%
  4. three-factor alpha = 2.6% - 2.1% = 0.5%
alpha falls from 2.6% to 0.5% when two factors are added

The portfolio did not change; the model did. This is why an alpha figure is meaningless without the factor model that produced it.

بنەمای ماتماتیکی

\alpha_i = \bar{R}_i - \left[R_f + \beta_i\left(\bar{R}_m - R_f\right)\right], \qquad R_{i,t} - R_{f,t} = \alpha_i + \sum_{k=1}^{K} \beta_{i,k} F_{k,t} + \varepsilon_{i,t}

\alpha_iپێگەی سەرەتاییی ڕێگرێشن: تێکڕای ڕێژەی زیادەی کە فاکتەرەکان ڕوونی ناکەنەوە% per period

ڕێبازی ژمێریاری

یەکەم مۆدێلی فاکتەری ڕابگەیەنە. ڕێژەی بێ‌مەترسیی هاوتا لە ڕێژەکانی پۆرتفۆلیۆ کەم بکەوە. ئەو زنجیرەی ڕێژەی زیادە بەسەر ڕێژەی فاکتەرەکان لە هەمان خولەکان ڕێگرێشن بکە؛ پێگەی سەرەتایی هەمان ئەلفایە و ئامارەی tـی دیاری دەکات ئایا هەڵسەنگاندنەکە لە سفر جیا دەکرێتەوە. مۆدێل، پەنجەرە و هەڵەی ستاندارد لەگەڵ ژمارەکە ڕاپۆرت بکە.

نموونەی کرابوو

داتاکان
  • R_p = 14%, R_f = 3%, R_m = 10%, beta = 1.2
  • then add size loading 0.5 with 3% premium and value loading 0.3 with 2% premium
هەنگاوەکان
  1. one-factor expected return = 3 + 1.2 * (10 - 3) = 11.4%
  2. one-factor alpha = 14 - 11.4 = 2.6%
  3. added factor contribution = 0.5 * 3 + 0.3 * 2 = 1.5 + 0.6 = 2.1%
  4. three-factor alpha = 2.6 - 2.1 = 0.5%
alpha = 2.6% under one factor, 0.5% under three

لێکدانەوە

ئەلفای ئەرێنی دەڵێت تۆمارەکە باشتر بووە لەوەی مۆدێلی ڕاگەیەنراو لە بەرکەوتنەکانی پێشبینی کردبوو. ڕاگەیاندنێکە دەربارەی پاشماوەی یەک دیاریکردن، بۆیە هەمیشە دەبێت پێکەوە لەگەڵ مۆدێل و هەڵەی ستاندارد بخوێنرێتەوە.

گریمانەکان

  • Alpha is defined only relative to a specified factor model; there is no model-free alpha.
  • The regression assumes stable loadings over the window and linear factor exposure.
  • Jensen's alpha uses a single market factor; multi-factor specifications such as the three-factor model typically reduce the intercept for the same portfolio.
سنووری فۆرموڵ
  • The estimate carries the regression's standard error and is usually insignificant on records shorter than several years.
  • Selecting the best alpha among many managers or strategies inflates it, so a reported figure is biased upwards by the search that found it.
  • Fees, borrowing costs and non-linear exposures such as option-like payoffs can all masquerade as alpha in a linear model.
