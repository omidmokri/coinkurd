پێناسەی ساکار

زیانی قەبارەیەکی دیاریکراو لە بڕیاردانەدا قورستر دادەنیشێت لە قازانجی هەمان قەبارە. لەدەستدانی ١٠٠ خراپتر هەست پێدەکرێت لەوەی بەدەستهێنانی ١٠٠ باش هەست پێدەکرێت.

پێناسەی پیشەیی

خاسیەتێکی تۆمارکراوی هەڵبژاردن لە ژێر مەترسیدا: دەرئەنجامەکان بەرامبەر خاڵێکی سەرەتا وەک قازانج یان زیان حوکم دەدرێن، و فەنکشنی بەها لەلای زیان لێژتر و توندترە. ئەمە هەمان مەترسی-ترسی نییە؛ مەترسی-ترسی پەیوەستە بە چەماوەیی بەها لە سامانەوە، نەک بە ناهاوسەنگی لە دەوری سفر.

پێناسەی تەکنیکی

لە تیۆری چاوەڕوانیدا، دەرئەنجامەکان وەک لادان لە خاڵێکی سەرەتا دێنە ژوورەوە، بەها لەسەر قازانجەکان چەماوەی ناوەوە و لەسەر زیانەکان چەماوەی دەرەوەیە، و لاقی زیان توندترە؛ هەر ئەمە ئەو شکانی ناسراو لە خاڵی سەرەتادا دروست دەکات. ئەم ناهاوسەنگییە حەزی مەترسی لە ناوچەی زیاندا پێشبینی دەکات: زیانێکی بچووکی دڵنیا زۆر جار ڕەت دەکرێتەوە بەقازانجی یارییەکی هەمان چاوەڕوانی یان خراپتر. قەبارەی پێواندراوی ئەم ناهاوسەنگییە لە نێوان توێژینەوە، ئەرک و گرووپەکاندا جیاوازە.

میکانیزم

هەموو شتێک لە خاڵی سەرەتاوە دێت. لەبەر ئەوەی دەرئەنجامەکان وەک لادان لەو خاڵە کۆد دەکرێن، هەمان پۆزیشن دەتوانێت قازانج یان زیان بێت بەپێی ئەوەی مامەڵەکار خاڵی دەستپێک لەکوێ نیشانە دەکات. پاشان لێژی توندتری لای زیان، داخستنی زیان گرانتر لە ڕاگرتن دەنوێنێت، و چەماوەیی دەرەوە لەسەر زیانەکان یارییەکی زیادە هەرزانتر لەوەی هەیە دەنوێنێت.

بەکارهێنانی پراکتیکی

کێ بەکاری دەهێنێت
هەر کەسێک بڕیارێک بدات کە بەرژەوەندی تێدایە، بەتایبەتی هەر کەسێک بڕیار بدات پۆزیشنێکی لە زیاندا دابخات یان نا.
بۆچی گرنگە
شێوەیەکی دیاریکراو و دووبارەبووەوە ڕوون دەکاتەوە: زوو چەسپاندنی قازانج، ڕاگرتنی زیانبار، و قبوڵکردنی ئەگەری خراپتر بۆ ئەوەی زیان تۆمار نەکرێت.
سنوورەکان
ئەمە دۆزینەوەیەکە دەربارەی هەڵبژاردن، نەک یاسایەکی مامەڵە. قەبارەی پێواندراو بەستراوە بە توێژینەوە و زەمینە، و ڕاگرتنی پۆزیشنێکی زیانبار دەکرێت بەخۆی دروستیش بێت.

هەڵەکانی باو

  • نرخی چوونە ژوورەوە وەک تاکە خاڵی سەرەتا دابنێی.
  • دوورکەوتن لە زیان و مەترسی-ترسی وەک یەک شت بگری.
  • یەک هاوکۆڵکەی زیان وەک نەگۆڕێکی جیهانی بگێڕیتەوە.

نموونەکان

everyday

زۆربەی خەڵک ئەو هەڵدانی دراوە ڕەت دەکەنەوە کە بە ڕووەکە ١٠٠ دەدات و بە پشتەکە ١٠٠ دەبات، هەرچەندە بەهای چاوەڕوانکراوی سفرە. هەمان یاری تەنها کاتێک قبوڵ دەکرێت کە لای براوە بە شێوەی بەرچاو زیاتر بدات.

numeric

بە هاوکۆڵکەی وێنەیی ٢ بۆ دوورکەوتن لە زیان، زیانی ئەگەری ١٠٠ وەک ٢٠٠ کێش وەردەگرێت. بێ‌لایەنی لە یارییەکی پەنجا-پەنجادا ئەوکات پێویستی بە قازانجێکی نزیکەی ٢٠٠ هەیە، نەک ١٠٠.

داتاکان
  • reference point at current wealth
  • loss of 100 and gain of G, each with probability 0.5
  • illustrative loss-aversion coefficient lambda = 2
  • value treated as locally linear so that only the kink matters
هەنگاوەکان
  1. weighted loss = 2 x 100 = 200
  2. indifference requires 0.5 x G = 0.5 x 200
  3. G = 200
a gain of about 200 is needed to offset a possible loss of 100

The coefficient 2 is used only to make the asymmetry visible. The 1979 paper establishes that the loss limb is steeper; it does not fix a universal value for the ratio, and later estimates vary.

بنەمای ماتماتیکی

v(x) = \begin{cases} u(x) & x \geq 0 \\ -\lambda \, u(-x) & x < 0 \end{cases}, \qquad \lambda > 1

ڕێبازی ژمێریاری

خاڵی سەرەتا جێگیر بکە، هەر دەرئەنجامێک وەک لادان لەو خاڵە بنووسە، پاشان قازانج و زیان بە هەمان فەنکشنی قەبارە نرخ بکە و لای زیان لە لامبدا بدە. هەڵبژاردەکان بە بەهای کێشدار بەراورد بکە، نەک بە سامانی چاوەڕوانکراو.

نموونەی کرابوو

داتاکان
  • lambda = 2
  • u treated as the identity locally
  • prospect: gain G with probability 0.5, loss 100 with probability 0.5
هەنگاوەکان
  1. v(-100) = -2 x 100 = -200
  2. 0.5 x v(G) + 0.5 x (-200) = 0
  3. v(G) = 200, so G = 200
indifference at a gain of 200 against a loss of 100

لێکدانەوە

لامبدای گەورەتر لە یەک تەواوی ناوەڕۆکی دوورکەوتن لە زیانە: ئەو شکانە لە خاڵی سەرەتا، نەک چەماوەیی دوور لەو خاڵە. لامبدای یەک، بڕیاردەرێکی ئاسایی مەترسی-ترس بەبێ هیچ ناهاوسەنگییەک بەجێ دەهێڵێت.

گریمانەکان

  • Outcomes are evaluated against a reference point, which the theory treats as given rather than deriving.
  • The 1979 formulation establishes reference dependence, diminishing sensitivity and a steeper loss limb; it does not impose a specific functional form, and the piecewise form above is a generic representation of that shape.
  • Probability weighting is omitted here for clarity; in full prospect theory, probabilities are transformed as well, which changes choices independently of lambda.
سنووری فۆرموڵ
  • Lambda is not a universal constant: reported estimates differ across studies, elicitation methods and populations, so no single number should be quoted as the coefficient.
  • The function describes choices in framed decision tasks. Carrying it over to a specific market decision is an extrapolation, not a result.

Reference dependence and the steeper loss limb are consensus findings and are cited to the 1979 paper. The piecewise value function is given as a generic representation of that shape, because the 1979 paper fixes no functional form and the commonly quoted power parameterisation and the coefficient estimates come from later literature not held in this closed registry; the lambda of 2 in the example is labelled illustrative for that reason.
