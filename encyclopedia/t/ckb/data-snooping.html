پێناسەی ساکار

تاقیکردنەوەی یاسای زۆر لەسەر یەک داتا و ڕاپۆرتکردنی ئەو یەکێکی کە کاری کرد. بە هەوڵی بەس، هەمیشە شتێک کار دەکات، تەنانەت کاتێک هیچ شتێک بەرتەری ڕاستەقینەی نییە.

پێناسەی پیشەیی

ئەو لایەنگری کە کاتێک ئەنجامی ڕاگەیەنراو لە نێو تاقیکردنەوەی ڕانەگەیەنراوی زۆر لەسەر یەک داتا هەڵبژێردرابێت دێتە ناوەوە. ئاستی مانادارێتی یەک تاقیکردنەوە بۆ باشترینی N تاقیکردنەوە گشتگیر نابێت: ئەگەری ئەوەی لانیکەم یەکێک لە N تاقیکردنەوەی سەربەخۆ لە ئاستی ٥ لەسەدیدا تێپەڕێت، یەک کەم ٠.٩٥ بە هێزی Nـە.

پێناسەی تەکنیکی

تاقیکردنەوەی فرە تەواوی کێشەکەیە. ئەگەر N یاسای سەربەخۆ هەریەکەیان لە ئاستی ئالفا تاقی بکرێن و هیچیان بەرتەری نەبێت، ئەگەری مانادارببوونی لانیکەم یەکێک دەکاتە ١ کەم (١ کەم ئالفا) بە هێزی N: لە ئالفای ٠.٠٥ ئەمە نزیکەی ٦٤ لەسەدییە بۆ N بە ٢٠ و نزیکەی ٩٩.٤ لەسەدی بۆ N بە ١٠٠. بۆیە p-بەهای ڕاگەیەنراوی سەرکەوتوو، p-بەهای خۆی نییە. ڕاستکردنەوە هەیە — سنووری بۆنفێرۆنی یانی ئالفا بەسەر N، یان کۆنترۆڵی ڕێژەی دۆزینەوەی هەڵە — بەڵام هەموویان پێویستیان بە زانینی Nـە، و گەڕانی بەڵگەنامەنەکراو هەمان N هەرگیز تۆمار ناکات.

میکانیزم

تاقیکردنەوەی مانادارێتی ڕێژەی هەڵەی یەک تاقیکردنەوەی پێشوەخت دیاریکراو کۆنترۆڵ دەکات. گەڕان هەمان ڕێکار دەکات بە زۆرترین‌گرتن بەسەر تاقیکردنەوەی زۆردا، و دابەشبوونی زۆرترین کلکێکی ڕاستی زۆر قورستری هەیە لە هەر تیروپشکێکی تاک. هیچ شتێک لە داتادا ناگۆڕێت؛ ئەوەی دەگۆڕێت ئەوەیە کە ئامارەی ڕاگەیەنراو ئێستا ئامارەیەکی ڕیزبەندی سنوورییە، و بەراوردکردنی لەگەڵ بەهای بنەڕەتی یەک تاقیکردنەوە، هەڵەی پۆلێنە.

بەکارهێنانی پراکتیکی

کێ بەکاری دەهێنێت
توێژەرانی ژمارەیی، هەر کەسێک کە پێوەرەکان یان تۆڕەکانی پارامەتەر دەپێوێت، و خوێنەری هەر ئەنجامێکی ستراتیژی بڵاوکراوە.
بۆچی گرنگە
ڕوون دەکاتەوە بۆچی ئەم هەموو بەرتەری بەڵگەنامەکراو لەسەر داتای نوێ لەناو دەچێت، بەبێ ئەوەی کەس لە هیچ قۆناغێکدا ناڕاست بووبێت.
سنوورەکان
ڕاستکردنەوەکان پێویستیان بە ژمارەی تاقیکردنەوەکانە کە بە دەگمەن تۆمار دەکرێت، و یاساکانی تاقیکراو زۆرتر پەیوەستن، بۆیە سنووری بۆنفێرۆنی پارێزکارانەیە.

هەڵەکانی باو

  • پێوانەی سەدان یاسا و ڕاپۆرتکردنی p-بەهای یەک-تاقیکردنەوەی سەرکەوتوو.
  • ژماردنی تەنها ئەو وەشانانەی هێڵدرانەوە.
  • سەربەخۆ دانانی تاقیکردنەوەکانی بەتوندی پەیوەست.

نموونەکان

numeric

بیست یاسای سەربەخۆی بێ بەرتەری، هەریەکەیان لە ئاستی ٥ لەسەدی تاقی بکرێن: ئەگەری ئەوەی لانیکەم یەکێک مانادار دەربکەوێت نزیکەی ٦٤ لەسەدییە. بە سەد یاسا نزیکەی ٩٩.٤ لەسەدی — یانی دۆزینەوەیەک گەرەنتیکراوە و بێ‌بەها.

داتاکان
  • alpha = 0.05 per test
  • all null hypotheses true: no rule has any edge
  • tests assumed independent
هەنگاوەکان
  1. N = 20: 0.95^20 = 0.3585, so 1 - 0.3585 = 0.6415
  2. N = 100: 0.95^100 = 0.0059, so 1 - 0.0059 = 0.9941
  3. Bonferroni threshold for N = 100: 0.05 / 100 = 0.0005
about 64% for N = 20 and about 99.4% for N = 100

Independence is the worst case for the bound's size and is unrealistic: correlated rules give a lower probability than this, but the direction of the problem is unchanged.

research

پێوانەیەک دووسەد تێکەڵەی پێوەر و سنوور ڕیز دەکات و ئەوی سەرەوە بە p-بەهای ٠.٠١ دەنووسرێت. ئەو ژمارەیە مانای دەبوو ئەگەر یاساکە پێشتر دیاری کرابووایە؛ وەک باشترینی دووسەد، بەڵگە نییە.

بنەمای ماتماتیکی

P(\text{at least one significant} \mid H_0 \text{ true}) = 1 - (1-\alpha)^{N}, \qquad \alpha_{adj} = \frac{\alpha}{N}

گۆڕاوەکان

\alphaئاستی مانادارێتی جێبەجێکراو بۆ هەر تاقیکردنەوەیەکprobability
Nژمارەی تاقیکردنەوەکانی بەڕاستی کراو، لەگەڵ ئەوانەی ڕانەگەیەنراونcount
\alpha_{adj}سنووری ڕاستکراوەی بۆنفێرۆنی کە ڕێژەی هەڵەی خێزانی کۆنترۆڵ دەکاتprobability

ڕێبازی ژمێریاری

هەر تاقیکردنەوەیەک کراوە بژمێرە، لەوانە وەشانەکانی بەجێماو، خاڵەکانی تۆڕی پارامەتەر و ئەو یاسایانەی بە یەک سەیرکردن لاخران. ئەگەری ئەوەی لانیکەم یەکێک بە ڕێکەوت لە ئاستی هەر تاقیکردنەوەیەک تێپەڕێت بژمێرە. ئەگەر ئەم ئەگەرە گەورە بوو، p-بەهای یەک-تاقیکردنەوەی سەرکەوتوو هیچ زانیارییەک ناگەیەنێت؛ یان سنوور بەرەو خوار ببە بۆ ئالفا بەسەر N، یان یاسای هەڵبژێردراو لەسەر داتایەک پشتڕاست بکە کە لە گەڕاندا هیچ ڕۆڵی نەبووە.

نموونەی کرابوو

داتاکان
  • alpha = 0.05
  • N = 20, then N = 100
  • independent tests, all nulls true
هەنگاوەکان
  1. 1 - 0.95^20 = 1 - 0.3585 = 0.6415
  2. 1 - 0.95^100 = 1 - 0.0059 = 0.9941
  3. alpha_adj for N = 100 is 0.0005
64.2% and 99.4% respectively

لێکدانەوە

دەرئەنجام ئەگەری خێزانی لانیکەم یەک دۆزینەوەی هەڵەیە. دەربڕینێکە دەربارەی گەڕان نەک دەربارەی یاسایەکی دیاریکراو: بەهای بەرز مانای ئەوەیە ئەنجامی سەرکەوتوو تەنانەت ئەگەر بازاڕ بە تەواوی پێشبینینەکراو بووایەش چاوەڕوان دەکرا.

گریمانەکان

  • Tests are assumed independent. Rules sharing data, signals or parameters are correlated, which lowers the probability below this figure without removing the problem; the independent case is the clean upper reference.
  • All null hypotheses are assumed true, so the figure is the probability of a purely spurious discovery, not an estimate of how many real edges exist.
  • N must count every test performed, including unrecorded ones. In practice N is unknown, which is why the correction is often impossible to apply after the fact.
سنووری فۆرموڵ
  • Bonferroni controls the family-wise error rate and is conservative when tests are correlated; false-discovery-rate methods trade some of that strictness for power.
  • The formula bounds the chance of a false positive. It says nothing about the out-of-sample performance of the rule that was selected.
