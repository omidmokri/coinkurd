پێناسەی ساکار

ژمارەیەک کە دەڵێت جوڵەی گەورە و دەگمەن لە کام لای تێکڕا دانیشتوون. نەرێنی یانی سەرسامییە گەورەکان زیانن؛ ئەرێنی یانی قازانجن.

پێناسەی پیشەیی

گۆستاوەری سێیەمی ستاندارکراوی دابەشبوونێک. سفر یانی هاوسەنگی بە دەوری تێکڕا؛ نەرێنی یانی کلکی چەپی درێژ، بۆیە زۆربەی بینینەکان قازانجی بچووکن کە هەر لە ماوەیەکدا بە زیانێکی گەورە دەبڕدرێن — هەمان شێوەی ڕێژەی گەڕانەوەی زۆربەی ستراتیژەکانی فرۆشتنی لەرزۆکی و کاری.

پێناسەی تەکنیکی

ڕێژەی گۆستاوەری ناوەندی سێیەم بەسەر کەعبی لادانی ستاندارد، کە دەکاتە بێ‌پێوەر و بەراوردکراو لە نێوان ئامرازەکان. لەژێر دەستی بینینەکانی سنووری سێ‌توان‌کراوە، بۆیە لە نمونەی بچووکدا ناجێگیرە، و کاتێک گۆستاوەری سێیەم بوونی نەبێت — کە بۆ کلکی بەقەد پێویست قورس دەکرێت — پێناسەنەکراوە.

میکانیزم

سێ‌توان‌کردنی لادانەکان نیشانەکەیان دەپارێزێت، بۆیە زیان و قازانج یەکتر لانابەن: یەک زیانی زۆر گەورە هەموو ئامارەکە نەرێنی دەکات، گرنگ نییە چەند قازانجی بچووک بە دەوریەوە بن. هەر ئەم ناهاوسەنگییە ئەوەیە کە فرۆشتنی دڵنیایی، نووسینی بژاردەی مامەڵە و هەڵگرتنی پۆزیشنی لیڤەرجدار هەموویان دروستی دەکەن.

بەکارهێنانی پراکتیکی

کێ بەکاری دەهێنێت
فرۆشیارانی بژاردەی مامەڵە، مامەڵەکارانی کاری و فرۆشتنی لەرزۆکی، بەڕێوەبەرانی مەترسی کە شێوەی ڕێژەی گەڕانەوەی ستراتیژێک پێداچوونەوە دەکەن، و ئەوانەی بەڕێوەبەرانی هاوشێوە بە ڕێژەی شارپ بەراورد دەکەن.
بۆچی گرنگە
لاری نەرێنی بۆ مامەڵەکاری لیڤەرجدار زۆر گرنگترە لە وەبەرهێنەری تەنها‌کڕیار. خاوەنی بێ‌لیڤەرج دەتوانێت زیانی گەورە بەرگە بگرێت و چاوەڕێی تێکڕا بێت؛ پۆزیشنی لیڤەرجدار بە بانگی مارجین یان لیکویدکردنی ناچاری لە خراپترین خاڵدا دادەخرێت، بۆیە ڕێڕەوەکە پێش گەیشتنی تێکڕا تەواو دەبێت.
سنوورەکان
لاری نمونە لەژێر دەستی چەند بینینی گەورەیە، بۆیە پڕ لەرزەیە، بە پەنجەرەی نمونە هەستیارە، و بە ئاسانی بە لابردنی قەیرانێک جوان دەکرێت.

هەڵەکانی باو

  • بەراوردکردنی دوو تۆمار لەسەر ڕێژەی شارپ بەبێ ئاوڕدانەوە لە لاری پێچەوانە.
  • خوێندنەوەی زنجیرەیەکی درێژی قازانجی بچووک وەک مەترسی نزم.
  • پشت بەستن بە خەمڵاندنی لاری لە چەند دەیەک بینینەوە.

نموونەکان

market

هەژمارێکی فرۆشتنی لەرزۆکی نزیکەی هەموو مانگێک پرێمیۆمێکی بچووک کۆدەکاتەوە، پاشان لە یەک شۆکدا قازانجی ساڵانێک دەگەڕێنێتەوە. تێکڕای ڕێژەی گەڕانەوەی دەتوانێت زۆر باش دەربکەوێت و لاریەکەی بە توندی نەرێنییە؛ وەشانی لیڤەرجداری هەمان هەژمار لەوانەیە هەرگیز لەو شۆکە دەرباز نەبێت.

numeric

پێنج ئەنجامی مانگانە: ١+، ١+، ١+، ١+، ٤−. تێکڕا سفرە و گۆستاوەری دووەم ٤ـە، بەڵام گۆستاوەری سێیەم ١٢−ـە و لاری ١.٥− دەدات — چوار مانگی ئاسوودە و یەکێک کە هەموویان دەسڕێتەوە.

داتاکان
  • observations: +1, +1, +1, +1, -4
  • n = 5
  • method-of-moments (population) formula applied to the sample
هەنگاوەکان
  1. mean = (1+1+1+1-4)/5 = 0
  2. m2 = (1+1+1+1+16)/5 = 20/5 = 4
  3. m3 = (1+1+1+1-64)/5 = -60/5 = -12
  4. skewness = m3 / m2^1.5 = -12 / 4^1.5 = -12 / 8
skewness = -1.5

Verified numerically. This is the moment-ratio form. The bias-adjusted sample estimator multiplies it by sqrt(n(n-1))/(n-2), which for n = 5 gives -1.5 x 1.4907 = -2.236, so the reported figure depends on which estimator the software uses.

بنەمای ماتماتیکی

\gamma_1 = \frac{E\!\left[(X-\mu)^3\right]}{\sigma^3}, \qquad b_1 = \frac{\frac{1}{n}\sum_{i=1}^{n}(x_i-\bar{x})^3}{\left[\frac{1}{n}\sum_{i=1}^{n}(x_i-\bar{x})^2\right]^{3/2}}

ڕێبازی ژمێریاری

تێکڕا بژمێرە. لە هەر بینینێک کەمی بکە. تێکڕای لادانەکانی سێ‌توان‌کراو گۆستاوەری سێیەم و تێکڕای لادانەکانی چوارگۆشەکراو گۆستاوەری دووەم دەدات. سێیەم بەسەر دووەمی توانی یەک‌ونیو دابەش بکە. سەرەتا نیشانە ڕابگەیەنە و پاشان قەبارە، و بڵێ کام خەمڵێنەر بەکارهاتووە، چونکە وەشانی ڕاستکراوەوە لەسەر هەمان داتا ژمارەیەکی دیکە دەدات.

نموونەی کرابوو

داتاکان
  • observations +1, +1, +1, +1, -4
  • n = 5
هەنگاوەکان
  1. mean = 0
  2. m2 = 20/5 = 4
  3. m3 = -60/5 = -12
  4. m2^1.5 = 4^1.5 = 8
  5. b1 = -12/8
b1 = -1.5 (method of moments); the bias-adjusted estimator gives -2.236 on the same data

لێکدانەوە

نیشانە هەمان پەیامەکەیە. لاری نەرێنی دەڵێت بینینەکانی دەگمەن لە لای زیانەوەن، و ئەمە بە هاتنی لیڤەرج ڕاستەوخۆ دەبێتە مەترسی ڕێڕەو: زیان پێش تێکڕا دەگەیشتێت. لێکدانەوەی قەبارە قورسترە، چونکە بە خەمڵێنەر و پەنجەرەی نمونە بەستراوە.

گریمانەکان

  • The third moment must exist; for sufficiently heavy tails it does not, and the statistic then has no population value to estimate.
  • Several estimators are in common use — the plain moment ratio shown here and the bias-adjusted version multiplying by sqrt(n(n-1))/(n-2) — and they disagree materially in small samples, so the convention must be stated.
  • The measure assumes the observations come from one distribution; a regime change inside the window produces skewness that describes neither regime.
سنووری فۆرموڵ
  • A single extreme observation can dominate the estimate, so the statistic is fragile and sensitive to the start and end dates of the sample.
  • Zero skewness does not mean symmetric risk: a distribution can be symmetric in its third moment while still carrying very heavy tails on both sides.
