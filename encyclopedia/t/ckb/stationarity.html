پێناسەی ساکار

زنجیرەیەک کاتێک جێگیرە کە ڕەوشتی ئامارییەکەی نەجوڵێت: هەمان تێکڕا، هەمان بڵاوبوونەوە، و هەمان پەیوەندی نێوان خاڵەکانی دراوسێ لە هەر ساتێکی کاتدا.

پێناسەی پیشەیی

جێگیری لاواز سێ مەرج دەخوازێت: تێکڕای جێگیر، جیاوازی جێگیر و سنووردار، و خۆکۆڤاریانسێک کە تەنها بە مەودای دوو بینینەوە بەستراوە نەک بە شوێنیان لە زنجیرەکەدا. نرخەکان زۆرتر ناجێگیرن؛ ڕێژەی گەڕانەوە مۆدێل دەکرێت چونکە زۆر نزیکترە لە جێگیری.

پێناسەی تەکنیکی

پڕۆسەیەک جێگیری لاواز یان جێگیری کۆڤاریانسە ئەگەر E[X_t] بۆ هەر t یەکسان بە بەهای جێگیری μ بێت، Var(X_t) جێگیرێکی سنووردار بێت، و Cov(X_t, X_t+h) فەنکشنێکی بە ناوی γ(h) تەنها لە مەودا بێت. جێگیری توند سەرباری ئەوە دەخوازێت تەواوی دابەشبوونی هاوبەش بەرامبەر گواستنەوەی کات نەگۆڕ بێت. هەنگاوی هەڕەمەکی هیچیان جێبەجێ ناکات: جیاوازییەکەی بە هێڵی لەگەڵ کات گەورە دەبێت، بۆیە تێکڕا و جیاوازییەکی جێگیر بۆ هەڵسەنگاندن نییە.

میکانیزم

نزیکەی هەموو هەڵسەنگێنەرێکی ستاندارد — تێکڕا، جیاوازی، پەیوەندی ئاماری، هەڵسەنگێنەری ڕێگرێشن — کۆمەڵگەیەکی جێگیر لە پشتی نمونەدا پێشفەرز دەکەن. زنجیرەی ناجێگیر کۆمەڵگەیەکی وا نییە: هەر پەنجەرەیەک لە کۆمەڵگەیەکی جیاوازەوە هاتووە. ئەوسا ئامارەی نمونە پەنجەرەکە دەپێوێت نەک پڕۆسەکە، و تاقیکردنەوەی گرنگی لەسەر ئەو بنەمایە دڵنیاییەک ڕادەگەیەنێت کە بوونی نییە.

بەکارهێنانی پراکتیکی

کێ بەکاری دەهێنێت
توێژەرانی ژمارەیی کە لە داتای نرخ تایبەتمەندی دروست دەکەن، مامەڵەکارانی جووت کە سپرێدێک تاقی دەکەنەوە، و هەر کەسێک کە ڕێگرێشن یان پەیوەندی ئاماری لەسەر زنجیرەی بازاڕ دەکات.
بۆچی گرنگە
تاقیکردنەوەی بۆ ئەوە دیاری دەکات ئایا دەکرێت متمانە بە پەیوەندی پێوراو بکرێت و ئایا دەبێت زنجیرەکە یەکەم بکرێتە ڕێژەی گەڕانەوە.
سنوورەکان
زنجیرەی ڕێژەی گەڕانەوە تەنها بە نزیکەیی جێگیرە: لەرزۆکی نرخ خڕۆکە دەبێت، بۆیە جیاوازی جێگیر نییە و بارودۆخ بەبێ ئاگادارکردنەوە دەگۆڕێت.

هەڵەکانی باو

  • پەیوەندی ئاماری نێوان دوو زنجیرەی نرخ لە جیاتی ڕێژەی گەڕانەوەیان.
  • خوێندنەوەی R²ی بەرز نێوان دوو زنجیرەی ئاراستەدار وەک پەیوەندی.
  • وا دابنێی یەک تاقیکردنەوەی جێگیری پرسیارەکە بۆ هەموو بارودۆخەکان دەچەسپێنێت.

نموونەکان

numeric

هەنگاوی هەڕەمەکی بە هەنگاوی ڕۆژانەی ١٪ دوای ١٠٠ ڕۆژ لادانی ستانداردی ١٠٪ و دوای ٤٠٠ ڕۆژ ٢٠٪ـی هەیە. جیاوازی لەگەڵ کاتی تێپەڕیو ڕێکە، بۆیە جیاوازییەکی جێگیر بۆ هەڵسەنگاندن نییە؛ هەمان شکستی پێناسەکەری جێگیری.

داتاکان
  • daily step standard deviation sigma = 1%
  • steps independent with zero mean
  • variance of a random walk after t steps = t * sigma^2
هەنگاوەکان
  1. t = 100: variance = 100 * 0.0001 = 0.01, sd = 10%
  2. t = 400: variance = 400 * 0.0001 = 0.04, sd = 20%
  3. for comparison, an AR(1) with phi = 0.95 has unconditional variance sigma^2 / (1 - 0.95^2) = 10.26 * sigma^2, a finite constant
random-walk variance grows without bound; the AR(1) variance converges to a fixed value

The contrast is the whole point: the AR(1) is stationary because 1 - phi^2 is positive. At phi = 1 the denominator vanishes and the process becomes a random walk.

market

دوو سامانی بێ‌پەیوەندی هەردووکیان لە ماوەیەکدا ئاراستەی سەرکەوتوویان هەیە. ڕێگرێشنی نرخی یەکێکیان بەسەر ئەوی تردا هەڵسەنگێنەرێکی گەورە و R²ێکی بەرز دەدات، تەنها لەبەر ئەوەی هەردووکیان ئاراستەیەکی هاوبەشیان هەیە. هەمان ڕێگرێشن لەسەر ڕێژەی گەڕانەوە دووبارە بکەوە و پەیوەندییەکە نامێنێت.

بنەمای ماتماتیکی

E[X_t] = \mu \;\; \forall t, \qquad \mathrm{Var}(X_t) = \sigma^2 < \infty, \qquad \mathrm{Cov}(X_t, X_{t+h}) = \gamma(h)

گۆڕاوەکان

\muتێکڕای نامەرجدار، لە هەر بەروارێکدا یەکسانsame as X
\sigma^2جیاوازی نامەرجدار؛ دەبێت سنووردار و جێگیر بێتsquared units of X
\gamma(h)خۆکۆڤاریانس لە مەودای h؛ فەنکشنێک تەنها لە hsquared units of X
hمەودا، ژمارەی خول لە نێوان دوو بینینperiods

ڕێبازی ژمێریاری

سێ مەرجەکە لەسەر زنجیرەی مەبەست بپشکنە. لە پراکتیکدا: تێکڕای جوڵاو و لادانی ستانداردی جوڵاو بکێشە و ببینە ئایا دەجوڵێن؛ پاشان تاقیکردنەوەی ڕەچەی یەکە ئەنجام بدە. ئەگەر زنجیرەی ئاست دەرنەچوو، یەک جار جیاوازی بگرە — بۆ نرخ ئەوە مانای گرتنی ڕێژەی گەڕانەوەیە — و دووبارە تاقی بکەوە. زنجیرەی جیاکراو مۆدێل بکە نەک ئاستەکە.

نموونەی کرابوو

داتاکان
  • random walk P_t = P_t-1 + e_t with sd(e) = 1% and independent steps
  • AR(1) X_t = 0.95 * X_t-1 + e_t with the same innovation sd
هەنگاوەکان
  1. random walk: Var(P_t) = t * sigma^2 = t * 0.0001
  2. t = 100 gives sd = 10%; t = 400 gives sd = 20%
  3. AR(1): Var(X) = sigma^2 / (1 - phi^2) = 0.0001 / 0.0975
  4. = 0.001026, sd = 3.20%, independent of t
the random walk has no constant variance; the AR(1) variance is fixed at 3.20%

لێکدانەوە

جێبەجێکردنی سێ مەرجەکە مانای ئەوەیە یەک تێکڕا، یەک بڵاوبوونەوە و یەک پێکهاتەی بەستراوی تەواوی زنجیرە ڕوون دەکەنەوە، بۆیە هەڵسەنگاندنی نمونە هەڵسەنگاندنی شتێکی جێگیرە. جێبەجێ نەکردنیان مانای ئەوەیە هەر ئامارەیەک تەنها بۆ پەنجەرەی خۆی بەکار دێت.

گریمانەکان

  • Weak stationarity constrains only the first two moments; it does not require normality and does not imply strict stationarity.
  • Finite variance is part of the definition, so a series with infinite variance is non-stationary by construction.
  • Unit-root tests have low power in short samples and competing tests take opposite null hypotheses, so a single test result is weak evidence either way.
سنووری فۆرموڵ
  • Differencing removes a trend but also destroys information about the level, which cointegration methods recover instead.
  • Financial return series show volatility clustering, so they violate constant variance even when a unit-root test clears them.
  • Stationarity over one sample is not stationarity over the next; a structural break makes the property time-local.
