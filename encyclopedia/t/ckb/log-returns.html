پێناسەی ساکار

لۆگاریتمی سروشتیی ڕێژەی دوو نرخ. ڕێژەی گەڕانەوەی لۆگاریتمی بەدرێژایی کات کۆدەبێتەوە، بۆیە دەکرێت زنجیرەیەکیان بە سادەیی کۆ بکرێتەوە بۆ وەدەستهێنانی کۆی گشتی.

پێناسەی پیشەیی

ڕێژەی گەڕانەوەی بەردەوام لێکدراو، یەکسان بە لۆگاریتمی سروشتیی یەک زیاد ڕێژەی گەڕانەوەی ساکار. بەدرێژایی کات کۆدەبێتەوە بەڵام لە نێوان سامانەکانی پۆرتفۆلیۆدا نا؛ ڕێژەی ساکار بە تەواوی پێچەوانەیە، و هەمان ئەم نەهاوسەنگییە دیاری دەکات کامە بەکاربهێنرێت.

پێناسەی تەکنیکی

بۆ نرخی P لە t−١ و t، ڕێژەی گەڕانەوەی لۆگاریتمی یەکسانە بە ln ی P_t بەسەر P_{t−١}، و بە هەمان شێوە عەینەن یەکسان بە ln ی یەک زیاد ڕێژەی ساکار. کۆبوونەوە لە کاتدا لە لۆگاریتمی بەرهەمەوە دێت، بۆیە ڕێژەی لۆگاریتمیی فرە‌خولی کۆی بەشەکانی تاک‌خولییە. کۆکردنەوەی پۆرتفۆلیۆ شکست دەهێنێت چونکە لۆگاریتمی کۆی کێشدار یەکسان نییە بە کۆی کێشداری لۆگاریتمەکان. ڕێژەی لۆگاریتمی لە خوارەوە بێ‌سنوورە، لە کاتێکدا ڕێژەی ساکار ناتوانێت لە نەرێنی یەک خوارتر بچێت.

میکانیزم

لێکدان ڕێژەکانی گشتی لێک دەدات، و لۆگاریتم لێکدان دەکاتە کۆکردنەوە. هەمان ئەم تایبەتمەندییە ڕێژەی لۆگاریتمی دەکاتە پێوەری سروشتیی کات: کۆکردنەوە، پێوانەکردنی کاتیی جیاوازی و مۆدێلەکانی کاتی بەردەوام هەموو ئاسان دەبن. بە پێچەوانە، پۆرتفۆلیۆ ڕێژەکانی گشتیی کێشدار بە بەها کۆ دەکاتەوە، و هیچ لۆگاریتمێک بەسەر کۆدا دابەش نابێت؛ نەهاوسەنگییەکە لێرەوە دێت.

بەکارهێنانی پراکتیکی

کێ بەکاری دەهێنێت
توێژەرانی ژمارەیی کە زنجیرەی ڕێژەی گەڕانەوە دروست دەکەن، مۆدێلکەرانی لەرزۆکی نرخ، نرخاندنەرانی بژاردە، و هەر کەسێک کە کارایی بەدرێژایی کات کۆ دەکاتەوە.
بۆچی گرنگە
کۆکردنەوەی ڕێژەی لۆگاریتمی ژمارەی فرە‌خولی بە وردی دەدات و جیاوازییەکەی بە هێڵی لەگەڵ کات پێوانە دەبێت؛ ئەو شتەی ڕێژەی ساکار نایکات.
سنوورەکان
ناکرێت کێشدار بکرێن و بگەن بە ڕێژەی گەڕانەوەی پۆرتفۆلیۆ، ئەوە نین کە لە ڕاپۆرتی کڕیاردا دێت، و لە جوڵەی گەورەدا جیاوازییەکی بەرچاو لەگەڵ ڕێژەی ساکار هەیە.

هەڵەکانی باو

  • کێشدارکردنی ڕێژەی لۆگاریتمی بە کێشی پۆرتفۆلیۆ بۆ ڕێژەی پۆرتفۆلیۆ.
  • ڕاپۆرتکردنی ڕێژەی لۆگاریتمی بۆ کڕیار وەک قازانجی لەسەدی ڕاستەقینە.
  • تێکەڵکردنی ڕێژەی لۆگاریتمی و ساکار لە یەک خشتەی کارایی.

نموونەکان

numeric

٥٠٪ سەرەوە پاشان ٥٠٪ خوارەوە: ڕێژەی لۆگاریتمی ‎+٠.٤٠٥٤٦٥ و ‎−٠.٦٩٣١٤٧ کۆیان دەکاتە ‎−٠.٢٨٧٦٨٢، و e بەم توانە ٠.٧٥ـە؛ یانی ٢٥٪ زیان. کۆکردنەوەی ڕێژەی ساکار سفر دەدات، کە هەڵەیە.

داتاکان
  • period 1 simple return = +50%
  • period 2 simple return = -50%
هەنگاوەکان
  1. ln(1 + 0.50) = +0.405465
  2. ln(1 - 0.50) = -0.693147
  3. sum = -0.287682, which equals ln(0.75)
  4. exp(-0.287682) = 0.75, so the simple total return is -25%
  5. by contrast 0.50 + (-0.50) = 0, which is not the realised result
total log return -0.287682; total simple return -25%

Verified arithmetic. This is the clearest demonstration that simple returns are not additive across time while log returns are.

pitfall

جووتێک بە کێشی یەکسان: سامانێک ‎+١٠٪، ئەوی تر ‎−١٠٪. پۆرتفۆلیۆ یەکسان کۆتایی دێت و کۆی کێشداری ڕێژەی ساکار بە تەواوی ٠٪ دەدات. کێشدارکردنی ڕێژەی لۆگاریتمی ‎−٠.٥٠٪ دەدات؛ زیانێک کە هەرگیز ڕووی نەداوە.

بنەمای ماتماتیکی

r^{\log}_t = \ln\!\left(\frac{P_t}{P_{t-1}}\right) = \ln\!\left(1 + r^{\text{simple}}_t\right), \qquad r^{\log}_{1:T} = \sum_{t=1}^{T} r^{\log}_t

ڕێبازی ژمێریاری

هەر نرخی داخستن بەسەر نرخی داخستنی پێشوودا دابەش بکە و لۆگاریتمی سروشتی بگرە، یان بە هەمان شێوە لۆگاریتمی یەک زیاد ڕێژەی ساکار. بۆ کۆکردنەوە لە کاتدا، ڕێژەکانی لۆگاریتمی کۆ بکەوە. بۆ گەڕانەوە بۆ لەسەدی، لە کۆیەکە توان بگرە و یەک لێ کەم بکەوە. بۆ کۆکردنەوە لە نێوان سامانەکان، یەکەم بگەڕێوە بۆ ڕێژەی ساکار و تەنها پاشان کێشی پۆرتفۆلیۆ جێبەجێ بکە.

نموونەی کرابوو

داتاکان
  • period 1: +50% simple
  • period 2: -50% simple
هەنگاوەکان
  1. r_log,1 = ln(1.50) = 0.405465
  2. r_log,2 = ln(0.50) = -0.693147
  3. sum = -0.287682
  4. ln(0.75) = -0.287682, so the two agree exactly
  5. exp(-0.287682) - 1 = -0.25
cumulative log return -0.287682; cumulative simple return -25%

لێکدانەوە

ڕێژەی لۆگاریتمیی سفر مانای بێ‌گۆڕانە، ئەرێنی مانای قازانج و نەرێنی مانای زیان، بەڵام ئەم ژمارەیە لەسەدی نییە. تەنها دوای توان‌گرتن دەبێتە ئەو ژمارەیەی ڕاپۆرتی هەژمار نیشانی دەدات.

گریمانەکان

  • Prices are strictly positive, so the logarithm is defined. A price reaching zero gives a log return of minus infinity.
  • The identity with ln of one plus the simple return is exact, not an approximation; the familiar claim that log and simple returns are 'about the same' holds only for small moves.
  • Dividends, funding and fees must be built into the price series first, otherwise both return measures are incomplete in the same way.
سنووری فۆرموڵ
  • Not additive across assets: a portfolio log return is not the weighted average of component log returns.
  • Not the figure reported to clients or used in most performance standards, which use simple returns.
  • Unbounded below, so distributional assumptions that look harmless on log returns can imply impossible simple returns.
