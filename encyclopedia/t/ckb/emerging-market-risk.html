پێناسەی ساکار

مەترسیەکانی زیادەی وەبەرهێنان لە ئابوورییەکی گەشەسەندوو: دراو دەتوانێت دابەزێت، هاتنی پارە لە دەرەوە دەتوانێت ببڕێت، یاساکان دەتوانن بگۆڕێن، و فرۆشتن دەتوانێت هەر لەو کاتەی پێویستت پێیەتی قورس بێت.

پێناسەی پیشەیی

پاکەتی مەترسی دراوی، دابینکردنی دەرەکی، سیاسەتی، یاسایی و ئاسانی ئاڵوگۆڕ کە بە سامانەکانی ئابووریەکانی بەستراو بە سەرمایەی بیانی نووساوە. ئەم مەترسیەکان پەیوەستن: شۆکێکی دابینکردنی جیهانی زۆرتر هاوکات دراو، بازاڕی پسووڵە و پشکی ناوخۆ لێدەدات.

پێناسەی تەکنیکی

نەخشەی تایبەتمەند «وەستانی لەپڕ»ـە: هاتنی سەرمایە دەگەڕێتەوە، بەهای دراو دادەبەزێت، خزمەتکردنی قەرزی بە دراوی بیانی بە دراوی ناوخۆ بەرز دەبێتەوە، و دەسەلاتداران دەبێت لە نێوان بەرگریکردن لە دراو، کەمکردنەوەی ڕێژە بۆ پاڵپشتی چالاکی، و سنووردارکردنی جوڵەکان هەڵبژێرن. جۆراوجۆرکردنی سامان لە ناو هەمان پۆلدا هەر لەو ماوەکاندا بە خراپی کار دەکات، چونکە جوڵێنەری هاوبەش دۆخی دابینکردنی دەرەکییە نەک بنەماکانی ناوخۆ.

میکانیزم

ئابووریەکانی هاوردەکاری سەرمایە بەشێک لە وەبەرهێنانیان لە دەرەوە دابین دەکەن، زۆرتر بە دراوێک کە خۆیان بڵاوی ناکەنەوە. کاتێک دابینکردنی جیهانی توند دەبێت، حەزی قەرزدەر بۆ نوێکردنەوەی ئەو دارایی بە هۆکارێکی بێ‌پەیوەندی بە قەرزدار دادەبەزێت و نرخی دراو ڕێک دەخرێتەوە. جوڵەی دراو پاشان تێچووی ناوخۆیی قەرزی بیانی بەرز دەکاتەوە و هەمان ئەو شۆکەی دروستی کردبوو قووڵتر دەکات.

بەکارهێنانی پراکتیکی

کێ بەکاری دەهێنێت
دابەشکەرانی سەرسنووری، وەبەرهێنەرانی پسووڵەی بە دراوی ناوخۆ، خەزێنەدارانی کۆمپانیا کە لە دەرەوە دابین دەکەن، و تیمەکانی مەترسی کە سنووری وڵات دادەنێن.
بۆچی گرنگە
ڕوون دەکاتەوە بۆچی بەرهەمی ناوخۆ دەتوانێت ڕاکێشەر دەربکەوێت و دوای کاریگەری دراوی و دابینکردن زیان بدات، و بۆچی سنووری وڵات جیا لە سنووری کەرت هەیە.
سنوورەکان
ئەم ناوە ئابووری زۆر جیاواز دەگرێتەوە و یەک‌کۆکردنەوەیان جیاوازی گەورە لە یەدەگ، دراوی قەرز و دامەزراوەکان دەشارێتەوە؛ پەیوەندیەکانی ئامارییش لە نێوان ماوەکاندا دەگۆڕێن.

هەڵەکانی باو

  • بەراوردی بەرهەمی دراوی ناوخۆ بەبێ ژماردنی مەترسی دراوی.
  • گشت ئەم پۆلی سامان وەک یەک بەرکەوتە دابنێی.
  • پاڵپشتی بە جۆراوجۆرکردن لە ناو هەمان پۆل لە کاتی شۆکی دابینکردن.

نموونەکان

numeric

پسووڵەیەکی ناوخۆ بە دراوی خۆی ١٢ لەسەدی بەرهەم دەدات. ئەگەر ئەو دراوە بە درێژایی ساڵ ١٥ لەسەدی بەرامبەر دراوی بنەڕەتی وەبەرهێنەر دابەزێت، گەڕانەوە بە دراوی بنەڕەت نزیکەی نێگەتیڤ ٤.٨ لەسەدییە.

داتاکان
  • local-currency return = +12% = 0.12
  • currency depreciation against the base currency = 15%, so the rate factor is 0.85
  • no hedge
هەنگاوەکان
  1. 1.12 x 0.85 = 0.952
  2. return in base currency = 0.952 - 1 = -0.048
about -4.8% in base-currency terms

Both inputs are invented. The point is that a local yield is not a return until the currency leg is included.

market

دۆخی دابینکردنی دەرەکی توند دەبێت. چەند ئابووری بێ‌پەیوەندی لە هەمان هەفتەدا دەرچوونی سەرمایە دەبینن، دراو و پسووڵەی ناوخۆیان پێکەوە دادەبەزن، و هەواڵی ئابووری ناوخۆ بەنزیکەیی هیچ لەم کاتبەندی ڕوون ناکاتەوە.

مەترسی قەرزدان

مەترسی کرێدیت ئەگەری نەتوانینی قەرزدارێکی دیاریکراوە لە پارەدان. مەترسی بازاڕەکانی سەرهەڵدەر ئەوەش لەخۆدەگرێت، بەڵام مەترسی دراوی، سیاسەتی، یاسایی و ئاسانی ئاڵوگۆڕیش کە دەتوانن زیان دروست بکەن لە کاتێکدا هەموو قەرزدارەکان بەردەوام دەبن لە پارەدان.
