پێناسەی ساکار

ژمارەیەکی زیان لەگەڵ ئاستێکی دڵنیایی پێوەی: ئەو بڕەی پۆرتفۆلیۆ لە ڕۆژێکی ئاساییدا نابێت زیاتر لەو لەدەست بدات، و ئاسایی یانی هەموو ڕۆژان جگە لە خراپترین ڕۆژ لە سەد ڕۆژدا.

پێناسەی پیشەیی

ئەو سنووری زیانەی چاوەڕوان دەکرێت پۆرتفۆلیۆ تەنها بە ئەگەرێکی دیاریکراو و لە ئاسۆیەکی دیاریکراودا لێی تێپەڕێت. گێڕانەوەی پێویستی بە هەر سێ بەشە: ئاسۆ، ئاستی دڵنیایی و بڕی پارە؛ و گۆڕینی هەر یەکێکیان ژمارەکە دەگۆڕێت.

پێناسەی تەکنیکی

پارچەیەکە لە دابەشبوونی زیان کە یان بە پارامەتری لە گرێبەستێکی لەرزۆکییەوە خەمڵێنرێت، یان بە مێژووی لە نموونەی ئەزموونییەوە، یان بە ئاسانکاری. خراپترین حالەت نییە و وەک پێوەری مەترسی هاوبەستیش نییە، چونکە بە شێوەیەکی گشتی ژێر-کۆکەر نییە: بەهای لە مەترسیدای دەفتەرێکی تێکەڵ دەکرێت لە کۆی بەشەکانی زیاتر بێت، و هەر ئەمەش هۆکاری جێگرتنەوەی بە کەمیی چاوەڕوانکراو لە چەند چوارچێوەیەکی ڕێسایی بوو.

میکانیزم

بەهای لە مەترسیدای پارامەتری بە گرتنی شێوەیەک بۆ دابەشبوونی ڕێژەی گەڕانەوە کار دەکات؛ بۆیە یەک ژمارەی لەرزۆکی لەگەڵ لێکدەرێکی پارچە، ژمارەیەکی زیان دروست دەکات. هەر ئەمەش کەموکوڕییەکەیەتی: لێکدەرەکە تەنها کاتێک ڕاستە کە شێوەکە ڕاست بێت، و دابەشبوونی ڕاستەقینەی ڕێژەی گەڕانەوە دوماڵێکی ئەستوورتری لە نۆرماڵ هەیە؛ بۆیە پارچەکە دوورتر دانیشتووە لەوەی مۆدێل دایدەنێت.

بەکارهێنانی پراکتیکی

کێ بەکاری دەهێنێت
بەشەکانی مەترسی لە بانک و سندوقەکان، ڕێکخەرە یاساییەکان کە ڕاپۆرتی سەرمایە دەخوێننەوە، و هەر تیمێک کە سنووری فەرمی زیانی بە شێوەی پارچە دەربڕدراوە.
بۆچی گرنگە
دەفتەرێکی تەواو دەکاتە یەک ژمارەی پارەیی بەراوردکراو، و هەر ئەمەش سنووردانان، کۆکردنەوە و ڕاپۆرتکردن لە نێوان تیمەکان و پۆلەکانی سامان کرداری دەکات.
سنوورەکان
دەربارەی هەموو ئەوەی ئەوبەری پارچەکەیە بێدەنگە. زۆرترین نییە، زۆر بە پەنجەرەی خەمڵاندن پەیوەستە، و لە دراوی ئەنکریپتیدا مەترسی دوماڵ بە توندی کەم دەخەمڵێنێت.

هەڵەکانی باو

  • وەرگرتنی بەهای لە مەترسیدا وەک خراپترین حالەت نەک سنوورێک.
  • بەراوردی ژمارەکان کە لە ئاسۆ یان دڵنیایی جیاوازدا ژمێردراون.
  • خەمڵاندن لە نموونەیەکی هێمن و بەکارهێنانی لە ماوەی فشاردا.

نموونەکان

market

تیمێک بەهای لە مەترسیدای یەک ڕۆژ بە دڵنیایی ٩٩ لەسەدی ڕادەگەیەنێت وەک دوو لەسەدی بەهای دەفتەر. لە هەفتەیەکدا کە زیان سێ ڕۆژی بەدوای یەک لێی تێپەڕێت، مۆدێل هیچ ڕێسایەکی نەشکاندووە؛ لە سەرەتاوە تەنها ژمارەی ڕوودانێک بەڵێن دابوو، نەک سنوورێک.

numeric

پۆرتفۆلیۆیەکی یەک ملیۆنی بە لەرزۆکی ڕۆژانەی دوو لەسەدی، لە دڵنیایی ٩٩ لەسەدی و ئاسۆی یەک ڕۆژ، بەهایەکی لە مەترسیدای نزیک ٤٦٬٥٠٠ دەدات. هەمان دەفتەر لە دە ڕۆژدا بە ڕەگی دە پێوانە دەگرێت و دەگاتە نزیکەی ١٤٧٬٠٠٠، ئەگەر ڕێژەی گەڕانەوەکان سەربەخۆ بن.

داتاکان
  • portfolio value V = 1,000,000 (account currency)
  • daily return volatility sigma = 0.02
  • confidence 99 percent, so z = 2.326
  • expected return term set to zero
  • horizon h = 1 day, then h = 10 days
هەنگاوەکان
  1. one-day VaR = 2.326 x 0.02 x 1,000,000 = 46,520
  2. ten-day scaling factor = sqrt(10) = 3.1623
  3. ten-day sigma = 0.02 x 3.1623 = 0.063246
  4. ten-day VaR = 2.326 x 0.063246 x 1,000,000 = 147,109
one-day 99 percent VaR of about 46,520, ten-day about 147,100

The square-root-of-time scaling assumes independent, identically distributed returns. Crypto returns cluster in volatility, so the ten-day figure is optimistic. Nothing here says what happens on the one day in a hundred that breaches the threshold.

بنەمای ماتماتیکی

\mathrm{VaR}_{\alpha,h} = V \left( z_{\alpha}\,\sigma\sqrt{h} - \mu h \right)

ڕێبازی ژمێریاری

لەرزۆکی ڕێژەی گەڕانەوە لەسەر پەنجەرەیەکی هەڵبژێردراو بخەمڵێنە و ئاسۆ و ئاستی دڵنیایی ڕابگەیەنە. لەرزۆکی بە لێکدان لە ڕەگی ژمارەی خولەکان بۆ ئاسۆکە پێوانە بکە. لە پارچەی ئاستی دڵنیایی و پاشان لە بەهای پۆرتفۆلیۆ بیدە. ئەگەر بەشی تێکڕا دەهێڵیتەوە، ڕێژەی گەڕانەوەی چاوەڕوانکراوی ئاسۆکە کەم بکە.

نموونەی کرابوو

داتاکان
  • V = 1,000,000
  • sigma = 0.02 per day
  • h = 1 day
  • alpha = 99 percent, z = 2.326
  • mu = 0
هەنگاوەکان
  1. sigma x sqrt(h) = 0.02 x 1 = 0.02
  2. z x 0.02 = 2.326 x 0.02 = 0.04652
  3. VaR = 0.04652 x 1,000,000
one-day 99 percent VaR = 46,520 account currency

لێکدانەوە

ئەم ژمارەیە سنوورێکە لەگەڵ ژمارەی ڕوودانێک و بەم شێوەیە دەخوێنرێتەوە: نزیکەی یەک ڕۆژ لە سەد ڕۆژدا، زیان دەبێت لەمە زیاتر بێت. زۆرترین نییە و هیچ زانیارییەک نادات کە چەند زیاتر. کەمیی چاوەڕوانکراو، یانی تێکڕای زیان بەمەرجی تێپەڕاندنی سنوورەکە، وەڵامی ستانداردی هەمان ئەو بۆشاییەیە.

گریمانەکان

  • The parametric form assumes a normal return distribution. Real series, and crypto series in particular, have fatter tails, so this form understates the quantile.
  • Square-root-of-time scaling assumes independent and identically distributed returns with no volatility clustering and no autocorrelation.
  • Volatility is estimated from a finite window and is therefore itself an estimate, with the window choice materially changing the result.
  • Historical VaR replaces the distributional assumption with the sample, but then cannot produce a loss larger than the worst one in the sample, which is a different way of understating the tail.
  • Linear exposures. Portfolios with options need a delta-gamma or simulation approach rather than this closed form.
سنووری فۆرموڵ
  • It says nothing whatsoever about the size of losses beyond the quantile; two books with identical VaR can have very different tails.
  • It is not sub-additive in general, so VaR does not aggregate cleanly across desks and can penalise diversification; expected shortfall is coherent and is used for this reason.
  • In crypto, correlated liquidations, venue outages and twenty-four-hour trading all break the assumptions behind the estimate at exactly the moment it matters.

لە ڕووی زمانی، ماتماتیکی یان یاساییەوە وەک نادڵنیا نیشانە کراوە.

The parametric formula and the quantile multipliers are standard, but estimation choices are not: window length, whether the mean term is carried, and parametric versus historical versus simulated estimation all give different numbers for the same book, and practitioners disagree about which is appropriate. The claim that historical VaR understates crypto tail risk is a judgement supported by the general literature on fat tails and the BIS discussion of crypto leverage, not a precise measured result. The Kurdish headword بەهای لە مەترسیدا is this project's proposed coinage; the English abbreviation VaR is retained beside it and native-expert review is needed.
