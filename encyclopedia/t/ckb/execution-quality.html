پێناسەی ساکار

ئەوەی جێبەجێکردنی ڕاستەقینەی تۆ بەراورد بەو نرخەی ئامانجت بوو چەند باش بوو، کاتێک هەموو تێچووەکان ژمێردران.

پێناسەی پیشەیی

پێوانەی ئەوەی جێبەجێکردن بەڕاستی چەند تێچووی هەبوو، بەرامبەر پێوەرێکی دیاریکراو. پێوەری ڕاستگۆ کەمینەی جێبەجێکردنە: ماوەی نێوان ئەو نرخەی بڕیار لەسەری دراوە و ئەو نرخەی بەدەستهاتووە، لەگەڵ کرێ و تێچووی ئەو بەشەی هەرگیز پڕ نەبووەوە.

پێناسەی تەکنیکی

خێزانێک لە پێوەرەکان کە هەریەکە بە پێوەری خۆی پێناسە دەکرێت: سپرێدی ڕاگەیەنراو، سپرێدی کاریگەر، نرخی گەیشتنی داواکاری، تێکڕای کێشداری قەبارەی ماوەکە، یان نرخی بڕیار. کەمینەی جێبەجێکردن تەواوترینە چونکە دواکەوتن، کاریگەری نرخ، تێچووی ئاشکرا و قەبارەی جێبەجێنەکراو دەخاتە سەر هەژماری ستراتیژی. پێوەرەکان جێگرەوەی یەک نین: ئەلگۆریتمێک دەتوانێت تێکڕای ماوەکە ببەزێنێت و هەر کەمینەیەکی گەورە پیشان بدات، ئەگەر لە کاتێکدا نرخ دوور دەکەوتەوە چاوەڕێ کردبێت. پێوانە پێویستی بە مۆری کات هەیە کە زۆربەی پلاتفۆرمەکانی خەڵکی ئاسایی هەرگیز ئاشکرای ناکەن.

میکانیزم

هەر هەڵبژاردنێکی جێبەجێکردن کاریگەری نرخ لەگەڵ دواکەوتن ئاڵوگۆڕ دەکات. خێرا مامەڵەکردن کاریگەری دەدات؛ هێواش مامەڵەکردن مەترسی دوورکەوتنەوەی نرخ. کەمینەی جێبەجێکردن تاکە یەکەی هاوبەشە کە دەتوانرێت ئەم دوو تێچووە تێیدا کۆ بکرێن؛ بۆیە پێوەرێکە کە بە کەمتر مامەڵەکردن ناجوانکرێت.

بەکارهێنانی پراکتیکی

کێ بەکاری دەهێنێت
تیمەکانی جێبەجێکردن، دروستکەرانی ئەلگۆریتم، ڕێکخستن و ڕاپۆرتی باشترین جێبەجێکردن، و هەر کەسێک بە جدی بەکتێست دەکات.
بۆچی گرنگە
تاکە وەڵامی ڕاستگۆیە بۆ ئەوەی ئایا چوونەژوورەوە هەرزان بوو، چونکە دواکەوتن و جێبەجێنەبوون نرخ دەکات؛ ئەوەی پێوەرەکانی لەسەر بنەمای سپرێد بە تەواوی پشتگوێ دەخەن.
سنوورەکان
پێویستی بە نرخی بڕیاری مۆرکاتدار هەیە کە زۆر پلاتفۆرم تۆماری ناکەن، و بڕگەی تێچووی دەرفەت پەیوەستە بەو نرخی کۆتایی ئاسۆی هەڵبژێردراو.

هەڵەکانی باو

  • داوەری جێبەجێکردن تەنها لە نرخی پڕکراوە.
  • بەراوردکردنی ژمارەکانی کەمینە کە بە پێوەری جیاواز ژمێردراون.
  • لابردنی قەبارەی پڕنەکراوە، کە ئەلگۆریتمی ئارام جوان پیشان دەدات.

نموونەکان

market

ئەلگۆریتمێک ڕاپۆرت دەدات کە تێکڕای نرخی ماوەکەی بە چەند خاڵی بنەڕەتی بەزاندووە. ئەگەر لە نرخی بڕیارەوە بپێورێت زۆر خراپترە: دوو کاتژمێر چاوەڕێ کرد لە کاتێکدا بازاڕ دوور دەکەوتەوە، و ئەو دواکەوتنە هەرگیز لە پێوەری هەڵبژێردراوی نەبینرا.

numeric

نیازی کڕینی ١٬٠٠٠ یەکە بە نرخی بڕیاری ١٠٠.٠٠ دەگەیەنرێتە ٨٠٠ یەکەی پڕکراوە لەسەر ١٠٠.٢٥ و ٤٠.١٠ کرێ، لە کاتێکدا ٢٠٠ یەکەی پڕنەکراوە ئێستا ١٠١.٠٠ دەکەوێت. کەمینە ٤٤٠.١٠ـە، یانی ٤٤ خاڵی بنەڕەتی.

داتاکان
  • intended quantity Q = 1,000, decision price 100.00
  • filled Q_f = 800 at a weighted average of 100.25
  • explicit costs 40.10 (0.05% of traded notional)
  • end-of-horizon price for the unfilled 200 is 101.00
هەنگاوەکان
  1. execution cost = 800 x (100.25 - 100.00) = 200.00
  2. explicit costs = 40.10
  3. opportunity cost = 200 x (101.00 - 100.00) = 200.00
  4. IS = 200.00 + 40.10 + 200.00 = 440.10
  5. as a fraction of intended notional = 440.10 / (1000 x 100.00) = 0.004401
implementation shortfall 440.10, or 44.0 basis points of the intended notional

Nearly half the shortfall comes from the quantity that never traded. A measure that ignores unfilled size would have reported roughly 24 basis points.

بنەمای ماتماتیکی

IS = Q_f \left( \bar{P}_{exec} - P_d \right) + C + \left( Q - Q_f \right) \left( P_{end} - P_d \right)

ڕێبازی ژمێریاری

نرخی بڕیار بە مۆری کات و پێش ناردنی داواکاری تۆمار بکە. دوای کۆتایی ئاسۆ، نرخی تێکڕای کێشداری قەبارەی جێبەجێکراو بژمێرە و جیاوازی لە هەمان قەبارە بدە. تێچووی ئاشکرا زیاد بکە. قەبارەی جێبەجێنەکراو بە سەرچاوەی کۆتایی ئاسۆ نرخ بکە و ئەویش زیاد بکە. بەسەر بەهای ناویی مەبەستدا دابەش بکە تاوەکو دەرئەنجام بە خاڵی بنەڕەتی دەرببڕدرێت.

نموونەی کرابوو

داتاکان
  • Q = 1000, Q_f = 800
  • P_d = 100.00, average fill 100.25
  • C = 40.10
  • P_end = 101.00
هەنگاوەکان
  1. 800 x (100.25 - 100.00) = 200.00
  2. C = 40.10
  3. (1000 - 800) x (101.00 - 100.00) = 200.00
  4. IS = 200.00 + 40.10 + 200.00 = 440.10
  5. 440.10 / 100000 = 0.004401
IS = 440.10, i.e. 44.0 basis points of the intended notional

لێکدانەوە

بەهایەکی ئەرێنی تێچووە: ئەو پۆرتفۆلیۆی کاغەزی کە لەسەر نرخی بڕیار داخرا بە هەمان بڕ باشتر کاری دەکرد. پارچەکردنی بڕگەکان لە خودی کۆ گرنگترە، چونکە دواکەوتن، کاریگەری نرخ، کرێ و قەبارەی لەدەستچوو چارەسەری جیاواز دەخوازن.

گریمانەکان

  • The decision price must be defined and timestamped before the order is sent. Using the arrival price or the previous close instead gives a different number that is not comparable with it.
  • The sign convention here makes a positive value a cost for a buy order; for a sell, both price differences reverse.
  • The opportunity-cost term requires a stated end-of-horizon price, which is a choice, so two desks can report different shortfalls on the same order.
سنووری فۆرموڵ
  • It evaluates one order against one benchmark and says nothing about whether the underlying decision was any good.
  • Delay between the decision and order entry is charged to execution here, although it is often an upstream organisational cost rather than a trading one.
