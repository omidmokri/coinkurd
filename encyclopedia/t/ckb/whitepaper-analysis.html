پێناسەی ساکار

خوێندنەوەی بەڵگەنامەی تەکنیکی خودی پڕۆژە بۆ بینینی ئەوەی ئایا قسەکانی دیاریکراو، لە ناوەوە یەکگرتوو، و گونجاو لەگەڵ کۆد و بلۆکچەینە.

پێناسەی پیشەیی

مەشقێکی پشتڕاستکردنەوە لەسەر بەڵگەنامەیەکی خۆ-بڵاوکراوە: جیاکردنەوەی دەربڕینەکانی تاقیکراو لە بازاڕکردن، پشکنینی میکانیزمی تۆکن لە دەقەکەدا بەرامبەر گرێبەستی جێبەجێکراو، و ڕوونکردنەوەی هەر سەرچاوە، هەر کەسێکی ناوبراو و هەر ئاماژەیەکی پێداچوونەوە.

پێناسەی تەکنیکی

ئەم بەڵگەنامەیە هیچ پێگەیەکی سەربەخۆی نییە. کەرەستەی بازاڕکردنە کە تێیدا بڵاوکەرەوە نەخشەی خۆی ڕوون دەکاتەوە، بەبێ هیچ ئەرکی تۆمارکردن، بەبێ پێداچوونەوەکار و لە زۆربەی دەسەڵاتەکاندا بەبێ بەرپرسیارێتی. بۆیە شیکاری وەک سەرچاوەی بانگەشەی دەگرێت کە دەبێت لە شوێنێکی تردا تاقی بکرێنەوە: ژمارەکانی پێشکەشکردن و دابەشکردن بەرامبەر گرێبەست، بانگەشەی کارایی بەرامبەر ڕەوشتی پێوانەکراو، سەرچاوەکان بەرامبەر ئەدەبیاتی ڕاستەقینە، و بەشی تیم بەرامبەر تۆمارەکانی گشتی.

میکانیزم

بانگەشەیەک خێراتر لەوە دەنووسرێت کە دروست بکرێت، بۆیە بەڵگەنامە و سیستەم لە یەکتر دوور دەکەونەوە مەگەر کەسێک بەراوردیان بکات. هەر بانگەشەیەکی تاقیکراو شوێنێکی هەیە کە دەکرێت ڕوون بکرێتەوە: گرێبەست، گەڕۆک، تۆمار، ئەو توێژینەوەی ئاماژەی بۆ کراوە. ئەم شیکارییە بە بردنی هەر بانگەشەیەک بۆ ئەو شوێنەی ڕێکی دەخات کار دەکات، و بە تۆمارکردنی ئەو بانگەشانەی شوێنێکی وا نییان.

بەکارهێنانی پراکتیکی

کێ بەکاری دەهێنێت
شیکەرانی پشکنین، پێداچوونەوەکارانی لیستکردنی مەڵبەند و گرانت، ڕۆژنامەنووسانی تەکنیکی، و بەشداربووان کە دەیانەوێت بزانن پڕۆژە بە نووسین پابەندی چی بووە.
بۆچی گرنگە
ئەم بەڵگەنامەیە ئەو شوێنەیە کە بانگەشەکانی پڕۆژە لە هەموو شوێنێک ڕوونترن، بۆیە هەرزانترین شوێنە بۆ دۆزینەوەی ناکۆکی لەگەڵ سیستەمی جێبەجێکراو.
سنوورەکان
بەڵگەنامەیەکی باش نووسراو بەڵگەی سیستەمێکی کارا نییە، و بەڵگەنامەیەکی لاواز بەڵگەی فێڵ نییە. شیکاری تەنها دەتوانێت ڕاپۆرت بکات دەقەکە چ بانگەشەیەکی هەیە و ئایا هەر بانگەشەیەک ڕوون دەبێتەوە یان نا.

هەڵەکانی باو

  • دادوەری پڕۆژە لەسەر بنەمای ڕازاندنەوەی بەڵگەنامەکە.
  • پەسەندکردنی ژمارەکانی پێشکەشکردن لە دەقەوە بەبێ خوێندنەوەی گرێبەست.
  • تێپەڕبوون بەسەر بەشی سەرچاوەکان، ئەو شوێنەی دزینی ئەدەبی و ئاماژەی داهێنراو دەردەکەوێت.

نموونەکان

procedure

خولێکی پشتڕاستکردنەوە لەسەر بەڵگەنامەکە: هەر بانگەشەیەکی ژمارەیی لیست بکە و هەر یەکێکیان بەرامبەر گرێبەست یان بلۆکچەین ڕوون بکەوە؛ بپشکنە خشتەی پێشکەشکردن بگاتە ئەو کۆیەی ڕاگەیەنراوە؛ هەر سەرچاوەیەکی ئاماژەکراو بکەوە؛ ڕستەی تایبەت بۆ بڵاوکردنەوەی پێشوو بگەڕێ؛ هەر نووسەر و ڕاوێژکارێکی ناوبراو بە سەربەخۆیی پشتڕاست بکەوە؛ هەر زمانێکی بەڵێنی گەڕانەوەی دڵنیا یان بێ‌مەترسی تۆمار بکە.

numeric

بەڵگەنامەکە پێشکەشکردنی سەرەوەی جێگیری ١٠٠٠ ملیۆن تۆکن ڕادەگەیەنێت، و خشتەی دابەشکردن ٤٠٠، ٣٠٠، ٢٥٠ و ١٠٠ ملیۆن لیست دەکات — کۆیان ١٠٥٠ـە. گرێبەستی جێبەجێکراو هەروەها فەنکشنێکی دروستکردنی بانگکراو لەلایەن خاوەنەوە هەیە، بۆیە ئەو سنوورەی ڕاگەیەنراوە لە کۆددا نەسەپێنراوە.

داتاکان
  • Stated maximum supply = 1,000 million
  • Allocation table: 400 + 300 + 250 + 100 million
  • Contract contains an owner-callable mint function with no cap
هەنگاوەکان
  1. Allocation sum = 400 + 300 + 250 + 100 = 1,050 million
  2. Excess over stated cap = 1,050 - 1,000 = 50 million, a 5% inconsistency
  3. Code check: no on-chain enforcement of the 1,000 million figure
An internal arithmetic contradiction of 5 per cent and a stated cap that the code does not enforce

Illustrative figures. The arithmetic error is a reading finding; the uncapped mint function is a code finding, and the second matters more.
