پێناسەی ساکار

ئەوەی دەفتەرەکان دەڵێن بەشی خاوەنانی کۆمپانیا چەند بەهای هەیە: هەرچی هەیەتی کەم هەرچی قەرزارە، بەو شێوەی تۆمارکراوە.

پێناسەی پیشەیی

سەرمایەی خاوەنان وەک لە باڵانسدا تۆمارکراوە — کۆی سامان کەم کۆی قەرزەکان — و بۆ هەر پشکێک، هەمان ماوە بەسەر ژمارەی پشکدا. تۆمارێکە لەسەر بنەمای تێچووی مێژوویی لە سەرمایەی هێنراو و قازانجی کۆکراوە، نەک هەڵسەنگاندنی ئەوەی سامانەکان چەند دەفرۆشرێن.

پێناسەی تەکنیکی

ماوەی ژمێریاری کە چوارچێوەی توخمەکان پێناسەی دەکات: سامان کەم قەرز دەکاتە سەرمایە. لەو بڕانە دروست دەبێت کە لە چوارچێوەی ڕاپۆرتکردندا دانراون و پێوراون، بۆیە براندی ناوەکی، هێزی کاری ڕاهێنراو و زۆربەی توێژینەوە هەرگیز تێدا نادەرکەون، بەڵام گودویڵی کڕدراو دەردەکەوێت. کڕینەوەی سەروو بەهای دەفتەری کەمی دەکات، کەمکردنەوەی بەها بە دواکەوتن کەمی دەکات، و مۆدێلی نرخاندنەوە بەبێ هیچ مامەڵەیەک دەگۆڕێت.

میکانیزم

سەرمایەی خاوەنان ڕاستەوخۆ ناپێورێت؛ ئەوەیە دوای پێوانەی سامان و قەرزەکان دەمێنێتەوە. بۆیە هەر یاسایەکی دانان بۆی دەڕژێت. ئەو خەرجییەی ژمێریاری وەک تێچوو دەژمێرێت — توێژینەوە، بازاڕکردن، ڕاهێنان — هیچ لە باڵانسدا بەجێ ناهێڵێت، بۆیە ئەو کۆمپانیایانەی بەهایان بەو ڕێگەیە دروست بووە کەمترین بەهای دەفتەری و زۆرترین زیادەی دەرکەوتوو پیشان دەدەن.

بەکارهێنانی پراکتیکی

کێ بەکاری دەهێنێت
شیکەرانی بانک و دڵنیایی، قەرزدەران کە بۆشایی مەرجەکان دەتاقێنن، شارەزایانی هەڵوەشاندنەوە و ڕێکخستنەوە، و هەر کەسێک P/B دەخەمڵێنێت.
بۆچی گرنگە
لەنگەرێکی پێداچوونەوەکراو و بە نیسبەت جێگیرە کە تەنانەت بە قازانجی نەرێنیش بوونی هەیە، و بنەمای گەڕانەوەی سەرمایە و P/Bـە.
سنوورەکان
تۆمارێکە لە تێچوو نەک لە بەها. کۆمپانیای نادیاری‌بنەما کەم پیشان دەدرێن، خانووبەرەی نرخاندنەوە بە خەمڵاندن تۆمار دەکرێت، و کەمکردنەوەی بەها زۆرجار دوای گۆڕانی ئابووری دێت.

هەڵەکانی باو

  • بەهای دەفتەری بە نرخی فرۆشتنی سامانەکان لێکدانەوە.
  • بەراوردکردنی بەهای دەفتەری بەبێ پشکنینی گودویڵ.
  • پشتگوێخستنی ئەوەی کڕینەوەی سەروو بەهای دەفتەری بە میکانیکی بچووکی دەکاتەوە.

نموونەکان

numeric

کۆی سامان ١٩٠٠ و کۆی قەرز ١٢٠٠ دەکاتە سەرمایەی دەفتەری ٧٠٠. بەسەر ٤٠ پشک، دەکاتە ١٧.٥ بۆ هەر پشکێک. ئەگەر گودویڵی کڕدراوی ٣٠٠ لابدرێت، بەهای دەفتەری دیاری هەر پشکێک دادەبەزێتە ١٠.

داتاکان
  • Total assets = 1,900
  • Total liabilities = 1,200
  • Ordinary shares outstanding = 40
  • Acquired goodwill included in assets = 300
هەنگاوەکان
  1. Book equity = 1,900 - 1,200 = 700
  2. Book value per share = 700 / 40 = 17.5
  3. Tangible book equity = 700 - 300 = 400
  4. Tangible book value per share = 400 / 40 = 10
Book value per share 17.5; tangible book value per share 10

A 43 per cent difference between two figures that are both called book value. The variant must be stated.

case

کڕیارێک زۆر سەروو بەهای دەفتەری کۆمپانیای ئامانج دەدات و زیادەکە وەک گودویڵ تۆمار دەکات، بۆیە بەهای دەفتەری گروپ بە بڕی نرخی کڕین بەرز دەبێتەوە. سێ ساڵ دواتر بازرگانییەکە بێ‌ئومێد دەکات و گودویڵ دەسڕێتەوە و بەهای دەفتەری کەم دەبێت بەبێ ئەوەی پارەیەک لە کۆمپانیا بچێتە دەرەوە.

بنەمای ماتماتیکی

BV_{equity} = A - L, \qquad BVPS = \frac{A - L - Pref}{N}

گۆڕاوەکان

Aکۆی سامان بە بڕەکانی تۆمارکراوcurrency
Lکۆی قەرزەکان بە بڕەکانی تۆمارکراوcurrency
Prefپشکی تایبەت و مافەکانی تر کە پێش پشکی ئاسایی ڕیز دەگرنcurrency
Nژمارەی پشکی ئاسایی لە ڕۆژی ڕاپۆرتداshares

ڕێبازی ژمێریاری

کۆی سامان و کۆی قەرزەکان لە باڵانسەوە بخوێنە و لێی کەم بکە. هەر مافێکی تایبەت یان بەشی کەمینە کە پێش پشکی ئاسایی ڕیز دەگرێت لاببە، پاشان بەسەر ژمارەی پشکدا دابەشی بکە. بە جیا تۆمار بکە ئایا گودویڵ و سامانی نادیاری تر لە ژمارەکەدان یان نا.

نموونەی کرابوو

داتاکان
  • A = 1,900
  • L = 1,200
  • Pref = 0
  • N = 40
هەنگاوەکان
  1. BV_equity = 1,900 - 1,200 = 700
  2. BVPS = 700 / 40
Book equity 700; book value per share 17.5

لێکدانەوە

ئەم ژمارەیە دەڵێت ئەگەر قەرزەکان بە بڕەکانی تۆمارکراو ڕێک بخرێن، خاوەن‌پشکانی ئاسایی مافی چەند بەشی سامانی تۆمارکراوی هەیە. هەمان ئەو مەرجە باری قورس هەڵدەگرێت، چونکە بڕەکانی تۆمارکراو بەهای وەرگرتنەوە نین.

گریمانەکان

  • Carrying amounts follow the reporting framework in use: historical cost, cost less impairment, revaluation or fair value depending on the asset class and the election made.
  • Variants are not interchangeable — total book value, tangible book value and book value excluding non-controlling interests are different numbers.
  • The identity holds by construction, so it cannot be used to test whether the balance sheet is right; it only restates how equity was derived.
سنووری فۆرموڵ
  • Omits internally generated intangibles entirely, so it systematically understates asset-light businesses.
  • Can be reduced by buybacks and by late impairments, both of which change the figure without any change in the underlying business.
