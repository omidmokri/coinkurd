پێناسەی ساکار

هەرچەند تاقیکردنەوەیەکی هەڕەمەکی زیاتر دووبارە بکەیتەوە، تێکڕای ئەنجامەکان لە بەهای چاوەڕوانکراوی ڕاستەقینە نزیک دەبێتەوە. سەبارەت بەوەی ئەمە کەی ڕوو دەدات هیچ ناڵێت.

پێناسەی پیشەیی

بۆ نمونەی سەربەخۆ کە تێکڕایەکی سنووردار هەیە، تێکڕای نمونە بە گەورەبوونی نمونە بەرەو تێکڕای کۆمەڵگە دەچێت. شێوەی لاواز گەڕانەوە لە ئەگەردا دەدات و شێوەی بەهێز گەڕانەوەی نزیکەی دڵنیا. هیچ یەکێکیان سنوورێک بۆ دوورکەوتنەوەی تێکڕای ڕۆیشتوو لە ناوەڕاستی ڕێگادا دانانێت.

پێناسەی تەکنیکی

وا دابنێ X١ بۆ Xn سەربەخۆ و هاوتا‌دابەشکراون، بە چاوەڕوانی سنووردار و تێکڕای μ. یاسای لاواز دەڵێت تێکڕای نمونە لە ئەگەردا بۆ μ دەگەڕێتەوە، و یاسای بەهێزی کۆلمۆگۆرۆڤ گەڕانەوەی نزیکەی دڵنیا دەدات. جیاوازی سنووردار مەرجی یاسای بەهێز نییە؛ سەربەخۆیی و مۆمێنتی یەکەمی سنووردار مەرجن. ئەم تیۆرەمە ئاسیمپتۆتییە: قەبارەی نمونە دیاری ناکات، خێرایی گەڕانەوە نادات، و ڕێگە دەدات تێکڕای ڕۆیشتوو ماوەیەکی درێژ دوور لە μ بمێنێتەوە.

میکانیزم

تێکڕاگرتن ژاوەژاوی کۆکراوە بەسەر n دابەش دەکات و ئاماژە وەک خۆی دەمێنێت، بۆیە بڵاوبوونەوەی تێکڕا بێ‌سنوور بچووک دەبێتەوە. ئەوەی بچووک دەبێتەوە بڵاوبوونەوەیە، نەک ڕێڕەوێکی تاک. ڕێڕەوێک دەتوانێت ماوەیەکی زۆر درێژ لە یەک لای μ بمێنێتەوە، چونکە یاساکە سنوور بۆ کۆتایی دادەنێت نەک بۆ ڕێگا.

بەکارهێنانی پراکتیکی

کێ بەکاری دەهێنێت
دروستکەرانی ستراتیژی کە هەڵدەسەنگێنن ئایا نمونەی بەکتێست گەورە هەیە، بەڕێوەبەرانی مەترسی کە قەبارەی پۆزیشن بەپێی چاوەڕوانی دادەنێن، و هەر کەسێک کە مەترسیی دووبارە نرخ دەکات.
بۆچی گرنگە
ئەمە هۆکاری فەرمی ئەوەیە کە سوودێکی پێوراو لەسەر چەندین بینینی سەربەخۆ، باوەڕپێکراوترە لە هەمان سوود لەسەر چەند بینینێک.
سنوورەکان
کۆتاییەک بەڵێن دەدات نەک ئاسۆیەکی کاتی. هەروەها سەربەخۆیی نمونەکان و تێکڕایەکی جێگیر پێشفەرز دەکات؛ مەرجێک کە زۆربەی زنجیرەی ڕێژەی گەڕانەوە دەیشکێنن.

هەڵەکانی باو

  • پەنجا مامەڵە «بەس» بزانی بۆ دەرکەوتنی سوود.
  • پاڵپشتی بە یاساکە لە کاتێکدا مامەڵەکان سەربەخۆ نین.
  • تێکەڵکردنی لەگەڵ بەڵێنی ئەوەی زیانەکان دەبێت یەکسان بن.

نموونەکان

market

دوو مامەڵەکار هەمان چاوەڕوانی ئەرێنییان هەیە. یەکێکیان دوای چل مامەڵە بە زیانی ساڵانە واز دەهێنێت و دەڵێت سوودەکە درۆیە؛ ئەوی تر دوای چوار سەد مامەڵە هێشتا لە بازاڕدایە. تەنها نمونەی دووەم ئەوەندە گەورەیە کە یاساکە شتێک بڵێت.

numeric

سوودی هەر مامەڵەیەک ٠.٢٪ بە بڵاوبوونەوەی ٢٪. بۆ ئەوەی بە دڵنیایی ٩٥٪ تێکڕای پێوراو لە ماوەی ٠.٢٪ی ڕاستییەکە بێت، سنووری چێبیشێڤ نزیکەی ٢٬٠٠٠ مامەڵەی سەربەخۆ دەخوازێت، نەک پەنجا.

داتاکان
  • sigma = 2% per trade
  • epsilon = 0.2%
  • target failure probability = 5%
  • trades assumed independent with a stable mean
هەنگاوەکان
  1. Chebyshev: P(|mean - mu| > epsilon) <= sigma^2 / (n * epsilon^2)
  2. require sigma^2 / (n * epsilon^2) <= 0.05
  3. n >= 0.0004 / (0.000004 * 0.05) = 2000
n = 2,000 trades

Chebyshev is deliberately loose, so this is an upper bound on the requirement, not a forecast. It also needs finite variance, which the strong law itself does not.

بنەمای ماتماتیکی

\bar{X}_n = \frac{1}{n}\sum_{i=1}^{n} X_i, \qquad \lim_{n \to \infty} P\big( |\bar{X}_n - \mu| > \varepsilon \big) = 0 \;\; \forall \varepsilon > 0

گۆڕاوەکان

\bar{X}_nتێکڕای نمونەی n بینینی یەکەمsame as X
\muتێکڕای کۆمەڵگە، بەهای چاوەڕوانکراوی Xsame as X
\varepsilonهەر سنوورێکی هەڵبژێردراو لە دەوری تێکڕاsame as X
nژمارەی بینینی سەربەخۆcount

ڕێبازی ژمێریاری

یەکەم دڵنیا بە کە نمونەکان سەربەخۆن و لە یەک دابەشبوونی تێکڕا سنووردارەوە هاتوون. تێکڕایان بگرە. یاسای لاواز دەڵێت ئەگەری ئەوەی ئەم تێکڕایە زیاتر لە هەر سنوورێکی جێگیر لە μ دوور بکەوێت، بە گەورەبوونی n بەرەو سفر دەچێت. بۆ گۆڕینی ئەمە بۆ قەبارەی نمونە پێویستت بە نایەکسانییەکی جیاوازە، وەک سنووری چێبیشێڤ یان تیۆرەمی سنووری ناوەندی.

نموونەی کرابوو

داتاکان
  • sigma = 0.02 (2% per trade)
  • epsilon = 0.002 (0.2%)
  • allowed failure probability 0.05
هەنگاوەکان
  1. Chebyshev bound: sigma^2 / (n * epsilon^2) <= 0.05
  2. 0.0004 / (n * 0.000004) <= 0.05
  3. n >= 0.0004 / 0.0000002 = 2000
n = 2,000 independent trades

لێکدانەوە

ئەم ڕاگەیاندنە دەربارەی کۆتایی زنجیرەیەک ئەگەرە. ڕێگە دەدات بڵێین نمونەی سەربەخۆی گەورە تێکڕا باش هەڵدەسەنگێنێت، و هەر بانگەشەیەک دەربارەی نمونەیەکی سنووردار و دیاریکراو بەبێ نایەکسانییەکی زیادە قەدەغە دەکات.

گریمانەکان

  • Observations are independent and identically distributed; clustered or regime-dependent trades are not.
  • The first moment is finite. For a distribution with no finite mean the law simply does not apply.
  • The Chebyshev step additionally requires finite variance, which the strong law does not.
سنووری فۆرموڵ
  • No rate and no sample size follow from the theorem itself.
  • Convergence of the average does not bound the path, so an account can be ruined long before the limit is approached.
  • Strictly stated the theorem concerns the sample mean, not the cumulative sum, which does not converge.
