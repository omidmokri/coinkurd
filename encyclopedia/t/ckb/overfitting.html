پێناسەی ساکار

ڕێکخستنی یاسایەک تا ئەو ڕادەی ڕابردوو بە وردی دەگونجێنێت، بەو بەشانەشەوە کە ڕاندۆم بوون. ئەوکات لەسەر ئەو داتای لێی دروستکراوە باش و لەسەر هەر داتایەکی تر خراپ کار دەکات.

پێناسەی پیشەیی

گونجاندنی ستراتیژی بەو تایبەتمەندییانەی نموونەیەک کە دووبارە نابنەوە. لە پارامەتەری ئازادی زۆر بەرامبەر قەبارەی داتا دێت، و لە تاقیکردنەوەی کاندیدی زۆر و ڕاگرتنی باشترین؛ شتێک کە بەخت بە هەمان دڵنیایی لێهاتوویی هەڵدەبژێرێت.

پێناسەی تەکنیکی

زیادە-گونجاندن کێشەی هەڵبژاردنە، نەک هەڵەی کۆدنووسین. بە N یاسای کاندیدی سەربەخۆ کە هەر یەکێک لە ئاستی مانادارێتی ئالفا تاقی دەکرێن، ئەگەری ئەوەی لانیکەم یەکێکیان بە ڕاندۆم تێپەڕێت دەکاتە یەک کەم (یەک کەم ئالفا) بە هێزی N، کە بە خێرایی لە دڵنیایی نزیک دەبێتەوە. زیادکردنی پارامەتەر هەمان کاریگەری لە ڕێگەی نەرمییەوە دەکات نەک لە ژمارەوە: مۆدێل دەتوانێت خڕۆشە وەک ئاماژە هەڵبگرێت. بۆیە ئامارەکانی ناو-نموونە لەگەڵ هەوڵی گەڕان بە یەک ئاڕاستە بەرز دەبنەوە و ئەنجامی دەرەوەی-نموونە دادەبەزێت، و هێڵی سەرمایەی جوان لەسەر هەمان داتای دروستکەری یاسا بەنزیکەیی هیچ زانیارییەک دەربارەی یاساکە ناگەیەنێت.

میکانیزم

بزوێنەری ئەم کێشە گەڕانە. هەر پارامەتەر، فلتەر، سنوور یان وەشانێکی تاقیکراوی زیادە، تیرێکی ترە لە دابەشبوونی دەرئەنجامی ڕاندۆم، و توێژەر زۆرترین ڕادەگرێت. زۆرترینی تیری زۆر زۆر بەرزترە لە تێکڕا، تەنانەت کاتێک هیچ یاسایەک بەهای نییە؛ بۆیە ئەنجامی ڕاگەیەنراوی ناو-نموونە بە هەمان ئەندازە هەوڵی گەڕان دەپێوێت وەک بەرتەری. هیچ شتێک لەو نموونەدا ئەمە ئاشکرا ناکات، چونکە هەمان نموونە گەڕدراوە.

بەکارهێنانی پراکتیکی

کێ بەکاری دەهێنێت
دروستکەرانی ستراتیژی، توێژەرانی ژمارەیی، کارکەرانی فێربوونی ئامێر، و پێداچووانی ئەنجامی کەسانی تر.
بۆچی گرنگە
باوترین شکستی مامەڵەی سیستەماتیک ڕوون دەکاتەوە: ئەنجامێک کە لە نموونەدا ڕاستەقینە بوو و دواتر نەما، بەبێ هیچ هەڵەیەک بۆ دۆزینەوە.
سنوورەکان
هیچ تاقیکردنەوەیەک ناسەلمێنێت کە یاسایەک زیادە-گونجاو نییە. داتای جیاکراوە، ڕێکاری پێشەوە و کەمی پارامەتەر مەترسی کەم دەکەنەوە؛ لای نابەن، و هەر دووبارە بەکارهێنانی داتای جیاکراوە دەیسووتێنێت.

هەڵەکانی باو

  • ڕاگەیاندنی باشترین کۆمەڵەی پارامەتەر بەبێ ژمارەی ئەو کۆمەڵانەی تاقی کراون.
  • دووبارە بەکارهێنانی هەمان خولی جیاکراوە دوای هەر پێداچوونەوەیەک.
  • زیادکردنی فلتەر بۆ لابردنی خراپترین مامەڵەکانی ڕابردوو.

نموونەکان

market

یاسایەک بە دوو پارامەتەر قازانجدارە. شەش فلتەر زیاد دەکرێت بۆ لابردنی خراپترین مامەڵەکانی ڕابردووی و هێڵەکە ناسک دەبێت. لە ڕاکردنی زیندوودا، هەمان فلتەرەکان مامەڵەی ئاساییش دەگرن، و بەرتەری نەماوە.

numeric

سەد وەشانی بێ‌بەها لە سنووری ٥ لەسەد تاقی بکە و ئەگەری ئەوەی لانیکەم یەکێکیان مانادار دیار بێت ٩٩.٤ لەسەدە. ڕاگەیاندنی ئەو براوە بەبێ ژمارەی تاقیکردنەوەکان، خڕۆشە وەک دۆزینەوە ڕادەگەیەنێت.

داتاکان
  • N = 100 candidate rules, each with no genuine edge
  • significance threshold alpha = 0.05 per test
  • tests treated as independent
هەنگاوەکان
  1. probability one test does not pass = 1 - 0.05 = 0.95
  2. probability none of 100 passes = 0.95^100 = 0.0059
  3. probability at least one passes = 1 - 0.0059 = 0.9941
about a 99.4 percent chance of at least one false positive

Independence is an idealisation: overlapping parameter grids are correlated, which lowers the effective number of tests but does not remove the problem.

بنەمای ماتماتیکی

P(\text{at least one false pass}) = 1 - (1 - \alpha)^{N}

گۆڕاوەکان

\alphaئاستی مانادارێتی کە بۆ هەر تاقیکردنەوەیەکی تاک جێبەجێ دەکرێتprobability
Nژمارەی ئەو یاسا، کۆمەڵەپارامەتەر یان وەشانانەی بەڕاستی تاقی کراونcount

ڕێبازی ژمێریاری

هەر وەشانێک کە بەڕاستی هەڵسەنگێندراوە بژمێرە، ئەوانەش کە زوو لابران یان بە نافەرمی تاقی کران. دەربڕینەکە لەسەر هەمان ژمارە جێبەجێ بکە، نەک لەسەر ژمارەی ئەنجامەکانی ڕاگەیەنراو، و دەرئەنجام لەگەڵ ئەو دڵنیایی بەراورد بکە کە بۆ یاسای ماوە بانگەشە دەکرێت.

نموونەی کرابوو

داتاکان
  • alpha = 0.05
  • N = 100
هەنگاوەکان
  1. 1 - 0.05 = 0.95
  2. 0.95^100 = 0.0059
  3. 1 - 0.0059 = 0.9941
0.9941, about 99.4 percent

لێکدانەوە

ئەم دەربڕینە ئەگەری دۆزینەوەی لانیکەم یەک یاسای بە ڕواڵەت مانادار دەدات کاتێک هیچیان بەرتەری نییە. هەر ئەمە هۆکارەکەیە کە یەک بەکتێستی ماوە، بەبێ مێژووی گەڕانی، بەلگە نییە.

گریمانەکان

  • Tests are treated as independent; correlated parameter grids reduce the effective N but never to one.
  • Alpha is the threshold genuinely applied per test, not the one reported afterwards for the winner.
  • The count N must include informal and abandoned trials, which are the ones most often left out.
سنووری فۆرموڵ
  • The expression bounds false discovery under search; it does not measure how much of a given result is noise.
  • It says nothing about overfitting through model flexibility, where a single highly parameterised model absorbs noise without any explicit search over variants.

لە ڕووی زمانی، ماتماتیکی یان یاساییەوە وەک نادڵنیا نیشانە کراوە.

The multiple-testing expression is a standard probability result and is presented with its independence assumption stated; it bounds false discovery under search and is not a measure of how overfitted a given rule is. No specific published study of strategy overfitting is in this closed registry, so no empirical magnitudes are claimed. The Kurdish headword زیادە-گونجاندن is a proposal by this project and needs native-expert review; the Persian بیش‌برازش is in use but اورفیتینگ is also common, so it is marked recommended rather than established.
