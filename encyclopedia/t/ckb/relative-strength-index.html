پێناسەی ساکار

پێوەرێک لە نێوان ٠ و ١٠٠ کە دەریدەخات جوڵەکانی ئەم دواییەی نرخ چەند یەک‌لایەنە بوون. ژمارەی بەرز یانی ڕۆژانی سەرکەوتوو زاڵ بوون، ژمارەی نزم یانی ڕۆژانی داشکاو.

پێناسەی پیشەیی

پێوەری لەرزۆکی مۆمێنتۆمی وایڵدەر، کە تێکڕای هێواشکراوی داخستنەکانی سەرەوە بە داخستنەکانی خوارەوە لە چوارچێوەیەکی دیاریکراو، زۆرتر ١٤ خول، بەراورد دەکات و دەخاتە نێوان ٠ بۆ ١٠٠. سەروو ٧٠ بە نەریت پڕبوونی کڕین و خواروو ٣٠ پڕبوونی فرۆشتن ناودەبردرێت.

پێناسەی تەکنیکی

ڕێژەیەکی ستانداردکراوی تێکڕای قازانجی هێواشکراوی وایڵدەر بۆ تێکڕای زیان. لەبەر ئەوەی سنووردار و هێواشکراوە، دابەشبوونی گۆڕانکاریەکانی ئەم دواییە دەپێوێت نەک ئاراستەی ڕێڕەو. لە ئاراستەیەکی بەهێزدا پڕ دەبێت و لە سنووری خۆیدا دەمێنێتەوە لە کاتێکدا نرخ بەردەوامە؛ بۆیە ئاماژەی گەڕانەوە لەسەر بنەمای ئاست لەوێ سەرکەوتوو نییە، و بەکارهێنانی باشتر توێژراوی لێکدووربوونەوەیە.

میکانیزم

لەبەر ئەوەی قازانج و زیان بە هەمان پەنجەرەی هێواشکردندا تێپەڕ دەبن، RSI هاوسەنگی گۆڕانکاریەکانی ئەم دواییە ڕادەگەیەنێت. پڕبوون لە سنووردارییەوە دێت: کاتێک تێکڕای زیان لە سفر نزیک دەبێتەوە ڕێژەکە دەتەقێتەوە و هەموو شتێک لە چەند خاڵی سەرەوەدا کۆدەبێتەوە، بۆیە هێزی زیاتر تۆمار نەکرێت.

بەکارهێنانی پراکتیکی

کێ بەکاری دەهێنێت
شیکەرانی تەکنیکی، دروستکەرانی ستراتیژی سیستەماتیک، و هەر کەسێک کە بەدوای ماندووبوونی مۆمێنتۆم یان لێکدووربوونەوەدا دەگەڕێت.
بۆچی گرنگە
زنجیرەی نرخ دەکات بە ژمارەیەکی سنووردار و بەراوردکراوی مۆمێنتۆم کە دەکرێت لە چەند ئامراز و چوارچێوەی کاتدا بپێورێت.
سنوورەکان
ئاستەکان لە نێوان چوارچێوەی مرجەعی جیاواز و جێبەجێکردنی هێواشکردنی جیاوازدا بەراوردکراو نین، و پڕبوونی کڕین مانای ئەوە نییە گەڕانەوە کاتی هاتووە.

هەڵەکانی باو

  • شۆرتکردنی بازاڕ تەنها لەبەر ئەوەی RSI سەروو ٧٠یە.
  • بەراوردکردنی RSI(14)ی ڕۆژانە لەگەڵ RSI(7)ی کاتژمێری وەک یەک پێوەر.
  • مامەڵەی لێکدووربوونەوە لە چوارچێوەی کاتی نزم بەبێ چوارچێوەی کاتی بەرزتر.

نموونەکان

market

لە ئاراستەیەکی سەرکەوتووی بەهێزدا، RSIی ڕۆژانە دەتوانێت هەفتەکان سەروو ٧٠ بمێنێتەوە و نرخیش بەرز بێتەوە. ئەوانەی هەر ژمارەیەکی ٧٠ شۆرت کرد لەگەڵ ئاراستە شەڕیان کرد؛ ئەوانەی چاوەڕێ بوون تا RSI لووتکەیەکی نزمتر بکێشێت و نرخ لووتکەیەکی بەرزتر، لێکدووربوونەوەیان دەخوێندەوە.

numeric

لە ١٤ خولدا، تێکڕای قازانج ١.٢٪ و تێکڕای زیان ٠.٨٪ـە. RS دەکاتە ١.٥، بۆیە RSI دەکاتە ٦٠ — جوڵەکانی سەرەوەی ئەم دواییە بە تێکڕا یەک‌ونیو ئەوەندەی جوڵەکانی خوارەوە بوون.

داتاکان
  • n = 14
  • average gain = 1.2%
  • average loss = 0.8% (entered as a positive magnitude)
هەنگاوەکان
  1. RS = 1.2 / 0.8 = 1.5
  2. RSI = 100 - 100 / (1 + 1.5) = 100 - 40
RSI = 60

A reading of 60 describes the recent balance of changes. It is not a probability of any future move.

بنەمای ماتماتیکی

RSI = 100 - \frac{100}{1 + RS}, \qquad RS = \frac{\overline{U}_n}{\overline{D}_n}

گۆڕاوەکان

RSهێزی بەراورد: تێکڕای قازانج بەسەر تێکڕای زیانratio (dimensionless)
\overline{U}_nتێکڕای هێواشکراوی وایڵدەری داخستنەکانی سەرەوە لە n خولداprice units or %
\overline{D}_nتێکڕای هێواشکراوی وایڵدەری داخستنەکانی خوارەوە لە n خولدا، وەک بەهای ئەرێنیprice units or %
nدرێژی چوارچێوەی مرجەع؛ وایڵدەر ١٤ بەکارهێناperiods

ڕێبازی ژمێریاری

گۆڕانی داخستن بۆ داخستنی هەر خولێک بکە بە قازانج یان زیان. هەر زنجیرەیەک بە ڕێبازی وایڵدەر هێواش بکە: بەهای یەکەم تێکڕای سادەی n خولە، پاشان هەر بەهایەک دەکاتە (بەهای پێشوو × (n−١) + بەهای ئێستا) ÷ n. تێکڕای قازانج بەسەر تێکڕای زیان دابەش بکە بۆ RS، پاشان بە فۆرموڵی سەرەوە بخەرە نێوان ٠ و ١٠٠.

نموونەی کرابوو

داتاکان
  • n = 14
  • average gain over the window = 1.2%
  • average loss over the window = 0.8%
هەنگاوەکان
  1. RS = 1.2 / 0.8 = 1.5
  2. 1 + RS = 2.5
  3. 100 / 2.5 = 40
  4. RSI = 100 - 40
RSI = 60

لێکدانەوە

دەرئەنجام شوێنێکە لەسەر پێوەری جێگیری ٠ بۆ ١٠٠، کە تێیدا ٥٠ مانای ئەوەیە جوڵەکانی سەرەوە و خوارەوە بە تێکڕا هاوقەبارە بوون. ئەوەی ڕوویداوە لە دابەشبوونی گۆڕانکاریەکان ڕوون دەکاتەوە و هیچ پێشبینییەک تێدا نییە.

گریمانەکان

  • Wilder's smoothing, not a simple moving average. Platforms that smooth with an SMA produce different numbers from the same price data.
  • Losses enter the average as positive magnitudes.
  • If the average loss over the window is zero, RS is undefined and RSI is set to 100 by convention.
سنووری فۆرموڵ
  • Bounded at 0 and 100, so it compresses information in strong trends and can sit above 70 for long stretches without a reversal.
  • The lookback n and the input series (close versus typical price) both change the output; a level is only comparable within one fixed configuration.
