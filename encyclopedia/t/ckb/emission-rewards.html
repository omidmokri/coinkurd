پێناسەی ساکار

تۆکنی نوێ کە پڕۆتۆکۆل بۆ ڕاکێشانی دانان یان مامەڵە دابەشی دەکات. ئەمانە یارمەتییەکن کە بە دەرکردنی پێشکەشکردنی زیاتر دەدرێن، نەک سوویەک کە لە کەسێک وەرگیرابێت.

پێناسەی پیشەیی

تۆکنی نوێ دەرکراوی پڕۆتۆکۆل کە لەبەر ڕەفتارێکی ئامانج، زۆرتر دابینکردنی ئاسانی ئاڵوگۆڕ یان قەرزکردن، بەسەر بەکارهێنەراندا دابەش دەکرێت. ڕێژەی ڕاگەیەنراو خشتەیەکی دەرکردنی ئێستا بە نرخی ئێستای تۆکن ساڵانە دەکات، و هەردوو تێچوو ژێر فشاری هەمان پاداشتەکانن.

پێناسەی تەکنیکی

سێ خاسیەت دەرکردن لە بەرهەمی ئابووری جیا دەکەنەوە. ئاوێتەکەرن: بەها لە خاوەنە ئێستاکانەوە دێت نەک لە بەکارهێنەرانی خزمەتەکە. لە لێوارەدا خۆ‌شکێنن: هەمان دەرکردن کە بەسەر دانانی زیاتردا دابەش بێت ڕێژەی یەکە نزم دەکاتەوە، و پاداشتی کۆکراوە زۆرتر دەفرۆشرێن و نرخ بەرەو خوارەوە دەکێشن. و ڕاست لەگەڵ ئەو دۆخانەدا پەیوەستن کە وەرگر دەیەوێت دەربچێت. پڕۆتۆکۆلێک کە داهاتی کرێی نەتوانێت لە کاتی کۆتایی خشتەدا جێگای دەرکردن بگرێتەوە، دانانی بەکرێ گرتووە نەک بەدەستی هێناوە.

میکانیزم

دەرکردن ڕەفتارێک دەکڕێت بە نرخێک کە پڕۆتۆکۆل بە دراوی خۆی دیاری دەکات؛ لەبەر ئەوە ڕێژە لەوێ زۆرترینە کە داواکاری سروشتی کەمترینە. سەرمایە دێت، پاداشتی هەر یەکە دادەبەزێت و فرۆشیارانی تۆکنی پاداشت نرخی بەرەو خوارەوە دەکێشن، بۆیە ژمارەی بانگەشەکراو لە هەردوو لاوە دادەڕزێت. ئەوەی دواتر دەمێنێتەوە هەمان ئەوەیە کە کرێ بە تەنها دەیتوانی پشتگیری بکات.

بەکارهێنانی پراکتیکی

کێ بەکاری دەهێنێت
پڕۆتۆکۆلەکان کە ئاسانی ئاڵوگۆڕ دەست پێ دەکەن، دانەران کە بەدوای ڕێژەی بانگەشەکراودان، و شیکەران کە بەرهەمی یارمەتیدراو لە بەرهەمی کرێبنەما جیا دەکەنەوە.
بۆچی گرنگە
خێراترین ڕێگەیە بۆ ڕاکێشانی سەرمایە بۆ بازاڕێکی نوێ، و بۆ وەرگر سەرچاوەیەکی ڕاستەقینەی بەرهەمە، هەرچەندە کاتییە.
سنوورەکان
پاداشت بە سامانێک دەدرێت کە پڕۆتۆکۆل بە ویستی خۆی دروستی دەکات، بەهای گرێبەستی نییە، و خشتەی بڵاوکراوە لەلایەن بەڕێوەبردنەوە دەگۆڕێت.

هەڵەکانی باو

  • زیادکردنی دەرکردن بۆ ڕێژەی سوو و پێشکەشکردنی یەک بەرهەمی تێکەڵ.
  • بەهادارکردنی پاداشت بە نرخی ئێستا بەبێ پشکنینی ئاسانی دەرچوونی ئەو تۆکنە.
  • خشتەی دەرکردن وەک پابەندی دانان نەک پارامەتر.

نموونەکان

numeric

حەوزێک هەفتانە ٥٠٬٠٠٠ تۆکن بە نرخی ٠.٤٠ دەردەکات بەرامبەر ٢٠٬٠٠٠٬٠٠٠ یەکە دانان. ڕێژەی دەرکردن بە ساڵانە دەکاتە نزیکەی ٥.٢ لەسەد، و ئەگەر دانان دووقات بێت یان نرخی تۆکن نیوە بێت، نیوە دەبێت.

داتاکان
  • emission = 50,000 tokens per week
  • reward token price = 0.40
  • deposits valued at 20,000,000
  • 52 weeks per year
هەنگاوەکان
  1. weekly value = 50,000 x 0.40 = 20,000
  2. annualised value = 20,000 x 52 = 1,040,000
  3. emission rate = 1,040,000 / 20,000,000 = 5.2%
  4. if deposits reach 40,000,000: 1,040,000 / 40,000,000 = 2.6%
5.2% annualised, falling to 2.6% if deposits double at an unchanged token price.

The figure assumes the token price holds. Rewards are commonly sold on receipt, which works against that assumption.

market

حەوزێک ڕێژەیەکی تێکەڵی بەرز بانگەشە دەکات کە زۆربەی دەرکردنە. کاتێک خشتەکە پلەیەک دادەبەزێت، دانانەکان لە چەند ڕۆژێکدا دەردەچن و ئەو ڕێژەیەی تەنها لە کرێ دەمێنێتەوە نیشان دەدات ئەو بازاڕە بەڕاستی چەندی دەویست.

بنەمای ماتماتیکی

r_{\text{emission}} = \frac{E \, p_E \, N}{V}

گۆڕاوەکان

r_{\text{emission}}بەرهەمی ساڵانەکراوی پەیوەست بە دەرکردنfraction or %
Eتۆکنی دەرکراو لە هەر خولێکدا بۆ ئەو پۆزیشنەtoken units
p_Eنرخی بازاڕی تۆکنی پاداشتquote currency per token
Nژمارەی ئەو خولانە لە ساڵێکداperiods
Vبەهای ئەو دانانانەی لە دەرکردندا هاوبەشنquote currency

ڕێبازی ژمێریاری

ئەو تۆکنانەی لە یەک خولدا بۆ حەوزەکە دەرکراون بە نرخی بازاڕی تۆکنی پاداشت بەهادار بکە، بە ژمارەی خولەکان ساڵانەی بکە، و بەسەر بەهای ئەو دانانانەدا دابەش بکە کە تێیدا هاوبەشن. ئەنجامەکە جیا لە داهاتی کرێ ڕابگەیەنە؛ کۆکردنەوەی ئەم دووانە ژمارەیەک دروست دەکات کە بەشەکانی متمانەی تەواو جیاوازیان هەیە.

نموونەی کرابوو

داتاکان
  • E = 50,000 tokens per week
  • p_E = 0.40
  • N = 52
  • V = 20,000,000
هەنگاوەکان
  1. E x p_E = 20,000 per week
  2. x N = 1,040,000 per year
  3. / V = 1,040,000 / 20,000,000 = 0.052
Emission component = 5.2% annualised.

لێکدانەوە

ئەم ژمارە ڕێژەی ئێستای یارمەتییەکە، بەهادارکراو بە نرخی ئەمڕۆی تۆکنی پاداشت. سوو نییە، گرێبەستی نییە، و هیچ ناڵێت لەسەر ئەوەی پڕۆتۆکۆل لە کاتی کۆتایی خشتەدا هێشتا هەیە یان نا. تاکە بەکارهێنانی ڕاستگۆی ئەوەیە لەتەنیشت بەرهەمی کرێبنەما بێت، نەک تێکەڵی بکرێت.

گریمانەکان

  • The reward token price holds for the full year, which is the strongest and least defensible assumption in the calculation.
  • The deposit base sharing the emission stays constant; inflows dilute the per-unit rate immediately.
  • The published schedule is followed. Emissions are a governance parameter and can be raised, cut or ended.
سنووری فۆرموڵ
  • The identity values a subsidy, not an economic return, and says nothing about dilution borne by existing token holders.
  • It ignores the exit liquidity for the reward token, which is what determines whether the quoted value can be realised.
  • Annualising a weekly schedule assumes continuation that no protocol is obliged to deliver.
