پێناسەی ساکار

فۆرموڵێک بۆ پەرشی چاوەڕوانکراوی سبەی کە لە سەرسامی ئەمڕۆ و پەرشی ئەمڕۆ دروست دەبێت. وا دەکات ماوەی ئارام و ئاژاوە بەردەوام بن نەک هەموو ڕۆژێک لە نوێوە دەست پێ بکەن.

پێناسەی پیشەیی

مۆدێلێک کە تێیدا پەرشی مەرجدار کۆی کێشداری جێگیرێک، دوا شۆکی چوارگۆشەکراو و پەرشی مەرجداری پێشووە. ئەم دوو کێشە خێرایی وەڵامدانەوەی پەرشی بۆ هەواڵ لە درێژخایەنی ئەو وەڵامدانەوە جیا دەکەنەوە؛ هەر بۆیە یەک دواکەوتن لە هەریەکەیان زۆرجار زنجیرەی درێژی گەڕانەوە باش دادەپۆشێت.

پێناسەی تەکنیکی

گشتاندنی ARCHـە کە پەرشی مەرجداری دواکەوتوو بۆ هاوکێشەی پەرشی زیاد دەکات. لە حاڵەتی پلە یەکدا، کێشی شۆکی چوارگۆشەکراو و کێشی پەرشی دواکەوتوو پێکەوە بەردەوامی پڕۆسە دروست دەکەن: ئەم کۆکە دەبێت لە یەک کەمتر بێت تا پەرشی بێ‌مەرج بوونی هەبێت، و پەرشی مەودا-درێژ یەکسانە بە جێگیرەکە بەسەر یەک کەم هەمان کۆ. لاوازبوونەوەی شۆک جیۆمەتریە بە ئەو ڕێژەی کە هەمان کۆ دەدات.

میکانیزم

بڕگەی شۆکی چوارگۆشەکراو وا دەکات پەرشی لە کاتی ڕووداندا بازبدات؛ بڕگەی پەرشی دواکەوتوو وا دەکات ئەو بازدانە بە هێواشی بڕەوێتەوە نەک یەکجار. ئەم دووانە پێکەوە یەک سەرسامی تاک دەکەن بە ڕێڕەوێکی لاواز-بووی مەترسی بەرز؛ هەر ئەوەی کە خڕبوونەوەی بینراو لەوە دەچێت. کۆی هەردوو کێش درێژی بیرەوەری کۆنترۆڵ دەکات و هەرچی لە یەک نزیکتر بێتەوە پڕۆسە کەمتر لە یاد دەکات.

بەکارهێنانی پراکتیکی

کێ بەکاری دەهێنێت
تیمەکانی مەترسی کە پێشبینی پەرشی بەرهەم دەهێنن، تیمەکانی بژاردە بۆ بەراوردی لەرزۆکی نرخی ڕوودراو لەگەڵ ئەوەی لکێنراو، و توێژەرانی کە پێش تاقیکردنەوەی هەر شتێکی تر پێویستیان بە مۆدێلی پەرشییە.
بۆچی گرنگە
لە هەمان پارامەتری لکێنراو، هەم پێشبینی یەک-هەنگاوی پەرشی دەدات و هەم لەنگەری مەودا-درێژ؛ هەر ئەوەی کە یاسای مارجین و قەبارەی پۆزیشن پێویستیان پێیەتی.
سنوورەکان
تەنها گەورەیی پێشبینی دەکات، لکاندن بە نموونە و خێرایی هەستیارە، و کۆی بەردەوامی نزیک بە یەک مانای ئەوەیە پێشبینیەکان ئەوەندە هێواش دەگەڕێنەوە کە لە کردەوەدا ئاراستە-شوێنکەر دەبن.

هەڵەکانی باو

  • بەکارهێنانی مۆدێلی لکێنراو لە تێپەڕینی گۆڕانی دۆخ بەبێ لکاندنەوە.
  • خوێندنەوەی پێشبینی لەرزۆکی نرخ وەک پێشبینی ئاراستە.
  • پشتگوێخستنی ئەوەی کۆی بەردەوامی خەمڵێنراو لە یەک کەمترە یان نا.

نموونەکان

numeric

بە جێگیری ٠.٠٠٠٠٠٢، کێشی شۆکی ٠.٠٨ و کێشی پەرشی ٠.٩٠، بەردەوامی ٠.٩٨ـە. لادانی ستانداردی مەودا-درێژی ڕۆژانە ١٪ـە و نیوەی هەر شۆکێک بۆ پەرشی نزیکەی ٣٤ ڕۆژ دواتر هێشتا ماوە.

داتاکان
  • omega = 0.000002
  • alpha = 0.08
  • beta = 0.90
هەنگاوەکان
  1. persistence = alpha + beta = 0.98, which is below 1 so the unconditional variance exists
  2. long-run variance = 0.000002 / (1 - 0.98) = 0.000002 / 0.02 = 0.0001
  3. long-run sd = sqrt(0.0001) = 0.01
  4. half-life = ln(0.5) / ln(0.98) = 34.3 periods
long-run daily sd = 1%, shock half-life about 34 days

Parameters are illustrative. Had alpha plus beta been 1 or more, no long-run variance would exist and the division above would be meaningless.

market

تیمێکی مامەڵە هەر چارەکێک مۆدێل دوبارە دەلکێنێت. دوای چارەکێکی ئاژاوە کێشی شۆک بەرز دەبێتەوە و پێشبینی هێواشتر بۆ تێکڕا دەگەڕێتەوە، بۆیە داواکاری مارجینی لێوە دەرچوو ماوەیەکی زۆر دوای ئارامبوونی نرخ بەرز دەمێنێتەوە.

بنەمای ماتماتیکی

\sigma_t^2 = \omega + \alpha\, \varepsilon_{t-1}^2 + \beta\, \sigma_{t-1}^2, \qquad \omega > 0,\ \alpha \ge 0,\ \beta \ge 0,\ \alpha + \beta < 1

گۆڕاوەکان

\sigma_t^2پەرشی مەرجداری خولی tsquared return
\omegaبڕگەی جێگیر؛ ئاستی پەرشی مەودا-درێژ دیاری دەکاتsquared return
\alphaوەڵامدانەوە: کێشی دوا نوێکاری چوارگۆشەکراو، یانی توندی وەڵامی پەرشی بۆ هەواڵdimensionless
\betaبەردەوامی: کێشی پەرشی مەرجداری پێشوو، یانی درێژخایەنی کاریگەری شۆکdimensionless
\alpha + \betaبەردەوامی تێکڕا؛ بۆ بوونی پەرشی بێ‌مەرجی سنووردار دەبێت لە یەک کەمتر بێتdimensionless
\bar{\sigma}^2پەرشی مەودا-درێژ (بێ‌مەرج)، یەکسان بە جێگیر بەسەر یەک کەم ئاڵفا کەم بێتاsquared return

ڕێبازی ژمێریاری

هاوکێشەیەکی تێکڕا دیاری بکە و ماوەکانی بکە بە نوێکاری. سێ پارامەتری پەرشی بە هاوکات بە زۆرترین ڕاستی‌نمایی بخەمڵێنە. بپشکنە کە کۆی هەردوو کێش لە یەک کەمتر بێت، پاشان پەرشی مەودا-درێژ و نیوە-تەمەنی شۆک لە بەهای لکێنراوەوە بژمێرە و ماوەی نموونە ڕاپۆرت بکە.

نموونەی کرابوو

داتاکان
  • omega = 0.000002
  • alpha = 0.08
  • beta = 0.90
هەنگاوەکان
  1. alpha + beta = 0.98 < 1
  2. long-run variance = 0.000002 / 0.02 = 0.0001
  3. long-run sd = 0.01
  4. half-life = ln(0.5) / ln(0.98) = 34.3
long-run sd 1% per period; half-life about 34 periods

لێکدانەوە

ئاڵفا توندی وەڵامدانەوەی پەرشییە و بێتا درێژی بیرەوەری. کۆیان بیرەوەری زنجیرەیە: نزیک یەک، پێشبینی پەرشی مانگەکان لادەدات؛ زۆر کەمتر لە یەک، لە چەند هەفتەیەکدا بۆ ئاستی مەودا-درێژ دەگەڕێتەوە.

گریمانەکان

  • The first-order form shown here is the common working case; higher orders and asymmetric variants exist and give different fitted persistence.
  • Non-negativity of the coefficients and omega above zero keep the variance positive; the sum below one is required for covariance stationarity and for the long-run variance formula to be meaningful.
  • The innovation distribution must be specified for likelihood estimation. A normal assumption is common but leaves residual excess kurtosis, so heavier-tailed choices change the estimates.
سنووری فۆرموڵ
  • The model captures the magnitude of risk and says nothing about direction, so it cannot generate an entry signal on its own.
  • Fitted parameters are unstable: the same series estimated on different windows or frequencies can give materially different persistence, and a half-life computed from one fit should not be treated as a property of the asset.

لەرزۆکی نرخی ئاماژەکراو

گارچ پەرشی لە گەڕانەوەی ڕوودراو و بە ڕوانینی بۆ ڕابردوو دەخەمڵێنێت. لەرزۆکی نرخی لکێنراو لە نرخی بژاردەوە دەردەهێنرێت و لەژێر مۆدێلێکی نرخداناندا داهاتوو-بین. ئەم دووانە دەتوانن ماوەیەکی درێژ ناکۆک بن بەبێ ئەوەی هیچیان هەڵە بن.
