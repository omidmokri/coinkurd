پێناسەی ساکار

کۆمەڵەیەک گواستنەوەی تۆڕ کە پێکەوە تۆمار دەکرێن و ئاماژەیەک بۆ بلۆکی پێشوو لەسەریانە. بلۆکەکان ئەو پێپلیکانەن کە زنجیرە بەوان گەشە دەکات.

پێناسەی پیشەیی

یەکەی پابەندبوون لە زنجیرەدا: کۆمەڵەیەکی ڕیزکراوی گواستنەوە لەگەڵ سەردێرێک کە هاشی بلۆکی پێشوو، پابەندبوون بە کۆمەڵەی گواستنەوەکان، مۆری کات و خانەکانی کۆدەنگی هەڵدەگرێت. دروستی هەمووی-یان-هیچە؛ بلۆک بە یەکەوە پەسەند یان ڕەت دەکرێتەوە.

پێناسەی تەکنیکی

دەفرێک بە دوو بەش. سەردێر ئەو شتەیە کۆدەنگی لەسەری کار دەکات: بە هاش بە بلۆکی باوک دەبەسترێت، بە ڕەگی مێرکل پابەندی لاشەکە دەبێت، و ئەو خانانە هەڵدەگرێت کە یاسای کۆدەنگی دەیپشکنێت، وەکو مۆری کات و لە بەڵگەی کار، ئامانج و نانس. لاشەکە لیستی گواستنەوەکانە. لەبەر ئەوەی سەردێر پابەندی لاشەکەیە، گۆڕینی یەک گواستنەوە سەردێر و بەدوایدا سەردێری هەموو بلۆکەکانی دواتر دەگۆڕێت.

میکانیزم

کۆکردنەوە بۆیە هەیە کە ڕێککەوتن گرانە: نۆدەکان لە جیاتی هەر گواستنەوەیەک، بۆ هەر بلۆکێک یەکجار یەکدەگرن. بارەکە لەسەر سەردێرە. سەردێر ئەوەندە بچووکە کە ناردن و پشکنینی هەرزانە، و لەگەڵ ئەوەش پابەندی هەموو لاشەکەیە؛ بۆیە نۆد دەتوانێت شێوەی زنجیرە پشکنین بکات پێش ئەوەی تەنانەت یەک گواستنەوە دابەزێنێت.

بەکارهێنانی پراکتیکی

کێ بەکاری دەهێنێت
ئەندازیارانی پڕۆتۆکۆڵ، بەڕێوەبەرانی نۆد، دروستکەرانی گەڕۆکی بلۆک، و شیکەرانی کە پشتڕاستکردنەوە دەژمێرن یان تێپەڕینی مامەڵە دەپێون.
بۆچی گرنگە
یەکەی بنەڕەتی کۆتاییکردنە: گواستنەوە هیچ دۆخێکی لەسەر زنجیرە نییە هەتا بلۆکێکی دروست نەیگرێتە خۆ، و قووڵی بە بلۆک دەژمێردرێت.
سنوورەکان
خستنە ناو بلۆکێک کۆتاییبوون نییە. بلۆکی سەری زنجیرە دەتوانێت بە هەتیو بمێنێتەوە ئەگەر لقێکی ڕکابەر بباتەوە، و گواستنەوەکانی بگەڕێنەوە بۆ چاوەڕوانی.

هەڵەکانی باو

  • گواستنەوەی نێردراو وەک کۆتاییکراو دابنێی پێش ئەوەی بلۆکێک بیگرێتە خۆ.
  • قەبارەی بلۆک وەک تێپەڕینی مامەڵە بخوێنیتەوە و کێشی هەر گواستنەوە پشتگوێ بخەی.
  • وا بزانی یەک پشتڕاستکردنەوە لە هەموو زنجیرەیەکدا هەمان مانا هەیە.

نموونەکان

crypto

گواستنەوەیەک کە کرێ دەدات لە مێمپووڵ دەمێنێتەوە هەتا بەرهەمهێنەری بلۆک هەڵی دەبژێرێت. بەرزکردنی کرێ بلۆکەکە خێراتر ناکات؛ تەنها بەختی هەڵبژاردن بۆ بلۆکی داهاتوو باشتر دەکات.

numeric

وابزانە زنجیرەیەک ٢٥٠٠ گواستنەوە لە هەر بلۆکێکدا جێ دەکاتەوە و هەر ٦٠٠ چرکە یەک بلۆک دروست دەکات. تێپەڕینی جێگیر نزیکەی ٤.٢ گواستنەوە لە چرکەیەکە؛ سنووری توانا بە قەبارەی بلۆک و ماوەی بلۆک پێکەوە دیاری دەکرێت، نەک بە هیچیان بە تەنها.

داتاکان
  • transactions per block = 2,500 (illustrative, not a protocol constant)
  • block interval = 600 s
هەنگاوەکان
  1. throughput = 2500 / 600
  2. = 4.166... transactions per second
about 4.2 transactions per second

Illustrative arithmetic. Real chains cap blocks by bytes or gas, so transaction count per block varies with transaction size.
