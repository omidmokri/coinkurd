پێناسەی ساکار

ئەوەی بەڕێوەبەرێک چەند بەسەر پێوەرەکەدا پێشکەوتووە، بەسەر ئەوەی چەند بێ‌ڕێکی ئەمەی کردووە. بەرز مانای ئەوەیە پێشکەوتنەکە بەردەوام بووە، نەک بەختەوەری.

پێناسەی پیشەیی

تێکڕای ڕێژەی چالاک بەسەر هەڵەی شوێنکەوتن، کە ڕێژەی چالاک یەکسانە بە پۆرتفۆلیۆ کەم پێوەر و هەڵەی شوێنکەوتن لادانی ستانداردی هەمان جیاوازییە. هەمان ڕێژەی شارپی مەترسیی چالاکە، بە جێگرتنەوەی پێوەرەکە لە جیاتی ڕێژەی بێ‌مەترسی.

پێناسەی تەکنیکی

سەرەژمارە و بنەژمارە دەبێت هەمان پێوەر، هەمان خولبەندی و هەمان شێوازی کەمکردنی کرێ بەکاربهێنن. ساڵانەکردن سەرەژمارە لە ژمارەی خولەکانی ساڵ و بنەژمارە لە ڕەچەی هەمان ژمارە دەکات، بۆیە ڕێژەی ساڵانە یەکسانە بە ڕێژەی خولی لێکدراو لە ڕەچەی ژمارەی خولەکان. گرتنی ڕێژەی بێ‌مەترسی لە جیاتی پێوەرەکە، ئەم پێوەرە دەگەڕێنێتەوە بۆ ڕێژەی شارپ؛ بۆیە پێوەرەکە دەبێت پێوەری ئەرکەکە بێت نەک ئەوەی لەبەردەستە.

میکانیزم

ڕێژەی چالاک بە تەنها بڕیاری لەسەر نادرێت، چونکە بەڕێوەبەر دەتوانێت بە دوورکەوتنەوەی زیاتر لە پێوەرەکە دروستی بکات نەک بە هەڵبژاردنی باشتر. دابەشکردن بەسەر هەڵەی شوێنکەوتن قەبارەی مەترسییەکە لادەبەرێت و کوالیتییەکەی دەهێڵێتەوە، بۆیە دوو بەڕێوەبەر بە بودجەی مەترسیی جیاواز لەسەر یەک پێوەر بەراوردکراو دەبن.

بەکارهێنانی پراکتیکی

کێ بەکاری دەهێنێت
دابەشکەرانی سەرمایە کە بەڕێوەبەری چالاک هەڵدەبژێرن، لیژنەکانی مەترسیی ناوخۆ کە ئەرکەکان پێداچوونەوە دەکەن، و دروستکەرانی ستراتیژی کە چینێکی زیادکراو لەگەڵ بناغەی بەراورد دەکەن.
بۆچی گرنگە
پێوەری ستانداردی شارەزاییە بۆ هەر یەکەیەک لادان لە ئەرکەکە، و بەڕێوەبەرانی بە بودجەی مەترسیی جیاواز بەراوردکراو دەکات.
سنوورەکان
ئامارەیەکی نمونەییە بە بازنەی دڵنیاییی پان: تۆمارى کورت ناتوانێت ڕێژەی باش لە ڕێژەی بەختەوەر جیا بکاتەوە.

هەڵەکانی باو

  • گرتنی ڕێژەی بێ‌مەترسی وەک پێوەر و ناونانی وەک ڕێژەی زانیاری.
  • بەراوردی ڕێژەی ساڵانەکراو لەگەڵ ڕێژەی مانگانە.
  • پلەبەندیی بەڕێوەبەران بە ڕێژەی دوو ساڵە وەک ئەوەی ڕیزبەندی متمانەپێکراو بێت.

نموونەکان

numeric

سندوقێک ١٢٪ ڕێژە دەدات بەرامبەر ١٠٪ی پێوەرەکە، بە هەڵەی شوێنکەوتنی ٤٪. ڕێژەی چالاک ٢٪ـە و ڕێژەی زانیاری ٠.٥ـە — دوو خاڵ پێشکەوتن کە بە چوار خاڵ لادان کڕدراوە.

داتاکان
  • portfolio return = 12% per year
  • benchmark return = 10% per year
  • annualised tracking error = 4%
  • both measured net of the same fees
هەنگاوەکان
  1. active return = 12% - 10% = 2%
  2. IR = 2% / 4% = 0.5
information ratio = 0.5

The same fund with tracking error of 1% would show an information ratio of 2.0 on identical outperformance — the denominator carries most of the verdict.

worked-series

ڕێژەی چالاکی وەرزیی ‎+٣، ‎−١، ‎+٣، ‎−١، ‎+١ لەسەد تێکڕای ١٪ و هەڵەی شوێنکەوتنی بە تەواوی ٢٪ دەدات، بۆیە ڕێژەی وەرزی ٠.٥ـە. ساڵانەکراو دەبێتە ٠.٥ لێکدراو لە ڕەچەی چوار، یانی ١.٠.

داتاکان
  • active returns = [3, -1, 3, -1, 1] % per quarter
  • sample divisor n - 1
  • m = 4 quarters per year
هەنگاوەکان
  1. mean = 1% per quarter
  2. sample standard deviation = 2% per quarter
  3. quarterly IR = 1 / 2 = 0.5
  4. annualised numerator = 1% * 4 = 4%; annualised TE = 2% * sqrt(4) = 4%
  5. annualised IR = 4 / 4 = 1.0, which equals 0.5 * sqrt(4)
quarterly IR 0.5, annualised IR 1.0

Annualisation multiplies the ratio by the square root of the period count, so the periodicity must always be stated with the figure.

بنەمای ماتماتیکی

\mathrm{IR} = \frac{\bar{R}_p - \bar{R}_b}{\mathrm{TE}} = \frac{\bar{a}}{\sigma_a}, \qquad \mathrm{IR}_{\text{ann}} = \mathrm{IR}\sqrt{m}

گۆڕاوەکان

\bar{a}تێکڕای ڕێژەی چالاک: پۆرتفۆلیۆ کەم پێوەر% per period
\sigma_aهەڵەی شوێنکەوتن: لادانی ستانداردی ڕێژەی چالاک% per period
\bar{R}_pتێکڕای ڕێژەی پۆرتفۆلیۆ% per period
\bar{R}_bتێکڕای ڕێژەی پێوەر لە هەمان خولەکان% per period
mژمارەی خولەکانی هەر ساڵ بۆ ساڵانەکردنcount

ڕێبازی ژمێریاری

پێوەری ئەرکەکە هەڵبژێرە و جێگیری بهێڵە. زنجیرەی ڕێژەی چالاک خول بە خول دروست بکە. بۆ سەرەژمارە تێکڕای بگرە و بۆ بنەژمارە لادانی ستانداردی. دابەشی بکە. بۆ ساڵانەکردن ڕێژەکە لە ڕەچەی ژمارەی خولەکانی ساڵ بکە، و پێوەر، خول و بنەمای کرێ لەگەڵ ژمارەکە ڕاپۆرت بکە.

نموونەی کرابوو

داتاکان
  • portfolio 12% per year, benchmark 10% per year
  • annualised tracking error 4%
  • second case: quarterly active returns [3, -1, 3, -1, 1] %
هەنگاوەکان
  1. case A: active = 2%, IR = 2 / 4 = 0.5
  2. case B: mean active = 1% per quarter, TE = 2% per quarter, quarterly IR = 0.5
  3. case B annualised: 0.5 * sqrt(4) = 1.0
IR = 0.5 in case A; 0.5 quarterly and 1.0 annualised in case B

لێکدانەوە

ئەم ژمارەیە ڕێژەی چالاکە بۆ هەر یەکەیەک مەترسیی چالاک. سفر مانای ئەوەیە لادان لە پێوەرەکە هیچ نەکڕیوە؛ نەرێنی مانای ئەوەیە پارەی تێچووە. قەبارەی ژمارەکە تەنها کاتێک مانا دەدات کە خولبەندی زانرابێت.

گریمانەکان

  • The benchmark is the mandate's benchmark. Substituting the risk-free rate produces the Sharpe ratio under a different name.
  • Arithmetic active return is standard; a geometric definition of active return exists and gives slightly different values.
  • Annualisation by the square root of m assumes serially independent active returns, which persistent active positions violate.
سنووری فۆرموڵ
  • It has a wide sampling distribution, so short records cannot distinguish skill from chance.
  • It is blind to the shape of the active return distribution: a ratio built on one huge quarter scores the same as one built on steady increments.
  • Reporting the best ratio among many candidate managers or strategies inflates it by selection.
