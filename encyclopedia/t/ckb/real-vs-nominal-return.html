پێناسەی ساکار

ڕێژەی گەڕانەوەی ناوی ئەو لەسەدەیەیە کە باڵانست گەشەی کردووە. ڕێژەی گەڕانەوەی ڕاستەقینە ئەوەیە دوای هەڵاوسان دەمێنێتەوە. تەنها دووەمیان دەڵێت ئایا دەتوانی زیاتر لە پێشتر بکڕیت.

پێناسەی پیشەیی

دوو دەربڕین بۆ هەمان قازانج. ژمارەی ناوی گۆڕانە بە یەکەی دراو؛ ژمارەی ڕاستەقینە بە ئاستی نرخی هەمان ماوە ڕێکی دەخات. بەستنەوەی ورد لێکدەرە نەک کۆکەر، و لەگەڵ بەرزبوونەوەی هەڵاوسان جیاوازی فراوانتر دەبێت.

پێناسەی تەکنیکی

بەپێی پەیوەندی فیشەر، یەک زیاد ڕێژەی گەڕانەوەی ناوی یەکسانە بە لێکدانی یەک زیاد ڕێژەی گەڕانەوەی ڕاستەقینە لە یەک زیاد هەڵاوسان. لابردنی هەڵاوسان لە ڕێژەی ناوی نزیکەییەکی پلەی یەکەمە کە هەڵەی زاراوەی لێکدەری r × i ـە؛ لە هەڵاوسانی نزمدا هەڵەکە بچووکە، لە بەرزدا نا. وەشانی ڕوویداو و وەشانی چاوەڕوانکراوی ئەم پەیوەندییە دەبێت جیا بپارێزرێن.

میکانیزم

ڕێژەی گەڕانەوە ڕێژەیەکی پارەیە، و هەڵاوسان ئەو یەکەیە دەگۆڕێت کە پارە پێی دەپێورێت. بۆیە ڕاستکردنەوەی مانای دابەشکردنە بەسەر ڕێژەی ئاستی نرخدا، نەک لابردنی لەسەدەیەک — هەمان ئەو هۆیەی کە لێکدانی دوو لەسەدە، کۆکردنیان نییە.

بەکارهێنانی پراکتیکی

کێ بەکاری دەهێنێت
پاشەکەوتکەرانی ماوەدرێژ، لیژنەی خانەنشینی و وەقف، و هەر کەسێک ڕێژەی گەڕانەوە لە نێوان ماوەی هەڵاوسانی جیاواز یان نێوان دراوەکان بەراورد دەکات.
بۆچی گرنگە
تۆمارێکی ناوی لە دەیەیەکی هەڵاوسانی بەرز بەراورد نەکراوە لەگەڵ دەیەیەکی هەڵاوسانی نزم تا هەردووکیان ڕێک نەخرێن.
سنوورەکان
ژمارەی ڕاستەقینە ئەو پێوەری نرخە بۆ خۆی دەمێنێت کە هەڵبژێردراوە، و باج زۆرتر لەسەر قازانجی ناوی دەگیرێت، بۆیە ڕێژەی ڕاستەقینەی دوای باج کەمترە.

هەڵەکانی باو

  • بەکارهێنانی n کەم i لە هەڵاوسانی دوو ژمارەیی و وردی بناوبەری.
  • ڕێکخستن بە پێوەرێک کە لەگەڵ خەرجی خۆت ناگونجێت.
  • بەراوردکردنی ڕێژەی ڕاستەقینە لەگەڵ پێوەرێکی ناوی.

نموونەکان

market

هەژمارێکی سپاردە بە ڕێژەی ڕاگەیەنراوی ١٨٪ لە ساڵێکی هەڵاوسانی ٢٥٪دا، بە کەلوپەل دۆخێکی زیانبارە، هەرچەندە هەر تۆمارێکی مانگانە باڵانسێکی گەورەتر لە پێشووی نیشان دەدات.

numeric

ناوی ١٨٪، هەڵاوسان ٢٥٪: ڕێژەی ڕاستەقینەی ورد سالبی ٥.٦٪ـە، لە کاتێکدا کورتبڕی ١٨ کەم ٢٥ دەڵێت سالبی ٧٪. نزیکەییەکە بە بڕی ١.٤ خاڵی لەسەدە هەڵەیە چونکە زاراوەی لێکدەر فڕێ دەدات.

داتاکان
  • nominal return n = 18%
  • inflation i = 25%
  • same measurement window for both
هەنگاوەکان
  1. 1 + r = 1.18 / 1.25 = 0.944
  2. r = 0.944 - 1 = -0.056
  3. linear shortcut: 0.18 - 0.25 = -0.07
exact r = -5.6%; approximation = -7.0%

Illustrative figures. The error equals r x i and grows with the size of both terms.

بنەمای ماتماتیکی

(1+n) = (1+r)(1+i) \;\Longrightarrow\; r = \frac{1+n}{1+i} - 1 \;\approx\; n - i

ڕێبازی ژمێریاری

ڕێژەی ناوی و هەڵاوسان لەسەر هەمان ماوە بپێوە. یەک زیاد ناوی دابەش بکە بەسەر یەک زیاد هەڵاوسان و یەک لێ کەم بکە. کورتبڕی لێکردنەوە تەنها وەک پشکنینێکی خێرا بەکاربهێنە و هەرگیز لە هەڵاوسانی بەرزدا نا.

لێکدانەوە

ڕێژەی ڕاستەقینەی سالبی ٥.٦٪ مانای ئەوەیە ئەو سامانە ٥.٦٪ کەلوپەلی کەمتر لە سەرەتا دەستی بەسەردایە، سەرەڕای باڵانسی ناوی گەورەتر. ئاماژەی ژمارەی ڕاستەقینە، نەک ناوی، وەڵام دەداتەوە ئایا سامانمەندی گەشەی کردووە.

گریمانەکان

  • The nominal return and the inflation measure cover exactly the same window and the same currency.
  • The relation shown is the realised (ex post) form. The ex ante form uses expected inflation and therefore carries an expectations error.
  • n - i is an approximation only; it is reported here as such and must never be presented as the identity.
سنووری فۆرموڵ
  • Index choice changes the answer; a household's own basket can differ materially from the published series.
  • Taxes usually apply to nominal gains, so the after-tax real return is lower than this calculation.

ڕێژەی سووی ڕاستەقینە

ڕێژەی سووی ڕاستەقینە، ڕێژەی گەڕانەوەی ڕاستەقینەی گرێبەستێکی قەرزە. ڕێژەی گەڕانەوەی ڕاستەقینە دۆخی گشتییە و بەسەر هەر سامانێکدا جێبەجێ دەکرێت، تەنانەت ئەوەی هیچ ڕێژەی ڕاگەیەنراوی نییە.
