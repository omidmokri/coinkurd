پێناسەی ساکار

ژمارەیەکی نهێنی زۆر گەورە. ئەو ئیمزایە دروست دەکات کە ڕێگە دەدات باڵانس بجوڵێت، بۆیە هەبوونی هەمان مانای خاوەندارێتییە لەسەر بلۆکچەین.

پێناسەی پیشەیی

نیوەی نهێنی جووتە‌کلیلێکی نا‌هاوسەنگ. کلیلی گشتی و ئەو ناونیشانەی لێی دەردەهێنرێت دەکرێت بە ئازادی بڵاو بکرێنەوە؛ تەنها کلیلی تایبەت دەتوانێت ئیمزایەک دروست بکات کە تۆڕ بۆ ئەو ناونیشانە پەسەندی بکات. بۆ هیچ شوێنێک نانێردرێت — ئیمزاکردن لە ناوخۆ ڕوودەدات و تەنها ئیمزا دەگوازرێتەوە.

پێناسەی تەکنیکی

ژمارەیەکە لە بۆشایی کلیلی خەتێکی هێلکەیی، لە بیتکۆین و ئیتریۆم خەتی secp256k1. لێکدانی ژمارە بە بەرهەمهێنەری خەت کلیلی گشتی دەدات، و ئەم کردارە لە ڕووی پراکتیکییەوە یەک‌لایەنەیە، بۆیە کلیلی گشتی هیچ شتێکی بەکارهێنراو لە نهێنی ئاشکرا ناکات. ئیمزا بەبێ کلیل دەستکاری ناکرێت، بەڵام نانسێکی دووبارە یان لارێژ دەتوانێت کلیل ئاشکرا بکات؛ ئەمە مەترسی جێبەجێکردنە نەک بیرکاری.

میکانیزم

بۆ پشکنینی ئیمزا تەنها کلیلی گشتی پێویستە، بۆیە هەر خاڵێکی تۆڕ دەتوانێت ئیمزا پشکنێت بەبێ ئەوەی نهێنی ببینێت. هەمان نا‌هاوسەنگی ڕێگە دەدات تۆڕێکی کراوە خاوەندارێتی جێبەجێ بکات بەبێ هیچ تۆمارگەیەک. ئەمە واتای ئەوەشە هیچ هەژمارێک نییە بۆ داخستن: کلیلی ئاشکرابوو هەڵنەوەشێتەوە، تەنها دەکرێت باڵانس بگوازرێتەوە بۆ کلیلێک کە تا ئێستا نهێنییە.

بەکارهێنانی پراکتیکی

کێ بەکاری دەهێنێت
گەشەپێدەری جانتا و خاڵی تۆڕ، ئەندازیاری پاراستنی سامان، پشکنەر، و هەر کەسێک کە بە دەست یان بە سکریپت ئیمزا دەکات.
بۆچی گرنگە
هەموو مۆدێلی کۆنتڕۆڵی دەستگەیشتنی بلۆکچەین هەمان ئەمەیە، بۆیە شێوازی هەڵگرتنی کلیل سەرچاوەی نزیکەی هەموو زیانی ڕاستەقینەیە.
سنوورەکان
بیرکاری تەنها کاتێک کلیل دەپارێزێت کە ئامێر، سەرچاوەی ژمارەی ڕێکەوتی و کتێبخانەی ئیمزا دروست کار بکەن؛ زۆربەی ئاشکرابوونی کلیل نەرمەکالایی یان مرۆییە نەک شاردنەوەیی.

هەڵەکانی باو

  • کلیل بنێری بۆ ئامرازی وێبگەڕ، خانەی مەڵبەند یان چات.
  • کلیل دروست بکەی بە سەرچاوەی ڕێکەوتی لاواز یان نا‌متمانە.
  • کلیلێکی جارێک ئاشکرابوو دوای گەڕاندنەوەی سامان بۆی سەلامەت دابنێی.

نموونەکان

numeric

بۆشایی کلیلی secp256k1 کەمێک کەمترە لە ٢ بە هێزی ٢٥٦، نزیکەی ١.١٦ لە ١٠ بە هێزی ٧٧. هیچ بودجەی گەڕانێک پێی ناگات؛ بۆیە هێرشبەر بەرەو مۆبایل، کلیپبۆرد و مرۆڤ دەچێت.

داتاکان
  • Curve order of secp256k1 is slightly less than 2^256
  • A valid private key is any integer in [1, n-1]
هەنگاوەکان
  1. 2^256 = 1.1579 x 10^77 approximately
  2. The curve order n is a little below that, so the usable space is of the same magnitude
About 1.16 x 10^77 valid keys

Size of the space bounds brute force only. It gives no protection against a weak random-number generator, which can shrink the real space to something searchable.

security
