Coin icons supplied by the owner (3D pack, "100 altcoins" sample) that are not on the coins wall yet.
Named files are the coins they clearly show; `unknown-NN` are icons whose coin could not be identified.
Move one up to `assets/coin3d/<TICKER>.png` and add the ticker to COIN3D in index.html to use it.
Any coin without a picture gets a drawn 3D coin with its ticker, so a tile is never empty.
